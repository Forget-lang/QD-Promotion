## 调研三问（都落到「某个时刻」）

1. **老板最头疼的时刻**：客人做完护理直夸好，你请她「带朋友来」，她笑着点头就是不带；你自己发圈喊人，老客户反而觉得你在推销。
2. **他现在怎么做（反常识切入）**：靠老客「人情」免费帮忙 + 群发优惠券。反常识——不是老客不认你可能，是你没给她一个「带人、她自己也有好处、还不用开口求人」的台阶。
3. **我们哪个功能真解决那一刻**：转赠（老客把体验券亲手转给闺蜜）+ 转赠奖励（闺蜜核销后，系统自动奖老客一张券）。这是全产品唯一的「系统自动到账」，不靠老板去主动触达（触达模型边界：产品不向手机号推、不主动触达未领取者）。

## 闭环故事五拍

| 拍 | 叙事职责 | 内容 |
|---|---|---|
| 1 抛悬念 | 痛点（结果前置） | 客人做完直夸好，让她带朋友来她笑着点头就是不带——先给钩子：「一张卡，让老客主动帮你带回新客，她还觉得是自己给闺蜜面子。」场景压在老客券详情里那个没人点的「转赠给好友」界面上。 |
| 2 讲道理 | 定律一不珍惜律 + 定律三占便宜感（辅：定律二门槛换珍惜） | 白群发的券，顾客领一堆不用——不珍惜；让老客把「给闺蜜的体验」亲手转赠出去，闺蜜觉得是熟人人情（面子），你还给带人的留一张「闺蜜用掉之后才到账」的奖励券。带人的有面子有实惠，她才肯开口。系统不主动捞人，靠顾客转赠这个社交动作把新客领进门。 |
| 3 证明 | 示例值演示 | 做两张券——一张体验兑换券当「转赠物」、一张私密券当「奖励」。示例：兑换内容「深层清洁护理」、有效期 15 天、每人限领 1 张、发放方式私密发放、开转赠 + 转赠奖励、奖励券选那张私密券。 |
| 4 落地 | 功能点逐个讲透（制券大头） | 见下「配置明细」①②。 |
| 5 金句 | 认知缺口收口 | 「老带新不是求老客帮忙，是给她一个带人、自己也有好处的台阶。」 |

### ③ 顾客侧 / 核销侧流转——流转屏

老客券详情点「转赠给好友」→ 闺蜜**主动领取**（触达模型：领取永远顾客主动）→ 闺蜜券卡右下角标「转赠获得」→ 闺蜜到店核销 → **老客自动收到奖励券 + 到账通知**（全产品唯一系统自动到账，发生在第二人核销之后）。

### 奖励券（第二张券，私密发放）

一张私密券当奖品（如「下次护理代金券」），仅作转赠奖励的候选池，不单独讲设置（本篇用不上的细节不提）。

## 屏序草案（跟着功能点的选择逻辑走，非点击顺序 · 约 6 屏 · ~90s）

1. hook/pain — 痛点压在「转赠给好友」界面（结果前置开场）
2. idea/mechanism — 讲道理：不珍惜律 + 占便宜感（机制对比）
3. fields — 制券①：体验兑换券券面 + 发放方式
4. fields — 制券②：转赠 + 转赠奖励 + 两张券关系（本片亮点）
5. advance — 顾客侧流转：转赠→领→核销→奖励到账
6. cta — 金句收口

> 屏数/时长最终以讲透为准，铺屏阶段按真图微调；不为时长砍功能点。

## 第 1 步补充 · 官网 + 语料现挖增量（2026-09-10，用户追问后补齐）

### 官网现读（`/marketing/laodai-xin` + `/industries`，角色=对账镜+蓝本增量，数字不采信）
- **痛点框架（喂痛点/讲道理拍，借结构不搬话术）**：官网把痛点定义成「愿意介绍，却没有一张能发出去的东西」「口头说下次带朋友来，朋友来了兑不了、老客也没好处，介绍就停在酒桌上」——正是定律八认知缺口式痛点，比我自己写的更具体，采纳。
- **私密发放理由（喂配置明细①）**：官网原话「公开裂变海报让全店客人刷屏，老客不愿意；适合私密发给愿意开口的人」——独立印证本片「体验券走私密发放给老客」的选择 + 触达模型（不公开刷屏）。
- **5 步链路（喂流转屏）**：做一张可转的体验券（写明可转给朋友）→ 私密发给愿意开口的老客 → 朋友领进卡包到店核销 → 再给老客一张奖励券（官网原文称「回店券」，我方口播/画面统一「奖励券」；奖励写清、发得到）→ 两边都核销得上。与我的两张券 + 转赠 + 转赠奖励链路一致。
- **美业场景对味**：官网「护理做完转给闺蜜」场景 + industries 美业推荐组合含「转介绍」——行业契合度确认。
- **对账/避雷**：① 页面自带「永久免费」与站外生态词字样 → 触台账 W5/W4/W6，一律不上屏进口播（措辞按子串匹配，此处不逐字复述，词表见 `spec/redlines.json`）；② 场景数字「39 元体验券 / 7 天护理券」属断言层，只作示例量级、不照搬；③ 官网「店员把券发到她手机里」措辞偏「系统自动」——我方口播须说成「老板私密一对一发给老客」，不暗示系统主动捞人（无新增硬越界，不改 §3 台账）。

### 爆款语料现挖（grep `cases.jsonl`：美容+老带新 27 篇 / 裂变机制 170 篇）
- **借到的讲法**：① 雷总餐饮篇「老顾客带新顾客来送一份凉菜/一瓶饮料…生意像滚雪球越做越大」= 转赠奖励的口语版（借结构：带人→给个小奖励→滚雪球）；② 烧烤篇「不是打折、不是送啤酒、不是充值满减」= 反常识开场 + 错误示范先行（通则 #5），可迁移做我 hook 屏；③ 「给两张好友卡」比「转赠」更 0 接触可懂（去冗边界：换成商家嘴里的说法）；④ 「你得给到别人去裂变的理由」= 定律一/三 的口语锚。
