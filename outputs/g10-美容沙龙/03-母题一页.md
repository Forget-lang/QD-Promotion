## 开工视觉语言隔离声明（方向已锁；五轴证据已于 2026-09-11 并排真图坐实）

本片三件事：
- **行业母题**：美容沙龙「护理邀请卡」语言——一张**递给闺蜜的卡**（社交递卡动作），不是"存折翻页"、不是"深色菜单板"、不是"大圆角清单卡"。
- **背景风格族**：抽象光效族 · `BG-ABS-006 粉晕光弧底`（浅底、粉调、梦幻干净；与 g09 蓝绿光斑冷底、g08 朱红海浪纹天然区隔）。
- **转场字幕风格**：转场 `slide`（卡片横向递入，g06 wipe / g07 dissolve / g08 reveal / g09 reveal 都没用过）；钩子 `contrast`（白群发没人用 vs 亲手转赠被珍惜，g06/08/09 都是 story）；motion `bouncy`（递卡/翻转的轻快社交感，区别 g09 buttery）。

## 与上一条 g09 的 ≥3 处非颜色结构差异（已并排真图坐实 · 2026-09-11）

并排图：`bench/g10-vs-g09-制券屏并排.png`（左 = g10 S3 制券①，右 = g09 S3 制券①，两图均为屏尾交付帧）。逐轴核对真图：

1. **栅格**：g10 = 左右双段（左约 55% 竖版邀请卡 hero + 右侧引线注释组）+ 底部通栏老板注意卡；g09 = 通栏表单，三组带圈序号 ①②③（卡基本信息 / 期限 / 领取与转赠）纵向堆叠。✔ 坐实
2. **容器形状**：g10 = 竖版邀请卡（缎带顶 + 撕齿 + 磁条感收口），字段行「左标签 · 右药丸值」嵌进卡内；g09 = 满宽圆角白表单卡，原生输入框 + toggle 开关控件。✔ 坐实
3. **标题承载**：g10 = 得意黑大标题「先做这张体验邀请卡」+ 紫分隔线（画面零面包屑、零示例标）；g09 = 大标题 + 副标「逐项设一下」+ 右上「次卡」眉标，无分隔横带。✔ 坐实
4. **入场语法**：g10 = 整卡微旋递入 → 字段随口播逐条擦入 → 引线注释浮出（三层递进）；g09 = 表单组按序号分组逐块入场（单层节奏）。✔ 坐实
5. **节奏密度（含强调载体）**：g10 = 卡内 5 字段 + 卡外 3 条虚线引线（外挂讲「为什么这么设」）+ 1 张老板注意卡，强调走缎带色块与药丸值；g09 = 8 字段三组线型下排，强调走圈序号与 toggle 开关（讲「设什么」本身）。✔ 坐实

> 五轴全部真图坐实，非换皮同构：g10 = 卡片预览驱动（先看卡、再讲为什么），g09 = 表单配置驱动（逐项设、当场开关），呈现架构不同。

## 视觉定位卡（2026-09-17 补记）

> 本片做于 2026-09-14「视觉定位卡先行」拍板之前，当时无此卡；现按 SKILL 第 2 步口径补答，四栏内容**从已成片母题反推**、与画面一致，非伪造事前记录。

- **核心痛点**：客人做完直夸好，请她带朋友来，她笑着点头就是不带——老客的人情帮不了你拉新。
- **情绪关键词**：柔 · 亲密 · 社交递卡 · 轻快 · 克制
- **视觉关键词**：粉晕光弧浅底 · 竖版邀请卡 · 缎带与撕齿 · 药丸值 + 引线注释 · 深字浅底
- **禁止出现**：SaaS 后台感 · 深色机械清单 · 密集图标堆砌 · 全屏毛玻璃

**背景素材张数**：1 张（BG-ABS-006 粉晕光弧底 → `backgrounds/g10/bg.png`，全片共用一张底；母题装饰层叠在其上、不当底——素材最小化纪律）。
