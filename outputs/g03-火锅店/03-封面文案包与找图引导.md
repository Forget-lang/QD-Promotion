## 一、封面策略

**核心卖点**：下午茶折扣券把火锅店闲时变成钱（反常识：下午 3 点的火锅店坐满了人）

**封面版式**（从 C-01~C-07 选）：**C-05 痛点场景型**（上半屏痛点问句 + 下半屏行业元素）——贴合"下午没人"的扎心场景，问句钩子点击欲强

**A/B 两版**（投放后保留数据好的）：

| 版本 | 版式 | 主标题 | 副标题 |
|---|---|---|---|
| A 版（推荐主推） | C-05 痛点场景型 | 下午3点的火锅店，坐满了人？ | 一张"下午茶折扣券"的秘密 |
| B 版 | C-04 卡片干货型 | 火锅店下午没人？ | 一张券，把空座位变成钱 |

## 二、封面配色

- 主色：暖橙 #E8734A（呼应视频 palette warm-orange）
- 背景：米白 #F5F0E8（BG-ABS-001 暖奶油卡片底）
- 文字：深棕 #2A1A12（保证浅底对比度 ≥4.5:1）
- 色系 ≤3 个（暖橙 + 米白 + 深棕），与视频一致

## 三、封面版式结构（A 版 C-05）

```
┌─────────────────────────┐
│  顶部安全区 160px 留白      │
│                         │
│  大字问句（≥80px）：       │
│  下午3点的火锅店，坐满了人？  │ ← 白字黑描边或深棕字（浅底）
│                         │
│  中部留白/光斑过渡          │
│                         │
│  副标题（40-48px）：       │
│  一张"下午茶折扣券"的秘密    │
│                         │
│  底部行业元素（1-2 个）：    │
│  🍲 火锅图标 + 券面小图     │ ← 图标素材/代码绘制
│  底部安全区 200px 留白      │
└─────────────────────────┘
```

**设计要点**：问句是绝对焦点（占画面 40%+）；背景用 BG-ABS-001 直接显示（不模糊）；不堆"免费"促销角标；右下角可加「券到卡包」文字角标（品牌克制）。

## 五、三平台封面规格

| 平台 | 规格 | 说明 |
|---|---|---|
| 抖音 | 9:16（1080×1920） | 手动设置封面，关闭"自动同步首帧" |
| 小红书 | 3:4 裁切中间区（1080×1440） | 标题/问句放中间安全区，feed 裁切不切掉 |
| 搜狐 | 16:9 横版头图（1920×1080） | 单独排版：左标题 + 右行业元素，风格与竖版一致 |

## 六、封面自查清单

- ☑ 三平台尺寸正确（抖音 9:16 / 小红书 3:4 中间区 / 搜狐 16:9）
- ☑ 7 条设计原则（干净优先/标题即内容/第一直觉引流/品牌克制/真实/平台分级/归档）
- ☑ 6 个核心要素 ≥3 个（数字冲击/痛点共鸣/行业识别/反差对比/利益承诺/情绪脸谱）
- ☑ 版式选自 C-01~C-07，配色主色 ≤2 个 + 与视频 palette 呼应
- ☑ 对比度 ≥4.5:1；无小程序码；无"免费"促销角标；无极限词
- ☑ 封面与首帧主色/字体/核心元素一致（首帧兑现封面承诺）
- ☑ A/B 两版已备
