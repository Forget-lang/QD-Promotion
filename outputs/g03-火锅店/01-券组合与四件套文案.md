## ① 活动设计总览

| 项 | 内容 |
|---|---|
| 活动名称 | 下午茶折扣券——把火锅店下午填满 |
| 目标客群 | 社区型火锅店（人均 80-120 元） |
| 核心玩法 | P-03 闲时填空档（主）：下午 2-5 点时段折扣券填闲时；核销奖励（辅）：核销后自动送券锁复购 |
| 活动周期 | 2026-09-10 ~ 10-10（中秋国庆聚餐季，宣传窗口） |

| 预期效果 | 下午闲时上座率提升；老客核销后复购率提升；晚市价格不受影响 |

### 券 1 · 下午茶折扣券（折扣券）

| 字段 | 配置 | 边界校验（R1） |
|---|---|---|
| 券类型 | 折扣券（打八折） | ✅ R1：折扣券 = 打 X 折 |
| 名称 | 下午茶折扣券 | ✅ ≤18 字 |
| 库存 | 按需（示例 500 张） | ✅ 1~10000 |
| 可用时段 | 周一至周日 + 14:00-17:00 | ✅ R1：可用时段最多 2 段，本活动 1 段 |
| 有效期 | 固定时间段（2026-09-10 ~ 10-10） | ✅ R1：固定时间段模式 |
| 限领规则 | 每人限领 1 张 | ✅ |
| 核销限制 | 到店核销（商家扫顾客出示的码） | ✅ R1：核销方向=商家扫顾客 |
| 使用须知 | 仅限下午 14:00-17:00 到店使用；不与店内其他优惠同享；节假日通用 | 参考话术，门店可自定义 |
| 定时开抢 | 每日 13:00 准时放券（领取页倒计时） | ✅ R1：公开领取可设自定义领取开始/结束时间 |
| 核销奖励 | 开启：核销后自动再送本券一张 | ✅ R1：核销奖励 = 核销后再得本券一张（仅优惠券支持） |

**边界提示**：
- 无在线支付（券是到店核销，不做"线上收款"表述）
- 可用时段最多 2 段（如要加"工作日晚市前"需删一段，本例只用下午一段）
- 次卡无转赠奖励——本活动不用次卡，不涉及该口径

## ④ 攻略长文（场景化功能教学，搜狐文章基础）

**标题**：火锅店下午没人？一张"下午茶折扣券"，把空座位变成钱

**结构**（≥6 信息单元 + 2 层递进）：

**开头 · 扎心现实**：火锅店老板都懂——晚市忙得脚不沾地，下午却闲得发慌。房租按天付，员工按天养，锅底烧热了没人来，翻台率为零。下午没客人，是火锅店看不见的隐形亏损。

**第一层 · 为什么下午是隐形亏损**：房租付的是全天，人力养的是全天，可营收只靠晚餐那几个小时。下午的空座位，每一张都在亏钱。这不是淡季的问题，是每天都会发生的时间黑洞。

**第二层 · 破局思路：不是打折，是"时段限定"**：全场打折会伤价格、引来贪便宜的人。更聪明的做法是：做一张"下午茶折扣券"，只在下午两点到五点有效。想吃火锅的人，下午来更划算；晚市的价，一分不动。

**第三层 · 具体怎么做（三步）**：第一步，选时段：下午两点到五点；第二步，设折扣：八折七折，自己定；第三步，定时开抢：下午一点准时放券。工具是"券到卡包"电子券——手机上就能做，不用找开发。

**第四层 · 为什么这招好使**：三件事同时发生——顾客得了实惠（下午吃火锅便宜，错峰不排队）；你填了闲时（空座位变成钱，房租照样付）；晚市不受影响（券只在下午有效）。

**进阶 · 把一次生意变成回头客**：开启核销奖励——顾客下午核销了这张券，系统自动再送一张，下周还能用。吃完这次，还惦记下次，回头客就是这么来的。

**收尾 · 数据说话**：发了多少张、核销了多少张、哪个渠道带来的客人最多，后台都看得见，每一分钱花在哪都清清楚楚。

**结尾**：下午的座位，别让它空着。"券到卡包"——把火锅店闲时变成钱的电子券工具。
