## S1 · 钩子屏（type: hook / ui: g09-hook）

- **叙事职责**：钩子。痛点直接压在"正在被填的次卡"界面上（C-05 同格，不另开铺垫屏）。
- **本屏讲哪项设置**：不讲解项，展示磁条次卡（洗护5次卡）+ 5 个泡泡其中 2 个已变暗（示意"用过两次、还剩三次"）→ 焦点是"次数看得见"。
- **商家在想什么**：怕的不是今天没人来，是洗完这一次没下文。
- **布局来源**：磁条卡（S3 标杆同款卡面）+ 痛点大字压在卡上方。
- **口播句→区域**：句1"洗完这一次…心里没数"→点亮痛点大字；句2"变成客人自己看得见的次数"→点亮卡上一排泡泡（2 暗 3 亮）。
- **信息全景清单**：① 痛点钩子大字 ② 判断副行 ③ 磁条卡名"洗护5次卡" ④ 5 泡泡（2 已用/3 剩余）⑤ "还剩 3 次"角标。≥3 ✓
- **画面占用率**：卡+大字+副行铺满中上带，≥70%。
- **入场语法**：痛点大字淡入上移 → 磁条卡落定 → 泡泡逐个上浮（已用的先暗、剩余的后点亮）。
- **本屏判据自查**：C-01 ✓（无具象插画，泡泡=抽象圆）｜C-05 ✓（钩子长在卡界面、无独立铺垫）｜C-06 ✓｜C-10 ✓（不画返回键/状态栏）｜C-11 ✓（"示例"角标挂右上、非屏底）｜C-14 ✓（无分镜外内容）。

## S2 · 痛点屏（type: pain / ui: g09-pain）

- **叙事职责**：痛点·现状失效对照。
- **本屏讲哪项设置**：不讲设置，讲"现在这么做→结果"：靠记性提一句→转身就忘；不知道隔多久该来→接不住；想起来→人去别家。
- **商家在想什么**：客人洗完走了，我到底啥时候该叫他？
- **布局来源**：白卡对照清单（复用 S3 白卡语言，✗ 红叉行）。
- **口播句→区域**：三句分别点亮三行 act→fail。
- **信息全景清单**：① 主标题 ② 副行 ③ 三条"现状→✗失效"对照。≥3 ✓
- **画面占用率**：≥70%（三行清单撑满白卡）。
- **入场语法**：主标题落定 → 三行逐条淡入（✗ 逐个浮现）。
- **本屏判据自查**：C-01 ✓｜C-06 ✓｜C-09 ✓（无统一底部结论条）｜C-10 ✓｜C-14 ✓。缓冲词"多半"1 处（红线合规）。

## S3 · 制券①屏（type: fields / ui: g09-make）——一屏标杆·样式冻结

- **叙事职责**：字段·把一次变五次。
- **本屏讲哪项设置**：`次卡名称`=洗护5次卡 → `每张包含次数`=5 次（hero，为什么：洗澡两三周一次，5 次管两三个月）→ `每人限领`=1 张 → `有效期类型`=自领券日起 → `有效期`=120 天（为什么：用得完又不拖到睡死）。不这么填：次数拍脑袋定 10 次→客人觉得远、不来了。
- **商家在想什么**：一次洗护几十块，我想把他接下来几次都锁定在我这。
- **布局来源**：一屏标杆（磁条卡 + 制作清单白卡）。
- **口播句→区域**：句1→卡名/次卡名称行；句2→每张包含次数 hero；句3→有效期行；句4→每人限领行。
- **信息全景清单**：磁条卡（卡名/5 泡泡/有效期小行）+ 清单 5 行字段。≥3 ✓
- **画面占用率**：≥70%（标杆实测铺满）。
- **入场语法**：卡落定 → 泡泡上浮 → 清单逐行淡入（已定，见标杆）。
- **本屏判据自查**：C-01 ✓｜C-02 ✓（结构源自磁条卡实物）｜C-03 ✓（载体=次卡，外观新配冷色）｜C-06 ✓｜C-07 ✓（清单 5 行在骨架容量内）｜C-10 ✓｜C-11 ✓（示例角标挂顶）｜C-14 ✓。字段名回 card-fields ① 层已过。

## S4 · 制券②屏（type: fields / ui: g09-make + intervalHint）——本片讲透核心

- **叙事职责**：字段·锁住到店节奏（核销间隔）。
- **本屏讲哪项设置**：`限制核销间隔`=开（hero）→ `核销间隔`=14 天（为什么：每两周用一次，防"一周把 5 次用光、优惠一次没"和"长期不来把卡睡死"两头）。不这么填：不设间隔→客人连着把 5 次用完，之后没有再来的钩子。
- **商家在想什么**：我不想让他一周洗五次把便宜占完，我想让他两三个月里常来。
- **布局来源**：复用 S3 制券屏组件，新增"间隔"注解行——5 个泡泡之间插"间隔 14 天"胶囊，把"核销间隔"画成看得见的节奏。
- **口播句→区域**：句1→限制核销间隔 hero；句2→核销间隔行 + 泡泡间"间隔14天"胶囊；句3（反面后果）→整排泡泡；句4→卡面"使用间隔"小字。
- **信息全景清单**：磁条卡（5 泡泡带间隔注解）+ 核销节奏组 2 行 + "两周来一次"标签。≥3 ✓
- **画面占用率**：≥70%（泡泡带间隔胶囊撑开卡面）。
- **入场语法**：卡落定 → 泡泡上浮 → "间隔14天"胶囊逐个淡入 → 清单行淡入。
- **本屏判据自查**：C-01 ✓｜C-06 ✓｜C-07 ✓（2 行 + 卡，容量内）｜C-10 ✓｜C-11 ✓（示例角标）｜C-14 ✓。⚠️ 制券② 只 2 字段行，靠卡面"间隔"注解撑密度，避免"很空"。

## S5 · 私密发放屏（type: fields / ui: g09-make，发放字段组）

- **叙事职责**：步骤/字段·只发给办卡的人。
- **本屏讲哪项设置**：`超时时间`=1 天（为什么：给宽点别把客人挡在外面）→ `发放方式`=二维码（次卡仅私密发放，正向说"只发给办卡的人"）→ `发放备注`=张姐·金毛·洗护5次（为什么：记是谁的哪只宠物，下次唤醒有据）。
- **商家在想什么**：这张卡是张姐办的，我得发回给她、别发错人。
- **布局来源**：复用制券屏组件，白卡换"① 发给谁"组。
- **口播句→区域**：句1→发放方式行（二维码）；句2→超时时间行；句3→发放备注行。
- **信息全景清单**：磁条卡 + 3 行发放字段 + 备注示例。≥3 ✓
- **画面占用率**：≥70%。
- **入场语法**：卡落定 → 三行逐条淡入。
- **本屏判据自查**：C-01 ✓｜C-06 ✓｜C-10 ✓｜C-11 ✓｜C-14 ✓。字段名回 card-fields（超时时间/发放方式/发放备注，① 层过）。边界：只画"二维码"那格，另一渠道名属站外生态词不上屏。

## S6 · 结果屏（type: advance / ui: g09-result）

- **叙事职责**：结果·两边各看到什么。
- **本屏讲哪项设置**：不讲设置，讲设完的结果——顾客端：卡包看剩余次数、到店扫一下减一次、最后一次会提示；商家端：后台看核销节奏、谁来了几次还剩几次。
- **商家在想什么**：我设这些，客人和我到底各得到什么？
- **布局来源**：两栏白卡（顾客那边 / 你这边），复用 g09 冷色语言（非 g08 米纸金钉）。
- **口播句→区域**：句1-2→左栏（顾客）；句3→右栏（商家）。
- **信息全景清单**：主标题 + 两栏各 3 条。≥3 ✓
- **画面占用率**：≥70%。
- **入场语法**：主标题落定 → 两栏卡逐栏上浮 → 条目逐条淡入。
- **本屏判据自查**：C-01 ✓｜C-06 ✓｜C-09 ✓（两栏非底部结论条）｜C-10 ✓｜C-14 ✓。真值回 card-fields verifyPageKeyInfo/customerSidePhrases（"第X次·剩余N次可用·本次为该次卡最后一次""已用N次"）。
