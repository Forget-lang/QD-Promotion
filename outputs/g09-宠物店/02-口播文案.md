# g09 · 宠物店（洗护美容）· 片1 · 口播文案（第 3 步过程稿）

> 七屏：钩子 → 痛点 → 制券①（次数+有效期）→ 制券②（核销间隔·讲透）→ 私密发放 → 结果 → 收尾。

## S1 · 钩子（痛点压在磁条卡界面上，C-05 同格）

1. 宠物店做的是回头生意，可洗完这一次，人下回啥时候来，你心里没数。
2. 别靠记性——一张次卡，把"下次还来"变成客人自己看得见的次数。

- 首句 2 秒内"身份 + 痛点"（入口三件套③）：宠物店老板 / 洗完不回头。禁场景铺垫。

## S2 · 痛点（现在这么做 → 失效）

1. 现在多半靠记性，见着熟客提一句"该洗了"，人家转身就忘。
2. 客人洗完走了，你也不知道他隔多久该再来。
3. 等你想起来，猫狗早被别家接走了。

## S3 · 制券①（把一次变五次）

1. 先做一张洗护次卡，名字直接写"洗护五次卡"。
2. 每张包含次数填五次——洗澡两三周一次，五次刚好管住两三个月。
3. 有效期给到一百二十天，用得完，又不至于拖太久把卡睡死。
4. 每人限领一张，别让人一次囤一堆。

- 讲透点：次数不是拍脑袋，是按洗澡频率算出来的（第 2 句给原因）。

## S4 · 制券②（锁住到店节奏 · 本片最该讲透的机制）

1. 关键在这行——限制核销间隔，打开。
2. 间隔设十四天，就是每两星期才能用一次。
3. 为什么不能让他随便用？一周把五次用光，优惠一次就没了；间隔一卡，客人被匀成两三个月里常来常往。
4. 客人那边，卡上写着"间隔十四天可用一次"，他自己算得清下次该哪天来。

- 讲透点：核销间隔防的是"一次用光 / 长期不来"两头（第 3 句给反面后果），这是"不这么设会怎样"必须嘴上说的部分。

## S5 · 私密发放（只发给办卡的人）

1. 次卡跟优惠券不一样，不能公开领——只能一对一，私密发给办了这张卡的人。
2. 生成一个领取码，超时时间给宽一点，别把人家挡在外面。
3. 发放备注记上"张姐、金毛、洗护五次"，是谁的哪只宠物，一目了然。

- 边界口径：次卡本就仅私密发放（产品硬约束），正向说"只发给办卡的人"，不写负面句式。

## S6 · 结果（两边各看到什么）

1. 客人那边，打开卡包，还剩几次清清楚楚，到店扫一下减一次。
2. 用到最后一次，还会提他一句"这是最后一次了"。
3. 你这边，后台看得到核销节奏，谁来了几次、还剩几次，都摆在那。

- 真值：顾客端"已用 N 次 / 剩余次数"、核销页"第 X 次·剩余 N 次可用·本次为该次卡最后一次"、后台核销明细——均回 `spec/card-fields.json`。

## S7 · 收尾（主张 + 品牌落章）

1. 把"洗完这一次"，变成"接下来五次"——不用你记，卡替他记。
2. （品牌句只上屏不口播：券到卡包 · 实体店的电子券工具）
