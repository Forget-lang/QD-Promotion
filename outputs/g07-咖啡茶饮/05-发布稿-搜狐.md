# 咖啡店发券没人回头？问题出在"门槛"那一栏

> 21 字（含标点），在搜狐 20~30 字 SEO 口径内；核心搜索词「咖啡店发券」在前 12 字（SEO 硬口径）。发布后两个动作别漏：后台手动填 60~120 字摘要；去百度搜索资源平台「普通收录」提交本文 URL（可把收录周期从数周压到 48~72 小时）。

【头图：covers/头图-搜狐16x9.png】（16:9，左标题右小票条）

不少咖啡店老板都遇到过同一件事：券一撒出去，店里呼啦来一波人，可喝完就走，回头客没攒下几个。于是怀疑"发券有没有用"。

其实问题多半不在"要不要发券"，而在**这张券怎么设**——尤其是"消费门槛"那一栏填了什么。下面用一张满减券，把"拉新 + 复购"该设的四处讲透：怎么设、为什么这么设、设完之后顾客和你各自看到什么。数值都是示例，按你店的客单价调。

## 一、先认清：无门槛的券，越发越像在请客

门槛填 0 的券，等于"谁都能白拿一杯"。来的人冲着免费，喝完就走，你一分钱客单没提。这种券发得越多，越像在请客，不像在做生意。拉新的第一道分水岭，就是把门槛从 0 抬起来。

【配图：frames/S2.png】
图注：无门槛那张券——白拿一杯、喝完就走，客单没提上去。

## 二、第一处·消费门槛：0 还是客单价，是分水岭

在券到卡包里做一张满减券，"消费门槛"这一栏：

- 填 **0**：无门槛引流券，招来的是只占便宜、不消费的人；
- 设成**接近客单价**（比如"满 35 才能用"）：客人要用这张券，就得先消费到 35，等于把"来一趟"变成"来消费一次"。

这一栏，就是"拉新"还是"提客单"的分水岭。券名也建议直接写清场景，比如"到店咖啡券"（券名最多 18 字）；再配一个优惠金额（示例：减 8 元）、先做 200 张库存（库存上限 1 万）。

【配图：frames/S3.png】
图注：制券页把券面逐项摆出来——消费门槛是这一屏的核心决策。

## 三、第二处·有效期：选"领后 N 天"，把券逼成到店

有效期有两种选法：**固定档期**（某几天可用）和**自领取日起 N 天内有效**。拉新促到店，选后者更狠——比如设"领后 7 天"，客人领了就得尽快来，不然过期作废，不会领完压在包里睡大觉。固定档期适合压活动，那是另一种打法。

【配图：frames/S4.png】
图注：门槛填 0 与满 35 的对比——同样发券，来的人完全不同。

## 四、第三处·发放方式：要拉新，选公开领取

发放方式有"公开领取"和"私密发放"两种。这张券的目标是拉新，就选**公开领取**——谁看到都能领，把券存成海报贴门口，路人顺手就领了。"只发给指定的人"属于私密发放，是另一套召回玩法，这篇先不展开。

【配图：frames/S5.png】
图注：发放方式选公开领取，为的就是让陌生人也能领到。

## 五、第四处·核销后赠券：用一张、再得一张，锁住回头

最后一个开关，把"来一次的客人"变成"回头客"——**核销后赠券**。打开它，客人这次把券用掉，系统马上再给他一张同款、直接到账。他为了用掉第二张，多半还会再来一趟。顾客侧会显示"核销奖励·到店核销后可再得本券一张"。

【配图：frames/S6.png】
图注：开开关→客人用掉→自动再得一张，把一次客变回头客。

## 六、发出去之后：顾客侧、核销那一下、到期提醒

- **顾客那边**：领到的是一张"满 35 才能用"的券，用完又自动多一张。
- **你核销那一下**：扫顾客的码一验，这张能不能用、是不是别人转赠来的，页面上写得清清楚楚。
- **到期前**：券快过期那天，给顾客发一条提醒，让他再跑一趟。

## 小结

一张满减券，把该设的四处理清楚，拉新和复购一次办齐：

1. **门槛设对**——从 0 抬到客单价，来的人得消费；
2. **公开发出去**——要拉新就公开，海报贴门口谁看到都能领；
3. **限期领了就来**——有效期选领后 N 天，压到店；
4. **用完再送一张**——开核销后赠券，把一次客变回头客。
