# g07 · 咖啡茶饮 · 视觉母题一页（系列共享）

> SKILL 第 2 步产出。一套行业母题 = 一个系列共享；跨行业整套重做。本文件只定"咖啡茶饮这套画面长什么样、为什么和教培那条不一样"，做屏前先看 `outputs/bench/` 四张锚图定质感。

## 0. 一句话母题

**「一张刚打印出来的点单小票」**——咖啡茶饮店最自然的物理载体是收银台吐出来的**热敏点单小票**：券的每一项设置，就像在小票上一行一行打印出来。整片围绕"小票 + 咖啡渍圈 + 拿铁纸感"长。

## 1. 信息载体与动效语法

| 维度 | 咖啡茶饮（本片） | 教培那条（对照，不复用） |
|---|---|---|
| 物理载体 | 热敏点单小票（上下撕齿、行行打印） | 回执单卡（左缘打孔齿） |
| 招牌记号 | **咖啡渍圈**（accent 色细环，落在关键词后） | 盖章对勾（红色印章） |
| 入场语法 | 打印出票：行自上而下落 + 擦入；卡片顶部下长 | 递交回执：右入 + 微旋落定 |
| 强调手法 | 咖啡渍圈 + 行底 accent 下划线 | 荧光抹带 + 盖章对勾 |

## 2. 栅格与安全区（1080×1920）

- 左右安全边距 68–72；内容主区 `left:72 right:72`。
- 顶栏/标题带：y ≈ 120–270。合规标注（示例值）走**顶部面包屑行尾**（C-11，不放屏底）。
- 卡片主区：y ≈ 300–1180。
- 底部字幕道：距底 60（`Subtitle` 组件），屏底只留字幕，不另起页脚小字。

## 3. 标题承载（菜单板风）

- 主标题：方圆体（FONT_ROUND）大字，espresso 深咖墨色，关键词后压一个 accent 咖啡渍圈。
- 副行/面包屑：普惠体灰咖色，行尾带「数值为示例」。
- 右上角「示例」小胶囊（accent 底白字）——承担合规标注义务。

## 4. 容器语言

- 小票卡：latte 纸白底 + 细咖啡描边 + 暖投影 + **上下撕齿边**（repeating-linear-gradient 三角齿）。
- 行分隔：咖啡色虚线。
- 结论/提示卡：白底 + accent 实线描边 + 左侧 accent 色条。

## 5. 色彩与质感配方（caramel 主题，系列内各片沿用）

- 主色 accent = `#B5502A`（陶土咖啡红，区别于教培的暖橙 #FF7043）。
- 深墨 espresso = `#2B1C12`；暖棕 brown = `#5A3E2B`；灰咖 muted = `#8A6F5A`；浅咖 faint = `#B49A80`。
- 纸白 latte = `#FFFDF8`；奶油卡底 cream = `#F1E4CE`。
- 全片氛围层（VTemplate 统一挂）：Grain 颗粒 + Vignette 暗角 + 暖光斑漂移 + 咖啡渍水印呼吸（底层持续微动）。
