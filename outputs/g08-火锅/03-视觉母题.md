## 一、换语言五轴自证（对照 g07）

| 轴 | g07 咖啡茶饮（上一条） | g08 火锅（本片） | 为何不同 |
|---|---|---|---|
| **栅格** | 菜单板式：上眉标题 + 下分行列表，纵向单列滚动感，内容偏中上 | 叫号单式：顶部粗色条标题+编号 + 中部三列对照/大数字 + 底部曲线装饰，横向呼吸感强，内容居中 | 菜单是"读下去"的纵向叙事；叫号单是"拿起来看"的横向信息块，三列对照对应三种有效期选择 |
| **容器形状** | 无外框卡片，菜单板直接铺内容，点线分隔行 | 叫号单卡片（顶部粗色条 + 白色主体 + 底部波浪齿边）+ 三列并排小卡（每列一张小叫号单） | 菜单没有"卡"的概念，就是一块板；叫号单是一张张独立的票，三列=三张票排开 |
| **标题承载** | 眉标题（金色小字+杯图标）+ 得意黑大标题两行 + 金下划线 + 副标题 | 叫号单顶部色条：左侧大号编号「No.01」+ 右侧档期标签 + 下方粗黑体主标题，标题压在色条上 | 菜单标题是"招牌"感（悬在上方）；叫号单标题是"票头"感（印在票上） |
| **入场语法** | 逐行淡起 + 上移（菜单行逐条呈现） | 曲线从左向右爬升点亮节点 + 卡片从下往上弹入（叫号单递出感）+ 数字滚动计数 | 菜单是"读下去"的顺序入场；叫号单是"递到手里"的弹入感，曲线是时间的流动 |
| **节奏密度** | buttery（黄油般顺滑，偏慢偏柔） | snappy（干脆利落，急促有力） | 咖啡是慢慢品的节奏；火锅叫号是干脆的、节日是紧张的 |

> 五轴中栅格/容器/标题/入场/节奏 五个维度全部不同，不是换皮。

## 二、色彩与质感配方

- **色板声明**：`warm-orange`（暖色系分类）
- **实际配色**（深底 + 火锅红 + 金，节日红火感）：
  - 主背景：`#2a1210`（深红褐色，比 g07 的咖啡更深更红）
  - 次背景：`#3a1a16`
  - 主色/强调：`#E53935`（火锅红）
  - 金色：`#FFB300`（节日金）
  - 正文：`#FFE0B2`（暖米色，深底上可读）
  - 弱化：`#D7A89A`
  - 卡片底：`#FFF8F0`（暖白，叫号单纸感）
  - 卡片墨：`#2a1210`（深褐红，卡片上的字）
- **质感锚**：anchor-mech（机制对比）+ anchor-table（对照表，做法参照、骨架重做）
- **背景氛围**：底部升腾的蒸汽/热气波纹（抽象曲线，不是具象蒸汽）+ 右上角暖光晕

## 三、母题零件

1. **叫号单卡片**（TicketCard）：顶部红色色条 + 大号金色编号 + 暖白纸体 + 底部客流曲线区 + 底部大波浪齿边 + 左右两侧票孔；色条左侧大号编号「01」、右侧档期胶囊标签
2. **客流曲线**（FlowCurve）：SVG 贝塞尔曲线 + 渐变填充区 + 数据点标记；三型=节日高峰型（中间高）/ 逐日递减型（左高右低）/ 双峰接力型（两高峰）
3. **标题承载**：叫号单票头式——上半部红色色条（左侧标签·右侧示例标注）+ 下半部深底毛玻璃区（主标题+副标题）
4. **三列对照**（ThreeColCompare）：三张叫号单小卡横向并排等高；推荐项红底白字高亮，两侧卡白底深字对照
5. **波浪分隔线**（WaveDivider）：波浪形 SVG 线条，结论条顶部用反向波浪
6. **数据徽章**：两列并排小卡片（紧迫感/灵活度），星级量化对比

## 四、动效语法

- **入场主语法**：卡片从底部弹入（spring，overshoot 一点点）—— 叫号单从窗口递出来的感觉
- **数据强调**：曲线节点随节拍逐个点亮 + 数字滚动到目标值
- **指向方式**：讲到哪一列，哪一列的卡片放大 + 描边变粗 + 其余列降 opacity 到 0.72
- **转场**：`reveal`（有机曲边扫过，曲线形状呼应火锅沸腾/蒸汽）
- **底层微动**：背景光晕缓慢呼吸 + 底部蒸汽波纹缓慢升腾漂移
