## 四、写法上定的四条（不占屏，落进每句）

这四条是自检用的问句，不是配额——每屏写完自己念一遍，念不通就重写。

1. **位置**：观众能不能从这句话知道"现在在哪个页面"。（首页 / 选券种 / 制券页第几段 / 券详情 / 家长手机）
2. **动作**：动词用产品自己的词——点、摁、打开、选、填、扫、输。不说"配置""设置一下"。
3. **结果**：这个动作下去出什么，必须说一句（标题变了、开关开了、链接失效了、记录留了）。
4. **理由**：给判断就连着给后果。「发放方式选公开领取」后面必须跟"因为创建完改不了"；「限领总量填 1 张」后面必须跟"一个人不能领三张去送人"。只给结论词的句子一律重写。

另两条口径：场景细节全部**填进真实字段的值里**（券名、兑换内容、使用须知那三样就是托管场景本身），不再单开痛点屏；数值全标"示例"，教培类不碰升学 / 效果 / 师资承诺（口径见 `spec/redlines.json` 的强监管行业表）。

## 五、画面真实性 vs 红线：四处要你点头

产品的原话里有四处是平台禁词（清单以 `spec/redlines.json` 机检层为准，本文不复述禁词本体）。**这几处是"画得跟真界面不一样"的唯一原因**，我不擅自定：

1. **发放面板只画两格**。真实面板一排里挂着多条渠道，其中数条的渠道名属禁词类。计划：只画「二维码」「海报」两格，其余不出现，口播也只念这两条。**代价**：观众以为只有两种发法。备选：画满各格但把禁词那几条的文字糊掉——我倾向不糊，糊了像有隐情。
2. **海报页顶部说明卡整块不上屏**。那块"使用说明"原话第二行含禁词。计划：不画说明卡，只画海报成品 +「保存海报」；口播改说"打印出来贴校门口"。
3. **制券页核销限制组里那颗防截屏开关跳过不念、不画**（2026-08-17 已定口径：该机制的名称本身在禁词表内）。S4/S5 的字段序列里直接不出现它，页面上不留空位。
4. **「到期提醒」这一行不引用产品原描述**（原话含禁词），改成 S5 第②句那种说法：只说"订阅过才收得到"，不承诺必达。

还有第 5 处不算冲突但要说：**"打开这款产品"是全片唯一的入口说法**。搜索导流类话术三平台都禁，所以片子里不能出现"去哪搜、怎么找到它"，导流只有一个合法位置——账号资料位。这决定了片子只能教会"怎么用"，教不了"怎么装"。

## 六、时长与砍法

上表合计 **11 屏 / 195 秒设计时长**（转场重叠后成片约 191 秒），屏均语速实测 **4.47 字/秒**，比上一版（147 秒）长 44 秒，长在全片每条口播要把"在哪点、摁完出什么、为什么这么填"说完。在 200 秒硬上限内，但确实超了"复杂行业 120–150 秒"的参考档。最紧的两屏是 S11（5.79）与 S5（5.04），算帧表时这两屏时长优先上调；逐句峰值仍按 ≤6 字/秒把关。

要压回 150 秒，只有一条路是**砍环节不砍句**（砍句就是把直白话再提炼成行话，那正是上一版失利的原因）：

- **砍法一（≈184s）**：S5 去掉「指定手机号可领取」「允许转赠」两句，只留 使用须知 + 到期提醒 + 填写手机号。这两个开关挪到下一片专讲老带新与定向回访。
- **砍法二（≈185s）**：S11 的第二张满减券整段挪走，本片收在 S10 那笔账上——一条片只教完一张券的闭环。
- **砍法三（≈152s，真回参考档）**：在砍法一之上，把 S8「家长拿到」、S9「到店核掉」、S10「看到数」三环压成两屏。代价：核销那屏一次摆 8 个真实字段，是全片最容易看糊的一屏，我不建议。
- 我推荐 **砍法一**：第二张券是这块生意真正的钱口（试完就得谈费用），必须留在片里；老带新与定向名单对 0 接触观众是"第二个月才用得上"的东西，塞进第一片只会挤掉他记住主链的力气。
