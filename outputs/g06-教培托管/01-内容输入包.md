# g06 教培托管 · 内容输入包

> 产出日期：2026-08-30 ｜ 流程：SKILL 七步法 ｜ 选题来源：10 候选场景用户圈选 #5
> 监管档位：教培类（逐条过 redlines.rules.industry_specific）

## 一、选型与窗口

- **行业**：教培 · 托管（小学生放学后接送 + 餐食 + 作业看护）
- **时令窗口**：9 月开学季。决策高峰 = 开学前一周 ~ 开学后两周，发布从紧
- **数据说明**：无抖音后台数据（G03/G04 未提供），本片选型按「靠猜」标注，发布后 24h/7d 数据是下一片的输入

## 二、调研三问（落到时刻）

1. **老板最头疼的时刻**：开学季咨询集中，但「来试一天」的邀约只落在口头和传单上——家长不来、手机号没留下，月底想回访找不到人。
2. **现在怎么做**：校门口发传单 + 口头「免费试一天」+ 本子记电话。反常识切入：不卷传单印得更花，把口头试用升级成一张正经凭证——券躺在家长卡包里、有有效期、到期前还能再提醒一次（送达是产品支持的能力，2026-08-30 用户口径；措辞只说「提醒」，不带平台名）。
3. **功能解法**：兑换券（试用做成券）+ 填写手机号 + 到期提醒 + 扫码核销/渠道统计 + 私密发放满减券 + 转赠奖励老带新 + 指定手机号可领取定向唤醒。

## 三、玩法一句话

把校门口「免费试用」的口头承诺做成一张体验兑换券：家长扫码领券填手机号 → 到期前提醒再推一次 → 试用当天扫码核销 → 1对1私密发月费满减券锁单 → 开放转赠让「约同学一起试」老带新。

### 券 C · 定向唤醒用法（复用券 B 或另制）

制券页「领券顾客信息」里打开**指定手机号可领取**：面板原话「每行一个手机号，最多 500 个」，重复号码自动跳过，仅输入的手机号可领取此券——定向回访有据可依（facts.coupon.mobileWhitelist ✓）。

## 五、信息单元清单（8 个，≥6 ✓）

1. 痛点：口头试用不来、传单断线、手机号没留
2. 思路：试用做成一张兑换券（有凭证才有下文）
3. 体验券字段：兑换内容（≤10 字）+ 使用须知写明细 / 14 天有效 / 工作日时段 / 填写手机号 / 到期提醒
4. 领券核销流程：校门口海报码 → 进卡包 → 到店扫码核销
5. 渠道统计：哪个校门口领得多、哪张海报有效
6. 转化：试用后私密 1对1 发月费满减券（领后链接失效）
7. 老带新：转赠 + 转赠奖励（约同学一起试）
8. 唤醒：「指定手机号可领取」定向发券给咨询未报名家长
