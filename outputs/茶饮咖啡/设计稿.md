## 三、视频分镜详规（9:16 · 67s · 无声版本体）

> 关键字 = 画面大字标题（非字幕）；口播 = 后合成语音用。**配色值见 §四**。

### 五维风格配置（写入 `data/g02.ts` style）
```
palette: 'mint-cool'   motion: 'buttery'   typography: 'clean'
transition: 'wipe'     hookStyle: 'number'
```

### S1 · Hook（钩子）· 0–5s

| 项 | 内容 |
|---|---|
| 口播 | 喝完就走，你只赚了这一杯的钱。 |
| 画面 | 深底（bgDark）大字标题 + 右上咖啡杯浮动装饰（数字「10」由标题内「十次」承载） |
| 关键字大字 | **「一杯的钱，先收住十次的客」** |
| 布局 | 标题居中，大数字「10」由标题「十次」承载，咖啡杯图标置于右上装饰位 |
| 配色 | 背景 derived from mint-cool bgDark；标题纸白；数字/图标 accent 绿 #07C160 |
| 动画 | 标题 wipe 擦入 + 数字 spring 弹入（buttery 缓动）；0.5s 内标题先出，强钩子 |
| 声画同步 | 口播「十次」时数字 10 放大强调 |

### S2 · Pain（痛点 · 红绿对比）· 5–15s

| 项 | 内容 |
|---|---|
| 口播 | 想让客人回头，你最先想到降价。可价格越打越低，利润先被自己砍没了。问题不在价格，在客人来几次。 |
| 画面 | 左右对比面板：左=「打价格战」旧方式（红），右=「锁次数」新思路（绿） |
| 关键字大字 | **「降价伤利润」**（痛点屏） |
| 布局 | 左卡红底白字列旧方式（拼低价/等折扣/利润越砍越薄）；右卡绿底白字「锁次数，锁住回头客」 |
| 配色 | 左卡 #EF5350 红；右卡 #07C160 绿；背景 paper 白 |
| 动画 | 左卡先入（红），右卡后入（绿）；中间「✗ vs ✓」切换强调 |
| 声画同步 | 口播「降价」时左卡强调，「锁次数」时右卡强调 |

### S3 · Solution（解法 · 次卡锁客）· 15–27s

| 项 | 内容 |
|---|---|
| 口播 | 用一张次卡，把今天这一杯，变成这周、这月都会回来的一杯。剩几次，卡包里一目了然。 |
| 画面 | 三张价值卡（stagger 逐条弹出）：次数看得见 / 核销扫码即扣 / 喝不完能转赠 |
| 关键字大字 | **「次卡锁客」** |
| 布局 | 标题顶置，三卡纵排（每卡左侧 SVG 图标 + 右侧标题小字 + 一句说明） |
| 配色 | 卡底色 paper；图标分别 绿 #07C160 / 青 #26C6DA / 橙 #FF7043；文字 ink |
| 动画 | 三卡 stagger 依次上滑（buttery）；标题 wipe 入 |
| 声画同步 | 口播每个价值点对应卡弹出 |

### S4 · Flow（流程图 · 转赠带新）· 27–37s

| 项 | 内容 |
|---|---|
| 口播 | 次卡还能转赠。有人喝不完，转给朋友，朋友来核销，一个新客就这么自然进店了。 |
| 画面 | 横向流程图 4 节点：领次卡 → 转赠朋友 → 朋友到店核销 → 新客进池 |
| 关键字大字 | **「转赠 = 老客帮你带新客」** |
| 布局 | 4 节点卡 + 节点间箭头（wipe 连线游走）；底部 footnote 金句 |
| 配色 | 节点卡 paper；箭头 accent 绿 #07C160；footnote 橙 #FF7043 |
| 动画 | 节点依次 wipe 入，箭头擦除式连线，引导视线 |
| 声画同步 | 口播「转赠」时第 2 节点强调，「新客」时第 4 节点强调 |

### S5 · Grid（卡片网格 · 两把火）· 37–47s

| 项 | 内容 |
|---|---|
| 口播 | 再配两张券：随机金额券，让群里热起来；套餐券，给新品一个低门槛的入口。 |
| 画面 | 2×2 卡片网格：随机金额券（热群）/ 套餐券（推新品）/ 定时开抢（增紧迫）/ 闲时时段（补空桌） |
| 关键字大字 | **「随机券热群 · 套餐券推新」** |
| 布局 | 2×2 网格卡，每卡图标 + 标题 + 一句说明 |
| 配色 | 四卡底色 paper、浅 d 底间隔；图标 橙 #FF7043 / 青 #26C6DA / 绿 #07C160 / 绿 |
| 动画 | 四卡 stagger 淡入上浮（buttery），对角错峰 |
| 声画同步 | 口播「随机券」时左上卡强调，「套餐券」时右上卡强调 |

### S6 · Panel（数据面板 · 用了之后）· 47–59s

| 项 | 内容 |
|---|---|
| 口播 | 回头客多了，空桌少了，复购自然就来了。 |
| 画面 | 三枚数据指标卡：回头客 ↑ / 空桌 ↓ / 复购 ↑（无趋势图，指标卡+方向箭头） |
| 关键字大字 | **「复购回来了」** |
| 布局 | 三卡横排，每卡：图标 + 指标名 + 大字方向箭头（↑/↓）+ 一句说明 |
| 配色 | 卡底色 paper；↑ 绿 #07C160、↓ 橙 #FF7043；文字 ink |
| 动画 | 三卡 stagger 弹出，数字/箭头 direction 滚动强调 |
| 声画同步 | 口播「回头客」「空桌」「复购」逐卡强调 |

### S7 · CTA（收尾）· 59–67s

| 项 | 内容 |
|---|---|
| 口播 | 券到卡包，再小的门店也可以制作电子券。 |
| 画面 | accent 绿整屏 + 产品名居中 + 一句价值句（轻署名，非水印/角标） |
| 关键字大字 | **「券到卡包」** |
| 布局 | 标题居中竖排，副句「再小的门店也可以制作电子券」；四角留白 |
| 配色 | 背景 accent 绿 #07C160；标题纸白；副句纸白略降透明度 |
| 动画 | 标题 wipe 入后整屏停留 ≥5s（屏幕停留保完播） |
| 声画同步 | 口播「券到卡包」时标题弹出 |

## 六、分平台适配 + 验收清单

| 平台 | 载体 | CTA |
|---|---|---|
| 抖音 | 9:16 视频 | 绝口不提微信/小程序/搜索；结尾轻署「券到卡包」，不硬推关注/收藏 |
| 小红书 | 9:16 视频 | 同抖音；正文不出现搜索/扫码导流 |
| 搜狐 | 图文文章 | 文章绝口不提微信/小程序/搜索，导流仅限账号资料位 |

**无声版画面验收清单（人确认项）**：
- [ ] 布局：S1 钩子是否前 3s 静音可懂留人
- [ ] 配色：薄荷统一、绿=解法/红=痛点语义清晰
- [ ] 动画：buttery 柔和、不跳不卡；转场 wipe 干净
- [ ] 节奏：67s 是否一次讲透、无「下个视频」硬切
- [ ] 封面与首帧连贯：S1 与封面 hero 视觉同语言
- [ ] 关键字层级：每屏 1 个核心词、大字可读、无极限词

**边界自检（红线）**：
- [ ] 无「微信/小程序/搜索」导流、无促销型「免费」、无极限词、无「审核」
- [ ] 数值均在校验内（次卡 10 次、随机券区间整数、核销间隔每天 1 次）
- [ ] 次卡仅私密发放、不卖卡、产品不参与收款；套餐券预约仅文字
- [ ] 改动后跑 `node scripts/check-redlines.mjs`，code 层零命中
