## 一、视觉基线（pipeline §2.1.0 六项，先于分镜表）

> **本片 UI 语言 = 「画室作品墙」**：一面贴着孩子画作、便签、表单和票券的墙。纸片用胶带/图钉/回形针固定，标题像美术馆展签，重点用蜡笔划线，进度用三原色点。**全片不出现"顶部主题色块 + 白圆角卡 + 左边色条"这套既有语言。**

| 基线项 | 上一条 G04 是什么 | **G05 本片是什么** | 差异 |
|---|---|---|---|
| ① 栅格与内容区 | 标题条 top 120 全宽居中；主体从 y:240 起整块铺开；结论条 bottom 280 | 展签卡左上 `x:80, y:150-272`（不居中、不通栏）；主体区 `y:330-1560` **不对称两栏 / 错落纸片**；片尾提示条固定在 `y:1568-1672`；字幕区不变 | 通栏居中 → 左置展签 + 非对称主体 |
| ② 标题系统 | 主题色圆角色块 + 白字居中 64-72px | **展览标签卡**：米白纸牌 `300-460×112`，2px 铅笔灰描边 + 一枚图钉 + 标题 56px 深墨左对齐 + 上方 22px 编号行（`01 / 09` 式）| 色块白字 → 纸牌+图钉+编号 |
| ③ 容器语言 | 白卡 radius 32-36 + `elevation(3)` + 左 10px 色条 | **纸片**：`#FBF7EF` / 白，radius 10，**无彩色左边框**，2px `rgba(0,0,0,0.10)` 铅笔描边 + 轻投影 `0 6px 18px rgba(20,40,70,0.10)` + **斜置胶带条**（45°、120×28、`rgba(244,196,48,0.55)`）压在纸角；纸片带 `±1.5~4°` 微旋 | 色条卡 → 纸片+胶带+微旋 |
| ④ 装饰母题 | 大引号 + 磁条卡光晕 + 虚线分区 | **蜡笔笔触下划线**（SVG 抖动 path，8-10px 粗，圆头，划过式 draw-on）+ **三原色点导航**（右下 `y:1620`，红/黄/蓝三枚 14px 圆点，当前幕实心、其余描边）贯穿全片 ≥7 屏 | 全片独有图形语言 |
| ⑤ 色彩与质感 | berry-purple + 粉雾网格底 + 深字 | deep-blue 骨架（`#1E88E5`/`#1565C0`）+ **纸米白 `#FBF7EF`** + **三原色点缀**：蜡笔红 `#E4572E` / 蜡笔黄 `#F4C430` / 蜡笔蓝 `#1E88E5` + 铅笔灰 `#6B6B6B`；底图 BG-ABS-002 冰蓝浅底（`darkText:true`、`bgBlur:0`）；阴影统一冷墨色不做暖影 | 与 G04 不同色系不同底图；与 G02 同底图但整墙语言全新（G02 是白卡+图标） |
| ⑥ 动效性格 | snappy + slide；标题逐字 + 卡片依次弹入 | bouncy + zoom；**纸片从上方落下并旋正**（translateY −60→0 + rotate −4°→0，`spring`），随后**胶带啪贴**（ScaleIn 0.6→1，delay +6）；错峰顺序固定为「展签 → 主纸片 → 副元素 → 蜡笔线划出 → 色点跳转」 | 入场轴向与节奏都换 |

**共享层复用边界**：只复用原子件——`Ico`、`FadeInUp`/`ScaleIn`/`Pulse`、`elevation`、`CharReveal`、palette、字体、`VTemplate`（转场/氛围/字幕/音频）。**九个屏结构全部新建**，放 `video/src/videos/g05/`，屏上写 `ui:'g05-xxx'`；`scenes/` 的共享组件本片一律不直接调用。

## 三、九屏规格（逐屏：结构 → 几何 → 数据 → 时序）

> 通用约定：所有纸片 `boxSizing:'border-box'`；左右内容边界 `x:80-1000`（安全区 ≥80px）；文字压浅底一律 `p.ink` / 深墨，压色块用 `accentDark`；`motion=style.motion` 贯穿；转场由 TransitionSeries 处理不逐屏写；字幕由 `SceneRenderer` 统一挂 `Subtitle`，屏组件不得自画字幕区（y:1757-1860 留给它）。
> **结构档位（已沉淀进 `craft.md` §8，勿再自造名）**：S1=L-14 速写纸侧注型 ｜ S2=L-15 便签墙型 ｜ S3=L-16 分叉路径型 ｜ S4=L-17 画架阶梯型 ｜ S5=L-18 表单纸型 ｜ S6=L-19 票券并排型 ｜ S7=L-20 名册漏斗型 ｜ S8=L-21 调色盘引线型 ｜ S9=L-12 收尾品牌型（走 CTA 例外登记）。
> 每屏数据载荷写在 `scene.payload`，本片 payload 类型集中定义在 `video/src/videos/g05/types.ts`（组件内用 `pick<T>(scene, 'S?')` 取，缺失直接抛错不静默画空屏）。
