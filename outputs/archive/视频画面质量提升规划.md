## 一、问题总览

g02 v2.0 审查发现 **10 类问题**，归为四大方向：

| 方向 | 问题数 | 核心问题 |
|---|---|---|
| **A. 内容准确性** | 4 | 产品功能混淆、自检表未同步、口播与画面不匹配 |
| **B. 排版与视觉** | 4 | 内容分散全屏、卡片无 padding、背景无质感、缺少装饰层 |
| **C. 字幕同步** | 1 | 字幕是口播摘要而非逐字同步 |
| **D. 资源利用** | 1 | 模板图/插画/挂件未纳入资源库，AI 设计稿阶段没有选图流程 |

### A2. 自检表未同步内容迭代（g02 重构时注意）

**问题**：S5 从"逻辑屏"改为"适用场景判断屏"，但自检表仍写"3 个底层逻辑"。

**规则**：设计稿任何屏的内容/类型变更后，必须同步更新 §5.8.1 内容深度自检表。

**规则**：写口播时必须对照画面布局逐条检查——口播提到的数量/结构，画面必须能体现。

## 三、B 方向：排版与视觉（本次规划重点）

### B1. 核心内容集中原则（硬底线）

**问题**：g02 S2 画面标题在顶部、卡片在正中、字幕在底部，三者之间大片空白，观众需要上下扫视。

**规则**（写进 13 号 §2 布局规则）：

> **核心内容（标题 + 卡片/图标/流程等）必须集中在 y:200-1100 区域内。**
> - 标题距顶部 ≥ 200px（避开平台 UI + 给呼吸空间）
> - 内容区底部距字幕区（y:1760）≥ 660px（下方留白让画面不压抑）
> - 标题与下方内容间距 40-60px（是一个整体，不能割裂）
> - 多卡片之间间距 ≥ 卡片高度的 20%
> - 卡片内 padding ≥ 画面宽度的 4%（约 43px）

这条不是限制风格/配色/创意，只约束**垂直分布**——防止内容分散到全屏。

### B2. 背景模板图（质感来源）

**问题**：g02 用的模糊照片背景灰蒙蒙的，没有质感。

**方案**：用创可贴的抽象背景模板图（光斑、渐变色块、纹理）替代模糊照片。

**放入现有目录**：
```
背景素材/
├── 古朴风/              # 已有（15 张）
├── 小红书风/            # 已有（20 张）
├── 抽象模板/            # 新增：光斑/渐变色块/纹理（无文字）
│   ├── 暖色系/          # 暖棕/焦糖/奶白（茶饮咖啡/美业等）
│   ├── 冷色系/          # 淡蓝/白/浅灰（教育/科技等）
│   └── 通用/            # 不限行业的抽象背景
└── gXX-行业/            # 已有：行业专属背景
```

### B3. 挂件/贴纸/插画（装饰层）

**问题**：g02 画面只有前景（文字/卡片）+ 背景（模糊照片），缺中景层。

**方案**：通过挂件/贴纸/插画补充中景层——标题下方的装饰线/色块、卡片旁边的点缀插画、角标/标签增加信息层次。

**放入现有目录**：
```
插图库/
├── （当前为空）
├── 挂件贴纸/            # 新增：角标/标签/装饰挂件（PNG 透明底）
│   ├── 文字标签/        # "进阶玩法""必看""免费"等
│   └── 装饰挂件/        # 星星、箭头、光晕、手绘线条等
└── 物体插画/            # 新增：行业相关物体插画（PNG 透明底）
    ├── 茶饮咖啡/        # 咖啡杯、茶叶、奶茶等
    ├── 美业/            # 剪刀、镜子、化妆品等
    └── 通用/            # 钱包、手机、笑脸等跨行业通用
```

### B4. 排版参照库（让 AI 学好的排版）

**方案**：在 09 号最佳实践库新增「排版参照库」章节。

**内容**：
- 收集好的排版参考图（创可贴找的 + 自有视频截图）
- 每张图配 AI 可读分析：适用场景、好在哪、可借鉴手法
- 设计稿模板加一条：写画面布局时，从参照库选一个匹配的，说明借鉴了什么

**已有参照图**（用户提供）：
1. 重启人生计划 → 编号列表型（标题紧凑 + 红色编号分层）
2. 求求了暑期实习 → 手写风大字 + 荧光笔高亮
3. CKT 价格表 → 多层信息分区（卡片+图标+色块）
4. 超级学霸 → 撕纸效果卡片 + 手绘插图（三层分明）
5. 保险投保思路 → 括号分组 + 星级标注 + 高亮关键词
6. 准初一衔接 → 大边框包裹 + 标题区/内容区明确分区
7. 自有视频-很多人以为 → 大色块光斑背景 + 清单小卡片 + 高亮关键词
8. 自有视频-这些券型都支持 → 彩色药丸徽章网格排列

## 五、D 方向：资源库升级流程（基于现有目录）

### D1. 11 号文档升级

在现有 11 号文档中新增/修改以下内容：

**① §1.1 取用规则新增"设计稿阶段查索引"流程**：

> AI 写设计稿时，逐屏查资源索引（§9）：
> 1. 背景层 → 先查 `背景素材/` 索引，有匹配的标注编号直接使用
> 2. 装饰层 → 先查 `插图库/` 索引，有匹配的标注编号直接使用
> 3. 都没有 → 在设计稿末尾输出「找图需求单」（见 §9.3）
> 4. 用户找图下载 → 放入对应目录 → AI 更新索引

**② §1 素材库结构表新增子目录**：

| 目录 | 角色 | 内容 | 维护方 |

| `背景素材/抽象模板/` | 视频背景模板图 | 光斑/渐变色块/纹理（无文字），按色系分子目录 | 人（创可贴找） |

### 画面布局规则

## 七、自检清单（g02 重构后逐项过）

### 内容准确性
- [ ] 次卡转赠链路不含转赠奖励（14 §2.1）
- [ ] 自检表 §5.8.1 每屏描述与实际画面/口播一致
- [ ] 口播提到的数量/结构，画面能体现
- [ ] 封面文档引用的口播与视频设计稿一致

### 排版与视觉
- [ ] 核心内容在 y:200-1100 内，不分散到全屏
- [ ] 标题与内容间距 40-60px，不割裂
- [ ] 卡片内 padding ≥ 43px
- [ ] 多卡片间距 ≥ 卡片高度 20%
- [ ] 背景用模板图（有质感），不是模糊照片
- [ ] 有装饰层（挂件/插画/色块），不只前景+背景两层

### 字幕
- [ ] 字幕 = 口播逐字稿，不做摘要
- [ ] 每行 10-20 字，按语义断句
- [ ] 时间点由 TTS 实测时长决定

### 资源利用
- [ ] 设计稿标注了使用的资源编号（11 §9）
- [ ] 资源库没有的输出找图需求单
- [ ] 选了排版参照并说明借鉴了什么（09 §排版参照库）
