# 03 · 接口清单

> 小程序前端实际调用的后端 API 清单（按业务域分组），来源于代码分析。用途：技术文档撰写、接口联调核对、深度事实核查。
> 通用约定：所有请求头带 `Authorization`（token）、`Merchant-Id`（已选商户）、`Version`；参数附 `sign`（MD5 签名）与 `timestamp`。响应 `code=0` 成功；`1000` token 过期回卡包；`1001` 员工退出门店回商户中心；`1009` 商户未认证跳认证页；`2000` 资源已删除。
