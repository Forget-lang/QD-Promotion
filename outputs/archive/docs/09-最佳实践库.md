## 二、验证过的视频结构

### 结构 A：痛点 → 解法 → 裂变 → CTA（时间线叙事型）

**结构**：S1 场景钩子 → S2 提出问题 → S3 给出解法 → S4 升级玩法（裂变/复购） → S5 CTA
**验证案例**：G02 茶饮咖啡 v2
**特点**：
- 用具体场景（下午3点咖啡店）带入，不是空泛讲道理
- 问题 → 解法 → 升级，层层递进，节奏感强
- 第 4 屏放"高级玩法"（转赠/核销奖励），让观众觉得"还能这样？"
- CTA 走品牌署名路线，不硬推

**适用行业**：全行业，尤其适合有明显"淡旺季/闲忙时段"的行业

### 5.1 高密度不杂乱 · 实现手法

> 核心目标：单位时间内让商家看到尽可能多的价值点，但视觉上不拥挤、不混乱。

**6 个关键手法**：

1. **统一视觉语言** —— 全片同色系、同圆角、同字体风格。元素再多，风格统一就不乱
2. **清晰视觉层级** —— 大标题 / 中标题 / 小字 / 说明，字号差拉开 2 倍以上。眼睛知道先看哪
3. **网格对齐** —— 所有元素对齐到隐形网格，等距分布。歪歪扭扭才会显得乱
4. **重复元素样式** —— 图标、标签、对勾、卡片，同款样式重复出现。形成节奏就不乱
5. **分组明确** —— 相关信息放在一起，用卡片/色块/线条区隔。大脑自动分组，不觉得满
6. **留白呼吸** —— 元素之间有足够间距，不是挤在一起的。留白越多，越显高级

**反例**：
- 一屏只有一句话，虽然干净但信息效率太低
- 什么都想放大，结果没有重点，看起来反而乱
- 颜色超过 3 种主色，视觉噪音大

### 5.2 视觉设计红线 · 建议 · 创意（三层弹性标准）

> **定位**：本标准是视频画面的"审美底线 + 方向指引 + 创意空间"。红线必须遵守，建议择优使用，创意自由发挥。
> **依据**：从创可贴设计参考图（7 张）+ 自有视频迭代经验 + 用户历次反馈中提炼。
> **更新规则**：每次出片后根据验证结果更新红线/建议，活标准。

#### 🔴 红线（不遵守就不及格，必须返工）

| 编号 | 红线 | 说明 | 反例 |
|---|---|---|---|
| V-R01 | **标题必须醒目** | 标题是全屏最大元素之一，字号 ≥ 56px，颜色深色或主色（与背景有强对比），位置要么居中要么左上但必须有存在感，不能淡、小、飘在角落看不清 | 标题白色半透明放在左上角，和背景融为一体 |
| V-R02 | **内容填满上 2/3** | 标题 + 主体内容必须集中在画面上 2/3 区域（top: 120px 到 y: 1400px），不能 3 张小卡片只占中间 40%、上下全空 | 3 张小方块挤在画面中央一条，上下各空 1/3 |
| V-R03 | **一屏一个视觉焦点** | 每屏必须有且只有一个主焦点（大数字/大标题/大图标/大卡片），所有元素围绕焦点排布，不能所有元素一样大、没有主次 | 3 张卡片尺寸完全一样，眼睛不知道先看哪 |
| V-R04 | **文字对比度足够** | 任何文字在背景上必须清晰可读，对比度 ≥ 4.5:1。模糊/看不清的文字就是失败 | 浅绿字放在浅蓝色背景上，看不清 |
| V-R05 | **相邻屏布局不重复** | 连续两屏不能用同一种布局模式（比如不能连续两屏都是"3 张卡片纵向列表"），必须有节奏感变化 | S2 卡片列表 → S3 卡片列表 → S5 卡片列表，审美疲劳 |
| V-R06 | **安全区内排版** | 内容在安全区内：顶部 ≥ 120px，底部 ≥ 160px（字幕区），左右 ≥ 60px | 内容贴边、被字幕遮挡 |
| V-R07 | **禁止全屏遮罩盖住背景图** | 背景图毛玻璃处理（blur: 4px）后直接作为画面基底，内容直接放在上面。**禁止**铺满全屏的半透明纯色/渐变遮罩把背景图完全盖住。文字看不清时用局部处理（文字加描边/投影、卡片加白底），不用全屏遮罩 | 深色渐变 + 发光光斑 + 点阵底纹铺满全屏，背景图完全看不见 |
| V-R08 | **每屏信息点 ≥ 3 个** | 不能一屏只有一句话或一个孤零零的元素撑场面 | 结尾屏只有两行字飘在中间，像半成品 |

#### 🟡 建议（择优使用，显著提升质感）

| 编号 | 建议 | 说明 |
|---|---|---|
| V-S01 | **每屏选排版参照** | 从 §8 排版参照库选一个匹配的参照类型，标注"参照：#X（XXX 型），借鉴了 Y 手法"，不凭空发明布局 |
| V-S02 | **至少 3 层视觉层次** | 背景层（虚化模板图）+ 主体层（卡片/图标/文字）+ 装饰/强调层（高亮底条/大数字/标签/投影），三层叠加画面才有厚度 |
| V-S03 | **颜色承担信息功能** | 主色用在最重点（标题/核心数字/CTA），辅色用在次要信息，灰色用在说明文字。颜色不只是装饰，是引导视线的工具 |
| V-S04 | **关键词有视觉强调** | 重要词汇用高亮底条、变色、放大、加粗、描边等方式强调，和普通文字拉开差距 |
| V-S05 | **装饰元素少而精** | 每屏用 1-2 个装饰元素（角标/标签/大图标/分割线/底条）增加层次和填充空间，但不堆砌（全片装饰件 ≤1-2 处，见 13 号 §8.5） |
| V-S06 | **卡片/图标风格全片统一** | 圆角大小、阴影强度、图标风格、字体字号在全片保持一致，不混搭 |
| V-S07 | **数字/数据做放大处理** | 凡是出现数字（百分比/步骤数/统计数据），一律放大做视觉焦点，配合动效（弹入/跳动/计数）增强冲击力 |
| V-S08 | **对比屏用左右/上下分色** | 痛点对比屏（传统做法 vs 新方法）用分色/分栏做强烈对比，左边冷/暗/灰（传统痛点），右边暖/亮/鲜（解法好处） |
| V-S09 | **内容多寡决定布局形态** | 左右两栏内容量不一样时，不要硬做成一样大的卡片。内容多的占主体空间（列表/大卡片），内容少的用"强调感"补分量（大字/气泡/印章/结论条），形态不同就不会有"一边空一边满"的违和感 |
| V-S10 | **纵向列表，视线一条线** | 清单/步骤/痛点类内容优先用纵向列表布局（从上到下一条线），视线不左右横跳，读起来顺。配合图标/序号/分隔线，每一条都有存在感 |
| V-S11 | **白底卡片 + 浅背景，清爽干净** | 内容放在白色/浅色卡片上，背景是浅色系（渐变/模糊底图）。对比度足够、文字清晰、整体不花哨，信息是主角而不是设计 |
| V-S12 | **画面填满，不留大块空白** | 标题 + 主体内容要把上 2/3 区域填饱满，不能上下各空 1/3、中间挤一小块。内容不够用大字号、大图标、装饰元素来撑，不能空着 |
| V-S13 | **色彩只用在关键点** | 全片颜色控制在 2-3 个色系内（主色 + 黑白灰 + 1 个强调色）。颜色用在标题、图标、关键词高亮这些"引导视线"的地方，不用颜色堆砌装饰 |
| V-S14 | **标题有"容器感"** | 标题不是飘在画面上的一行字，而是有"容器"——底色条/便签纸/顶部栏/标签框，让标题有重量感、第一眼就看见 |

#### 🟢 创意（自由发挥，鼓励创新）

| 维度 | 空间 |
|---|---|
| 特殊屏布局 | 钩子屏、结尾屏可以跳出常规布局，用大字冲击、品牌升华等创新形式 |
| 动效设计 | 入场动画、强调动画、转场方式，在 13 号硬规则范围内自由设计 |
| 装饰选择 | 具体用什么装饰元素（波浪线/手绘圈/贴纸/光效），根据内容和行业自由选择 |
| 色彩微调 | 在 palette 色系范围内，可以根据场景微调饱和度、明度，制造节奏变化 |
| 新手法尝试 | 发现新的好用设计手法，验证后沉淀回本标准 |

### 6.1 竞品：实体店电子券制作工具（抖音）

**分析日期**：2026-08-19
**样本**：5 张截图（hook / 痛点×2 / 真机演示 / 券型展示）
**整体定位**：清新手绘风 + 大字问答式，面向实体店老板的认知教育型内容

#### 视觉风格拆解

| 维度 | 做法 | 可借鉴度 | 备注 |
|---|---|---|---|
| 背景 | 浅米色 + 2-3 个模糊圆形色块（朦胧装饰） | ⭐⭐⭐ | 非常干净但不单调，比纯渐变有温度（注：此为竞品风格描述，非我方规范；我方背景模板采用毛玻璃微虚化，blur: 4px） |
| 主色调 | 深蓝字（标题）+ 橙色（强调）+ 黄色（高亮底） | ⭐⭐⭐ | 品牌色统一，识别度高 |
| 字体效果 | 粗黑体 + 蓝色描边 + 轻微投影（卡通感） | ⭐⭐⭐ | 抖音里刷到第一眼抓重点 |
| 关键词强调 | 黄色底条衬在关键词下方 | ⭐⭐⭐ | 比单纯变色更有"划重点"的感觉 |
| 图标风格 | 手绘风粗线条填色图标 | ⭐⭐ | 有温度，但制作成本高 |
| 信息密度 | 一屏只讲一件事（极低密度） | ⭐⭐⭐ | 观众不用费脑，看完就划走 |
| 排版 | 完全居中，上下对称 | ⭐⭐ | 简洁但略显单调 |

#### 叙事结构："很多人以为…" 反转式

```
S1 钩子：做电子券，一定要找人开发吗？
S2 误区1：很多人以为要装软件 → 电脑里一堆安装包
S3 误区2：很多人以为流程很复杂 → 注册/部署/对接/培训
S4 反转：其实不用，手机打开小程序就能做
S5 演示：真机展示优惠券详情页
S6 展示：这些券型都支持（胶囊标签云）
```

**核心手法**：先讲普遍误区 → 观众点头"对啊我也是这么想的" → 再推翻 → 给出简单方案。比"痛点→解法"代入感更强。

#### 可直接复用的组件

1. **黄色高亮底条**：关键词底下铺一条黄色半透明条，比单纯变色更有"划重点"的既视感
2. **胶囊标签云**：券类型用彩色圆角胶囊左右错落排列，比网格更活泼、更像贴纸
3. **手机真机演示框**：用示意框 + 抽象卡片展示券/卡的视觉效果，不用真实小程序截图（避免暴露平台信息），真实感来自手机外形而非界面内容
4. **底部进度点**：多页流程类画面用小圆点指示当前进度
5. **"很多人以为"句式**：作为痛点屏的统一开头，形成系列感

### 6.3 封面设计与 3 秒留存优化

> **核心认知**：封面是流量的第一道门，首屏（前3秒）是第二道门。两道门都过了，用户才会看你的内容。
> **封面规范唯一真源**：07 号文档 §3（策略层：尺寸/平台机制/引流规则/命名规范）。
> **设计执行细则**：13 号文档 §5.9（版式库 + 找图方法 + 交付格式）。
> 本节聚焦"为什么这么做"和"经验沉淀"。

#### 6.3.1 封面 → 点击 → 留存：转化链路

```
用户刷到视频
    ↓ （0.3 秒决定要不要点）
【封面点击率】← 封面图质量决定
    ↓ （点进来了）
【3 秒留存率】← 首屏内容质量决定
    ↓ （留下来了）
【完播率/互动率】← 视频内容质量决定
    ↓
平台推流算法判定 → 推更多流量 or 停止推流
```

**关键洞察**：
- 封面决定"有没有人点"，内容决定"有没有人看完"
- 封面差 = 内容再好也没人看 = 平台不给推流 = 恶性循环
- 封面好但内容差 = 点进来就划走 = 3 秒留存低 = 平台也不给推流
- 所以：封面和首屏必须**连起来设计**，不能各做各的

#### 6.3.2 高转化封面的底层逻辑

人在刷视频时，封面的判断时间只有 **0.3 秒**。这么短时间内，大脑只会处理 3 件事：

1. **这是什么？**（行业识别 —— 跟我有关吗？）
2. **有什么好处/威胁？**（利益点/痛点 —— 值不值得停下来？）
3. **跟别人有什么不一样？**（反差/好奇 —— 为什么要点这个？）

> 好封面 = 一眼识别行业 + 一个强利益点/痛点 + 一点反差感

#### 6.3.3 经过验证的封面标题句式库

> 从爆款封面提炼的标题句式，直接套。每个句式都附了为什么好用。

| 编号 | 句式 | 类型 | 为什么好用 | 示例 |
|---|---|---|---|---|
| F-01 | "XX 的 XX，为什么 XX？" | 提问型 | 问句天然激发好奇心，大脑会不自觉想答案 | "咖啡店的下午，为什么没人？" |
| F-02 | "一张 XX，搞定 XX" | 利益承诺型 | 简单直接，告诉用户"用一个东西就能解决大问题" | "一张次卡，搞定回头客" |
| F-03 | "做 XX，一定要 XX 吗？" | 反常识型 | 打破固有认知，激发"那不然呢"的好奇心 | "做电子券，一定要找人开发吗？" |
| F-04 | "3 个 XX，搞定 XX" | 数字冲击型 | 具体方法数比抽象描述更有说服力，也更抓眼 | "3 种券玩法，搞定门店锁客" |
| F-05 | "别再 XX 了！试试 XX" | 对比型 | 先否定旧做法，再给出新方案，反差感强 | "别再打折了！试试次卡" |
| F-06 | "XX 店老板必看：XX" | 身份标签型 | 精准命中目标人群，"说的就是我"的感觉 | "咖啡店老板必看：3 招锁客" |
| F-07 | "做 XX，只用 XX 步" | 方法型 | 用步骤数说话，让老板觉得"简单好上手" | "做电子券，只用三步" |

#### 6.3.4 封面常见的坑

| 坑 | 表现 | 后果 | 怎么避 |
|---|---|---|---|
| 文字太小 | 封面标题字低于 80px | 手机小屏看不清，直接划走 | 最小 80px，标题建议 120px+ |
| 信息过载 | 一屏塞 5 个以上信息点 | 不知道看什么，反而都没记住 | 最多 3 个信息点，主次分明 |
| 行业不明 | 没有行业元素，全是文字 | 用户不知道"这跟我有啥关系" | 必须有 1 个一眼识别的行业元素 |
| 文不对题 | 封面说的跟内容没关系 | 点进来发现被骗，秒划走，3 秒留存暴跌 | 封面是钩子，首屏必须接住 |
| 太"干净" | 纯白底 + 几个字，没设计感 | 不像干货，像随手发的，没人点 | 至少有背景色 + 1 个装饰元素 |
| 用长句 | 标题超过 15 个字 | 0.3 秒读不完，直接划走 | 控制在 12 字以内，断行不超过 2 行 |

#### 6.3.5 首屏（前 3 秒）怎么接住封面的流量

> 封面把人"骗"进来，首屏要让人"留"下来。以下是几种有效的承接方式：

1. **自问自答型**：封面问"下午 3 点没人怎么办？"，首屏答"试试这 3 招"—— 接住问题，给出希望
2. **场景延续型**：封面是咖啡店空座照片，首屏接着讲"下午 3 点的咖啡店，员工比客人多"—— 延续场景，加深共鸣
3. **数字开场型**：封面有大数字，首屏开口就报数字—— 强化冲击，快速进入正题
4. **反差升级型**：封面说"不打折也能锁客"，首屏说"反而赚更多"—— 把反常识进行到底

**绝对不能做**：
- 封面问 A 问题，首屏讲 B 内容 → 用户感觉被骗，秒走
- 首屏慢悠悠铺垫（logo 转一圈 / "大家好我是 XX"）→ 等你铺垫完，人都走了

#### 6.3.6 封面 A/B 测试方法（有条件时做）

> 同一个视频做 2 个不同封面，投放测试点击率，高的那个用。

| 测试维度 | A 版 | B 版 |
|---|---|---|
| 标题风格 | 提问型 | 利益承诺型 |
| 主色调 | 暖色系 | 冷色系 |
| 版式 | 大字标题型 | 数字冲击型 |
| 有无真人 | 有真人表情 | 纯文字+元素 |

**判断标准**：相同投放条件下，点击率高 20% 以上才算显著差异。

**参照图**：`outputs/archive/排版参考/ref-07-光斑背景清单卡片型-自有视频-很多人以为.jpg`
**适用屏类型**：痛点屏（S2）、方案屏（S3）——有质感的背景+前景组合
**好在哪**：
- 大色块光斑背景有质感，比模糊照片干净
- 白色小卡片带投影，像便签一样浮在画面上
- 高亮关键词用橙色渐变+下划线，视觉冲击力强
**可借鉴手法**：
- 背景用抽象光斑（代码 radial gradient 或模板图）
- 前景卡片用白色+投影，制造悬浮感
- 关键词用高亮底条/渐变色强调

### 8.8 彩色药丸徽章网格型（自有视频）

- 颜色在统一色系内变化（暖色系/冷色系）
- 徽章带投影，增加立体感
