# outputs/archive/ · 历史过程文件

> 本目录存放**历史过程文件**，不是权威规则文档，也不是当前 AI 接入口，更不是当前用户操作接口。

## 阅读纪律（给 AI）

1. **当前权威文档在 `AGENTS.md`、`SKILL.md`、`spec/`、`docs/internal/`。** 规则、参数、口径一律以当前 Owner 为准。
2. 本目录文件记录“那个时间点做了什么”——changelog、生产回顾、规划书、历史启动模板等，反映的是当时的决策和状态，部分内容可能已被后续决策覆盖。
3. **冲突时以当前权威文档为准**——本目录任何文件都不能覆盖当前 Owner。
4. **不要按本目录文件的细节执行。** 只有在需要追溯历史决策、证据或变更原因时才读取。
5. 本目录不得被注册为新的生产 Owner、AI 自动入口或用户当前指挥接口。

## 目录内容说明

| 文件类型 | 文件 | 用途 |
|---|---|---|
| 变更日志 | `changelog.md` | 权威文档的改动历史，供追溯上下文 |
| 历史启动模板 | `AI启动提示词.md` | **当前同名模板的历史快照**，仅供追溯；当前可复制模板在根目录 |
| 历史架构地图 | `文档架构总览.md` | 当时的结构快照，不作为当前入口 |

> 当前用户指挥接口与历史证据是两种不同角色：根目录 `AI启动提示词.md` 服务用户当前指挥；本目录同名文件只服务历史追溯。
