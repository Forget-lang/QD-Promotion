# outputs/archive/ · 历史过程文件

> 本目录存放**历史过程文件**，不是权威文档，也不是当前作业入口。

## 阅读纪律（给 AI）

1. **当前权威文档在 `AGENTS.md`、`SKILL.md`、`spec/`、`docs/internal/`。** 规则、参数、口径一律以当前权威文档为准。
2. 本目录文件记录“那个时间点做了什么”——changelog、生产回顾、规划书、历史接班模板等，反映的是当时的决策和状态，部分内容可能已被后续决策覆盖。
3. **冲突时以当前权威文档为准**——本目录任何文件都不能覆盖 `AGENTS.md`、`SKILL.md`、`spec/`、`docs/internal/` 的当前规则。
4. **不要按本目录文件的细节执行。** 只有在需要追溯历史决策、证据或变更原因时才读取。
5. 本目录不得被注册为新的生产 Owner 或 AI 当前入口；若历史文件描述了旧入口，只视为历史证据。

## 目录内容说明

> 本表为本目录的历史文件清单，随归档动作同步更新。

| 文件类型 | 文件 | 用途 |
|---|---|---|
| 变更日志 | `changelog.md` | 权威文档的改动历史，供追溯上下文 |
| 历史接班模板 | `AI启动提示词.md` | 已退休的历史多模型接力模板，仅供追溯 |
| 历史架构地图 | `文档架构总览.md` | 当时的结构快照，不作为当前入口 |

> 注：更早的生产回顾、旧 workflow、迁移地图等已按收敛规则清理，原文在 git 历史可查；不得把历史文件重新注册为当前规则源。
