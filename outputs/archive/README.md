# outputs/archive/ · 历史过程文件

> 本目录存放**历史过程文件**，不是权威文档。

## 阅读纪律（给 AI）

1. **权威文档在 `spec/`（事实/红线/素材登记）、`workflow/`（流程/审美/弹药）、`docs/internal/`（R2/R3）和 `AGENTS.md`**——规则、参数、口径一律以权威文档为准。
2. **本目录文件是"那个时间点做了什么"的记录**——changelog、生产回顾、规划书、攻略等，反映的是当时的决策和状态，部分内容可能已被后续决策覆盖。
3. **冲突时以权威文档为准**——如果本目录任何文件的内容与权威文档（`spec/`、`workflow/`、`docs/internal/`）不一致，按权威文档执行。
4. **不要按本目录文件的细节执行**——除非 changelog 里明确写了"待办"且状态为"待执行"，否则本目录文件仅供参考，不作为操作依据。
