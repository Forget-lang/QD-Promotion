- 新增 §2.11「内容呈现型 UI 设计指引」：6 种呈现类型对应 UI 样式指引 + 口播与画面分工规则（画面展示具体内容，口播讲关键理由）

- §五 阶段二新增「声画字幕同步」强调（语速变化后尤其要注意，工作流不变）

**TraeWork 会话已完成的改动（本会话验证确认）**：
- M1：语速 4.5-5→5.5-6，字数 540-750→660-900，设计稿素材提示

- 信息密度升级是丰富画面的**途径之一**，不是硬性要求每屏堆内容

- 画面展示 ≠ 口播念出来——具体内容贴画面，口播讲关键理由
- 工作流不变：无声版先行 → 看画面 → 确认后再语音合成
