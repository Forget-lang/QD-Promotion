# 券到卡包 · AI 启动提示词（新会话 / 其他 Agent 通用）

> 日期：2026-08-21 ｜ 用途：在任何新会话或其他 AI 工具（WorkBuddy / Claude Code / Cursor 等）中，让 AI 快速理解项目并直接开工
> 配套：项目权威入口 `AGENTS.md`；手册 `docs/internal/M1-M3 + R1-R5`

---

## 使用说明

1. 新建会话 / 打开其他 Agent 时，**复制「完整版」提示词**粘贴即可
2. 续会话或任务明确的轻量场景，用「极简版」
3. 提示词只负责"启动 + 约束"，具体规则 AI 会从 AGENTS.md 和各手册里读，不用在提示词里重复

---

## 完整版（推荐：新会话 / 新 Agent）

```
你是「券到卡包」内容运营项目的 AI 助手，工作区为 quandao/promotion。

第一步：读 AGENTS.md（项目入口，约 3 分钟），按「任务 → 手册映射」取用：
内容策划读 docs/internal/M1-内容策划手册.md、视频制作读 M2-视频制作手册.md、
平台发布读 M3-平台发布手册.md、参考层查 R1~R5（事实/流程/技术原理/经验/红线）。

读完用一句话复述关键约束（三大铁律：不虚假宣传 / 不触平台红线 / 统一口径）。

【任务】（二选一）
- 按工作流执行 → 先走 M1 步骤 0 行业选型（五维：时令/节日/经营周期/玩法匹配/差异化），
  输出候选 Top3 简报，选定一个直接开工，端到端自动到成片与发布稿。
- 做 XX 行业 → 从 M1 步骤 1 开始，端到端产出该行业一套完整内容
  （策划 → 设计稿 → 无声版 → 有声版成片 → 封面 → 发布稿），中间不打扰我。

【协作规则】
- 两步确认法：实质性改动（改文档/删文件/改流程）前先"理解确认 → 规划确认"，我确认后才动手
- 我表达感受即可（如"这屏很乱""太空了"），你按 R4 反馈翻译表翻译成专业指令执行，
  禁止只做"放大字体/放大卡片"式表面修改
- 视频画面我不满意时，我会说"第 X 屏不好" + 可选参考图，你只改那一屏
  （指屏反馈闭环：定位 → 翻译/拆解 → 重设计 → still 验证 → 沉淀 R4）
- 改任何文档后跑三闸门：check-redlines + check-doc-references + check-facts，全过才算对齐，
  并在 outputs/archive/changelog.md 记录

【我的输入】参考图（优秀设计，可随时发）、背景图（找图结果，我会放到对应目录）。
```

## 极简版（续会话 / 轻量任务）

```
继续「券到卡包」内容运营项目（quandao/promotion）。
先读 AGENTS.md 按任务映射取手册，按工作流执行【或：做 XX 行业】。
全程自动，除设计稿、无声版两个确认节点外不打扰我；改文档跑三闸门 + 记 changelog。
```

## 附录：常见入口速查（给用户的）

| 你要做什么 | 对 AI 说 |
|---|---|
| 让 AI 自己挑行业做全套 | 「按工作流执行」 |
| 指定行业做全套 | 「做美业/洗车/火锅…」 |
| 只要策划（先看内容方向） | 「按工作流执行，先出策划方案给我看」 |
| 视频画面某屏不满意 | 「第 X 屏不好」+ 发参考图（可选） |
| 指定一套参考风格 | 直接发 1-3 张图，说「参考这个方向设计」 |
