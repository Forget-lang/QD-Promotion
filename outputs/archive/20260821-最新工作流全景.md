## 一、开工流程（任何新会话）

1. 读 `AGENTS.md`（3 分钟，唯一入口）
2. 按「任务 → 手册映射」定位：做视频 = AGENTS + M2；写图文 = AGENTS + M3；策划 = AGENTS + M1
3. 只读对应手册，不读全部文档（阅读成本：做视频 ≈31KB，写图文 ≈21KB）

## 二、行业单元端到端（两种入口）

```
入口 A：用户指定行业（"做美业/洗车…"）→ 跳过选型，直接步骤 1
入口 B：用户说"按工作流执行"→ 先走步骤 0 行业选型（AI 自主选，输出简报直接开工）
  ↓
M1 策划（步骤 0-4）：
  步骤 0 · 行业选型（入口 B）：五维判断（时令/节日节点/经营周期/玩法匹配/差异化）
    → 候选 Top3 简报 + 选定行业 + 宣传窗口期 2-4 周 → 一句话告知用户 → 直接开工
  步骤 1 · 行业调研：细分业态（不选大行业）→ 调研三问 → 功能边界核对（R1）
  步骤 2 · 玩法选择：P-01~P-07 选 1主+1辅 → 场景策略 → 风格轮换（≥3 维不同）
  步骤 3 · 文案/口播：券组合 + 四件套 + 口播稿（4.5-5字/秒，数字写中文）
  步骤 4 · 质量自检：≥6 信息单元 / ≥2 层递进 / 深度 4 问 / 同质化检查
  ↓
设计稿（M2 §二，AI 自主设计，用户零干预）：
  选布局模式 L-XX（12 种，连续两屏不重复）→ 视觉参数（字号阶梯/间距/留白/色彩 60-30-10）
  → 一屏一焦点（三选二 + 非焦点降级）→ 参考图拆解（用户给了才做，7 项）
  → 四维自评（层次/焦点/节奏/质感 0-5 分）
  → 工具规则：项目定制规则优先，ui-ux-pro-max 仅按需补灵感
  ↓
【确认节点①】用户看设计稿 → 提意见（指屏反馈闭环）或通过
  ↓
阶段一 · 无声版（M2 §五）：代码（dur 预估）→ tsc + still 关键帧验证 → 渲染无声版（字幕占位）
  ↓
【确认节点②】用户看无声版 → 不满意走「指屏反馈闭环」：
  "第X屏不好" + 参考图（可选）→ AI 只改该屏（翻译感受/拆解图 → 重设计 → 渲染该屏 still）→ 通过才继续
  ↓
阶段二 · 有声版：TTS（seed-tts-2.0，禁 atempo）→ loudnorm → ffprobe 实测
  → dur = ceilTo01(audioDuration) + extraHold（信息屏 0 / 数据屏 0.8 / CTA 1.5）
  → voiceDur 回填 → 字幕精确同步 → 成片渲染 → 盲听校验
  ↓
发布（M3）：封面（找图需求单含前景兼容约束 → 用户找图 → still 兼容验证）→ CTA（不提微信/小程序，导流仅限资料位）
  → 三平台自查清单（抖音 7 项 / 小红书 6 项 / 搜狐 6 项）
  ↓
生产回顾（强制，缺了不算交付完成）：经验沉淀 R4（句式/踩坑/新布局/新感受/选型命中记录）
```

## 三、背景图专项流程（前景兼容）

```
设计稿出找图需求单（必填「前景兼容约束」：内容区留白/低饱和 + 前景主色清单 + 禁撞色项）
  → 用户找图或 AI 生图（提示词带约束：内容区留白、避开前景主色、无文字无logo）
  → 放入 video/public/backgrounds/gXX/
  → AI 渲染 1-2 帧 still 验证对比度 ≥4.5:1
  → 不达标：代码层局部处理 / 换图 / 重新生成
  → 通过才全量渲染
背景显示策略：默认直接显示原图（blur=0）；AccentOverlay 主色调和作兜底；毛玻璃降为可选
```

## 四、文档维护（改任何权威文档）

```
改 → 跑三闸门（全过才算对齐）：
  ① node scripts/check-redlines.mjs        （画面/口播层零命中；文档层命中=红线描述正常）
  ② node scripts/check-doc-references.mjs  （文件名/章节名引用失效即报错，防残留旧方案）
  ③ node scripts/check-facts.mjs           （关键资产路径在磁盘存在，注册表 ref-registry.json）
  → outputs/archive/changelog.md 顶部追加记录（最新在前）
新增内容按 AGENTS 归属判定表放对文档（拿不准默认放 R4）
```

## 五、相似度防线（防同质化，M2 §2.3）

- 风格五维 ≥3 维不同（palette/motion/transition/typography/hookStyle）
- 场景序列：新增+消失+重排 ≥3 位置
- 布局模式组合：两视频模式选型至少 4 种不同
- 同质化检查：去掉行业词剩余结构 80% 一样 = 回炉重设
