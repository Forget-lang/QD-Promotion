# 视频风格轮换方案 · 防视觉疲劳与抗同质化限流

> 配套文档：10-视频制作方案（三要素模型）、07-渠道与执行（三平台）、11-素材规范。
> 与 `outputs/三平台规则调研-限流与推荐机制-20260813.md` 的"同质化严打"结论直接挂钩。
> 建立日期：2026-08-13。

---

## 0. 为什么要做风格轮换（两个独立理由）

1. **用户体验：视觉疲劳**。同一条三要素模板、同一种插画风、同一种配色刷满信息流，用户刷到第 3 条就预判内容、划走率上升、完播率下降。而完播率 <15% 抖音十分钟停推（见 10 §4），疲劳直接伤推荐。
2. **平台规则：同质化严打**（调研结论）。抖音/小红书对"相似度 >25%"的内容压流量池，多行业（G01–G06）共用一套模板画风，极易被判定为"模板化 AI 流水账"。**风格单一不只是审美问题，是限流风险。**

两条结论指向同一动作：**让每一条视频在"形"上不同，在"神"上统一。**

---

## 1. 核心策略：形散神聚

- **神（固定，建立账号记忆点）**：统一的品牌记忆锚（见 §5）——开场 1.5s 标识、统一角标、贯穿的轻量吉祥物剪影。用户不一定记得某条视频，但会记得"那个用券的小卡片精灵讲的店"。
- **形（轮换，无限组合）**：插画风、配色、版式、转场、钩子、字幕视觉六大维度各自成库，逐条/逐屏组合变化。

> 小红书封面规范原话"同系列用统一模板形成账号记忆点"是对的，但**记忆点靠"神"不靠"形"**——固定角标与吉祥物即可，不必锁死画风。

---

## 2. 六大可变维度（每个都是可选项库）

### 维度 1 · 插画风格库（最强变量）

| 编号 | 风格 | 适用调性 | 生成要点（ImageGen brief 锚点） |
|---|---|---|---|
| I1 | 扁平几何 flat | 现代、商务、干净 | 纯色块+粗描边，无渐变无阴影 |
| I2 | 2.5D 等距 iso | 有空间感，适合"门店/街区" | 等距视角，柔和高光，适合画店铺/商圈 |
| I3 | 手绘涂鸦 doodle | 亲切、接地气，适合夫妻店 | 不规则线条、马克笔质感、略歪 |
| I4 | 孟菲斯/波普 memphis | 活泼、年轻、吸睛 | 撞色几何、波浪点、 zigzag 装饰 |
| I5 | 国潮/水墨 guochao | 文化感，适合茶饮/火锅/烘焙 | 水墨晕染+朱红印章+留白 |
| I6 | 极简线条 line | 高级、克制 | 单色细线、大量留白 |
| I7 | 3D 黏土/胖胖 clay | 可爱、记忆点强 | 软阴影、圆润、果冻质感 |
| I8 | 像素/复古 pixel | 反差、有趣 | 8/16bit 调色板、硬边像素 |

每行业先锚定 1 个 base 风格，再轮换变体，避免跳脱显廉价（见 11 §3-② 风格锚定）。

### 维度 2 · 配色方案库（配色遵循「合适就使用」原则，不限制具体色值，2026-08-15 决策）

| 编号 | 名称 | 主色氛围 | 适配 |
|---|---|---|---|
| P1 | 暖橙活力 | 橙+米白 | 餐饮/火锅/烘焙 |
| P2 | 薄荷清冷 | 青绿+雾白 | 茶饮/咖啡/生鲜 |
| P3 | 莓紫高级 | 紫+浅粉 | 美业/美容/护肤 |
| P4 | 深蓝信任 | 藏青+银灰 | 汽车/家政/服务 |
| P5 | 焦糖暖棕 | 棕+奶油 | 零售/书店/花店 |
| P6 | 墨绿沉稳 | 墨绿+米 | 农产/有机/健康 |
| P7 | 霓虹撞色 | 品红+青 | 年轻/潮流/夜经济 |

每套 = 背景渐变 stops + 关键字文字色 + 插画点缀色，封装为 Remotion 的 `palette` 对象。

### 维度 3 · 版式构图库（三要素怎么排）

| 编号 | 版式 | 描述 |
|---|---|---|
| L1 | 居中大字 | 关键字居中，插画铺底/半透明 |
| L2 | 左对齐压暗 | 关键字左、插画右，编辑式排版（横版友好） |
| L3 | 分屏 | 左插画 / 右文字，对等分割 |
| L4 | 全屏插画+浮层 | 插画占满，小标题浮层一角 |
| L5 | 画中画 | 小插画卡浮于背景图上 |
| L6 | 大字镂空 | 关键字作主角（描边/填充），背景模糊插画 |

横版（16:9 搜狐）优先 L2/L3；竖版（9:16）优先 L1/L4/L6。

### 维度 4 · 转场与节奏库

- 转场：滑动 slide / 缩放 zoom / 形状遮罩 wipe / 溶解 dissolve / 翻页 flip / 弹入 pop / 字符级逐词。
- 节奏：总时长在 18–40s 内微调；相邻场景时长不等（避免机械感）；同一条内转场类型不重复 ≥2 次。

### 维度 5 · 钩子类型库（开场不重样）

| 类型 | 示例（餐饮） |
|---|---|
| 反差型 | "你店里的老客，正被隔壁一张券悄悄撬走" |
| 数字型 | "90% 的奶茶店，第一张券就做错了" |
| 提问型 | "为什么隔壁火锅店，周一也满台？" |
| 故事型 | "上周有个开面馆的老板跟我说……" |
| 挑战型 | "不花一分钱，让老客带新客，你做得到吗？" |

### 维度 6 · 字幕/关键字视觉变体

- 描边样式：TikTok 黄边 / 白边 / 同色系描边；
- 字号节奏：逐词弹入 / 整句滑入 / 逐行 stagger；
- 关键字装饰：无 / 下划波浪 / 重点词放大。

## 3. 行业 × 风格映射矩阵（base identity，避免跨行业雷同）

| 行业 | base 插画风 | base 配色 | 备注 |
|---|---|---|---|
| G01 火锅 | I5 国潮 | P1 暖橙 | 红火氛围 |
| G02 茶饮咖啡 | I6 极简线 / I5 水墨 | P2 薄荷 | 清爽高级 |
| G03 美业 | I7 黏土 | P3 莓紫 | 可爱记忆点 |
| G04 汽车服务 | I2 等距 | P4 深蓝 | 空间感 |
| G05 零售 | I1 扁平 | P5 焦糖 | 干净 |
| G06 连锁 | I4 孟菲斯 | P7 霓虹 | 年轻潮流 |

> 矩阵只定"base"，**每条视频再在维度 1–6 上轮换变体**——同行业不同选题也长得不一样。

## 4. 品牌记忆锚（固定项，全片统一）

1. **开场 1.5s 标识**：统一的小动画（如一张券飞入 + 轻响），不随风格变；
2. **统一角标**：右下「券到卡包」文字角标 + 「AI 技术制作 · AI 配音」角标（合规，见 10 §8）；
3. **轻量吉祥物（可选）**：一个"小卡片精灵"剪影，在转场/收尾露脸，作记忆锚；场景插画风格仍可换，吉祥物线稿固定。

---

## 5. Remotion 落地：风格主题化（theme config）

把"风格"抽象成数据，避免每换风格改代码：

```ts
// src/styles.ts
export type Theme = {
  illustrationStyle: 'flat'|'iso'|'doodle'|'memphis'|'guochao'|'line'|'clay'|'pixel';
  palette: { bgFrom:string; bgTo:string; keyword:string; accent:string };
  layout: 'center'|'left'|'split'|'full'|'pip'|'hero';
  transition: 'slide'|'zoom'|'wipe'|'dissolve'|'flip'|'pop';
  caption: 'tiktok'|'white'|'mono';
};
export const THEMES: Record<string, Theme> = { /* P1I5, P2I6, ... */ };
```

- 每条视频：`--props='{"theme":"P2I6","hookType":"num"}'` 选主题与钩子；
- 分屏覆盖：单条视频内某屏可 override `layout/transition`，制造节奏；
- 插画按 `illustrationStyle` 调用对应生成 prompt 库（见维度 1）。

> 这正发挥 Remotion 参数化优势：一套代码，N 种风格，零改架构。

---

## 6. 生产节奏规则

- **单条内**：场景间版式/转场至少轮换 2 次，不机械重复。
- **跨视频**：相邻两条不同（插画风 OR 配色 OR 钩子）至少一项不同；同行业周更时走"base 风格 + 变体轮换"。
- **账号级**：神（锚）固定，形（风格）按矩阵+轮换，形成"熟悉又新鲜"的观感。

---

## 7. 数据闭环（让数据选赢家）

每次真片发布后，按 12 步骤 12 的《视频生产回顾模板》额外记录：
- 本条所用：插画风 / 配色 / 版式 / 钩子 / 转场；
- 表现：播放、完播率、涨粉、评论关键词。
- 轮末把"哪组风格组合表现最好"回写本方案 §3 矩阵，形成**数据驱动的风格进化**，而非拍脑袋。

---

## 8. 实施建议（分阶段）

1. **先建风格库**：把维度 1–6 各选项固化为生成 prompt 与 Remotion 参数（THEMES 注册表）；
2. **首批试水**：G02 茶饮先做 2 条不同风格（如 I6 极简 + I5 水墨）A/B 看完播；
3. **铺矩阵**：按 §3 给 G01–G06 各定 base，逐行业出 1–2 条；
4. **数据回流**：回顾模板跑 2–3 周，优化矩阵与轮换规则；
5. **常态化**：把"风格轮换检查"加入 12 红线汇总第 10 条。
