## 一、整体架构：一套代码 → 双画幅（关键）

**最干净的做法 = `vmin` 响应式 + `isPortrait` 布局分支。**

原理：竖屏 1080×1920 的 `vmin = width/100 = 10.8px`；横屏 1920×1080 的 `vmin = height/100 = 10.8px`。**两种画幅下 vmin 的像素值完全相同**，所以只要所有字号、元素尺寸、间距都用 `vmin` 倍数，组件在 9:16 和 16:9 下"自动等长"。只需对**布局位置**（竖屏竖向排布、横屏横向排布）做 `isPortrait` 分支。

```tsx
const { width, height } = useVideoConfig();
const vmin = Math.min(width, height) / 100;     // 两画幅均 = 10.8
const isPortrait = height > width;
const headingSize = vmin * 12;                  // 约 130px，两版一致
```
字号参考（基于 vmin，1080p 下 vmin=10.8）：主标题 `vmin*10–15`、章节标题 `vmin*6–8`、正文/卡片 `vmin*2.5–3`、字幕 `vmin*1.5–2`。**宁可大不要小**。

注册两个 Composition，共用同一组件：
```tsx
<Composition id="Promo-Portrait"  component={Promo} width={1080} height={1920} fps={30} durationInFrames={...} />
<Composition id="Promo-Landscape" component={Promo} width={1920} height={1080}  fps={30} durationInFrames={...} />
```
渲染：`npx remotion render src/index.tsx Promo-Portrait out/promo-9x16.mp4` 与 `...Promo-Landscape out/promo-16x9.mp4`。

## 二、场景结构模板（宣传片 15–40s）

> 抖音完播率<15% 十分钟停推，15–40s 完播最佳。每场景 ≥4–8s，宁可慢。

| 段落 | 时长 | 内容 | 视觉 |
|---|---|---|---|
| Hook 钩子 | 0–3s | 痛点/冲突/反差，**静音也能懂**（文字承载） | 大字标题 + 背景图，禁开场放 logo（像广告会被划走） |
| 痛点 | 3–10s | 实体店经营共鸣（老客流失/拉新难） | 插画 + 关键字逐条弹出 |
| 解法 | 10–20s | "有个玩法/工具能这样解决"（软种草，自然带出券到卡包） | 插画演示 + 关键字 |
| 价值点 | 20–30s | 3 个核心价值（锁客/复购/私域） | 列表 stagger 入场 |
| CTA | 末 3–5s | 分平台话术（见第六节），屏幕上 ≥5s | 关键字收束 + 关注/收藏引导 |

用 `<TransitionSeries>`（fade/slide，15–20 帧重叠）替代硬切；或 `<Sequence>` 分段。

## 三、Hook 钩子设计（最高杠杆）

- **必须静音可懂**：文字叠加承载信息，不能靠配音。
- **禁止开场 logo / "你是否想过…" / "如果我说…"**（2025+ 划走触发词）。
- 钩子类型（选一种）：反差 / 社会证明 / 悬念 / 数字列举 / 情绪 / 矛盾 / 对比。
- **针对我们的产品示例**（反差+情绪）："你店里的老客，正被隔壁一张券悄悄撬走"；"发传单没人领？不是活动差，是方式老了"。
- 短视频（<30s）可直接用"结果前置"型钩子（先亮效果）。

## 四、三层 motion graphics 实现（背景+插画+关键字）

```tsx
<AbsoluteFill>                                  // 背景封面图
  <Img src={staticFile('bg/coffee.jpg')} style={{objectFit:'cover'}} />
  <AbsoluteFill style={{background:'rgba(0,0,0,0.35)'}} />  // 压暗保证文字可读
</AbsoluteFill>
<AbsoluteFill>                                  // 插画层
  <Img src={staticFile('illu/pain.svg')} style={{...spring 入场}} />
</AbsoluteFill>
<AbsoluteFill style={{justifyContent:'center'}}> // 关键字层
  <h1 style={{fontSize: headingSize, textShadow:'0 2px 8px rgba(0,0,0,0.6)'}}>老客流失</h1>
</AbsoluteFill>
```
- 文字**必须加 textShadow** 保证任意背景可读（用高对比深色/暖色保证可读；配色遵循「合适就使用」原则，不限制具体色值，2026-08-15 决策）。
- 禁按钮式 UI（胶囊/圆角卡片/徽章），走"实景底图+大字标题+插画"开放画风。
- 插画/背景存 `public/`，统一 `staticFile()` 引用，不写裸路径。

## 五、文字与关键字动画

- 入场：`spring({ damping: 10 })`（有机弹性）；退场：`interpolate + ease-out`。
- 列表 stagger：每项 `delay = index * 5` 帧错峰入场。
- 关键字逐词/逐字揭示：用 `spring` 控制每个 token 弹入（scale 0.6→1 微过冲），当前词高亮单色。
- 节奏铁律：**太Fast是头号错误**。每个场景给足 4–8s，文字停留时间 = 读者读完+理解。

## 六、TTS 配音 + 字幕逐词同步（豆包）

1. **先定稿 TTS 音频，再对画面**：锁定配音后才生成视觉，片段时长对齐音频。
2. 豆包 TTS 导出 **44.1/48kHz、16bit** mp3；段间留 **0.2–0.5s 静音 padding**；远程加载用 `delayRender()/continueRender()`。
3. 字幕：用 `@remotion/install-whisper-cpp` 对成片配音做**词级时间戳**（或用豆包返回的字/词级时间戳），`createTikTokStyleCaptions({ combineTokensWithinMilliseconds: 800 })` 生成 1–4 词/页。
4. 字幕样式：Bold sans（中文 Noto Sans SC），**56–80px**、2–6px 黑描边 + 阴影、高对比；居中带（屏高 62–70%），**避开底部 15% 平台 UI 区**，左右留安全边。
5. 配音全程铺在 `<Audio src={staticFile('voice.mp3')} />` 下，时间戳对齐音频时基，零手动偏移。

> 注意：抖音/小红书 CTA 话术绝口不提微信（见配套调研报告）；搜狐版可在结尾字幕放"微信搜券到卡包"。

## 七、CTA 放置规则

- 短视频（<60s）：CTA 放**前 1/4 或结尾**；屏幕上可见 ≥5s；口语 CTA + 屏幕文字/按钮（我们禁按钮式 UI，用大字关键字替代）同步。
- **一视频一 CTA**，多个 CTA 转化下降。
- 抖音/小红书结尾引导"关注/收藏/评论"；搜狐结尾可引导搜索。

---

## 八、安全区与字号（9:16 避 UI）

- 竖屏底部 ~280px（屏高 15%）留给平台 UI（昵称/音频/按钮），字幕与 CTA 上移。
- 左右留出中心 80% 宽度，避开右栏图标。
- 正文 ≥28px、标题 ≥64px（vmin 倍数法已保证）。

---

## 九、字体 / 性能 / 渲染

- **中文字体必须本地加载**（不能依赖系统字体）：Noto Sans SC，用 `@remotion/google-fonts` 或 `delayRender + document.fonts.ready`。
- 性能：重计算 `useMemo`；场景拆 `<Sequence>`；图片压 jpeg（`Config.setVideoImageFormat("jpeg")`）；CJK 大字体并发别太高（`Config.setConcurrency(4)`）。
- 动态时长：`calculateMetadata` 按场景数算 `durationInFrames`，适配多行业数据驱动。
- 渲染：`npx remotion render ... --codec h264 --crf 18`。
