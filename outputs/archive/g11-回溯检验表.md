# g11 回溯检验表（CHANGE-20260917-020 真实产物证据）

> 用途：用 CHANGE-020 新口径（认知职责 / 表达形态 / 双入口 / 形态复用纪律）**回溯审查已产出的 g11 口播七屏**，证明两件事：① 新口径可执行（能落到真实内容上逐屏判读）；② 新口径能**识别**形态复用（而非只在文档里声明）。
> 边界：本表**只审不改**——g11 已标记为 Legacy Baseline / 旧方法基线样本，本表不构成对 g11 的修改，也不据 g11 的任何结论评价新方法效果。
> 产出：`outputs/archive/`（过程证据，不进 g11 交付包）。

## 一、逐屏判读

| 屏 | 内容（简） | 认知职责（五拍） | 实际表达形态 | g10 对应屏的形态 | 形态重叠判定 |
|---|---|---|---|---|---|
| S1 | 周五满座 / 周一空桌，缺的是出门理由 | 吸引 | 排比钉事实 + 正面陈述缺口 | 身份点名 + 痛点 + 「不是X是Y」缺口反转 | **部分重叠**（同走"认知缺口"落点） |
| S2 | 打折喊群没用 → 券要"抢"才当回事 | 保持（理解） | 错误示范先行 → 后果具体化 → 正面拆机制 | 换位设问（群里甩的券你领过几张）+ 本能隐喻 | **高度重叠**（同走「错误示范先行」） |
| S3 | 手气券：区间六块到八十八，两问两答讲为什么 | 理解 / 落地 | 现场型（跟着设置项走）+ 自问自答 | 现场型（跟着制券表单走）+ 借官网蓝本 | **重叠**（同样"现场跟设"） |
| S4 | 公开领取 + 限领一张 + 晚八点开抢 | 落地 | 动作指令链 + 后果说明 | "真正的杀招在这"式反常识标签 + 动作链 | **部分重叠**（同用"最重要一步"标签法） |
| S5 | 可用时段写死周一到周四，别选全天 | 落地 | "最关键的一步"标签 + 判断 + 身体隐喻收 | 同上（S4 的亮点机制标签） | **部分重叠**（标记法同型） |
| S6 | 顾客侧：抢到 → 卡包 → 核销 → 满减 | 理解与相信（兑现） | 独立流转屏（一条线串起来） | 独立流转屏（老客领券→转赠→核销→奖励） | **高度重叠**（同型独立流转屏） |
| S7 | 金句两句 + 动作收尾 | 收口 | 可转发公式 + 动作指令 | 认知缺口式金句（两句） | **高度重叠**（同型金句收尾） |

**重叠统计**：7 屏中 **3 屏高度重叠 + 3 屏部分重叠 + 1 屏（S3）形态本身必要**（讲设置天然要现场）。

**判读结论**：跨片形态复用**不是个别句子问题，而是七屏里的普遍现象**——g10→g11 撞句只是它在文字层露出的一个尖。这与侦察报告"结构组件被当成表达组件用"的定性一致。

## 二、按新口径，这七屏应如何选择（可执行性验证）

| 屏 | 按新口径的处理 |
|---|---|
| S1 | 不走"身份+痛点+缺口陈述"三重套路；改**观察型**——画面先给两种夜晚的对照事实，口播只说看见的东西，缺口留给观众自己得出 |
| S2 | **不必**再走"错误示范→正解"；改**算账型**（把"打折喊群"的代价与"到点开抢"的回收并排算一笔），或**场景入口**直接进行业情境 |
| S3 | 现场型对"讲设置"是内在必需 → **可以复用**，但按复用纪律须写出理由（写入《表达形态选择及理由》）："设置演示必须跟着界面走，此处形态由内容性质决定，非默认继承" |
| S4 | 去掉"最重要一步"标签法；改**对话型**（一问一答把门槛演出来） |
| S5 | 同上——两屏连用同一标记法，是 g11 最明显的形态冗余点 |
| S6 | **形态重叠最严重**：独立流转屏与 g10 同型 → 改为**结果内嵌**（把顾客侧结果压进设置屏的收尾句），省一屏且去重 |
| S7 | 金句形态可换；改**观察型收口**或**动作指令收口**，避免"两句式金句"的固定收束感 |

**可执行性验证结论**：新口径能对真实内容**逐屏给出替代选择**（上表七行全部可落），不是抽象原则 → 口径可执行。

## 三、本表证明的两件事（对应契约 §十一 适用证据）

1. **新口径可执行**：能把"认知职责 / 表达形态 / 复用判定 / 替代选择"逐屏落到真实内容上，且判读标准可被第三方复核。
2. **新口径能识别形态复用**：查出 7 屏中 6 屏存在跨片形态重叠（含 3 屏高度重叠），并定位到具体形态名（错误示范先行 / 独立流转屏 / 两句式金句 / 最重要一步标记）——**这是旧口径下无从检查的维度**（旧口径只查数字中文、品牌一次、红线词）。
