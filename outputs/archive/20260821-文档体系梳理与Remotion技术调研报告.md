## 四、Remotion 调研：让 AI 做出"好看"的视频效果

### 4.1 "画面不好看"的技术根因（代码实锤，按影响排序）

结合代码审查，当前观感问题主要不是"AI 不会设计"，而是**三个实现层断点**：

1. **氛围层没挂载（C2）**：暗角（聚焦视线）、颗粒（杀色带）、主色调和（背景与 UI 融合）是让画面从"平"到"有质感"的三件套，组件写好了但 VTemplate 没挂——这是性价比最高的一处修复。
2. **背景图加载失败（C1）**：G02-V2 八屏黑底，钩子/CTA 氛围直接归零。
3. **数据屏/钩子屏信息缺失（C3/C4）**：panel 无数字、contrast 钩子丢标题，画面"空"。

### 4.2 专业感的核心原理（外部调研提炼）

**动效设计 12 法则**（行业通用理论，可直接当设计检查表）：

1. **缓动（Easing）**——最关键的一条。关键帧只定起止，缓动决定中间过程；线性运动 = 生硬感第一来源。
2. **偏移与延迟（Stagger）**——多个元素错峰入场（一个接一个），避免齐步走；这是"节奏感"的来源。
3. **父子关系**——父动子随，建立元素层级。
4. **变换（Morph）**——元素平滑过渡（按钮→进度→完成），避免突兀切换。
5. **数值变化**——数字滚动暗示动态（本项目的 StatCounter 正是此条）。
6. **滑动与变焦**——镜头运动制造"旅行感"。
7. **维度**——翻转/折叠赋予深度，像物理世界的物体。
8. **视差**——前景快、背景慢，引导视线同时保持画面统一。
9. **模糊**——前后景关系（毛玻璃），也用于过渡（本项目 dissolve 转场已用）。
10. **克隆**——元素分裂要有来源，避免凭空出现/消失。
11. **叠加**——2D 空间模拟深度错觉。
12. **蒙版**——局部揭示（本项目 CharReveal 逐字 mask 入场正是此条）。

**AI 生成视频"廉价感"的四个根源**（影视级通用诊断）：① 缺乏视觉层次（所有元素精度/权重一致，无视线引导）；② 过度运动（滥用运镜和动效）；③ 光线无依据；④ 情绪节奏缺失（没有留白让观众沉淀）。

映射到本项目：画面的"平"主要来自 ①（层级不足）+ ④（节奏平铺、信息密度不匀、无呼吸点）。好在 Remotion 是代码渲染，**①层次和④节奏恰恰是代码层最能直接控制的两项**——这是本项目的最大提升空间。

### 4.3 落地到 Remotion 的具体技术清单（建议沉淀进 13 号文档）

**A. Spring 物理感（入场首选）**
- `spring({ frame: frame - delay, fps, config: { stiffness, damping, mass } })`
- 参数安全带：`stiffness 80-200`、`damping 20-60`；**damping 过小会无限震荡**（如 bouncy 应控制 damping ≥ 12）
- 用 `measureSpring()` 精确计算弹簧动画持续帧数，不要手估
- 入场/强调用 spring（带过冲更生动）；离场、长距离位移用 easing 更稳

**B. 缓动（非 spring 一律指定 easing，本规范已有 EASE_OUT）**
- 入场：expo-out（快起慢落）通用；关键数字/标题可用 `Easing.back(1.2)` 或 spring 轻微过冲
- 数字滚动：easeInOut 或 expo-out + clamp
- 禁止裸线性（唯一例外：匀速滚动字幕等刻意匀速场景）
- 插值必须 `extrapolateRight: 'clamp'` 防越界（TimelineScene 的缺 easing 问题即此类）

**C. 节奏与错峰**
- 同屏元素 stagger 间隔 **4-8 帧**（太快=齐步走，太慢=拖沓）
- 主体动画时长 **20-40 帧**（0.7-1.3s）：短于 0.5s 生硬，长于 1.5s 拖沓
- 每屏只设一个**主动画时刻（peak frame）**，其余元素围绕它编排——对应"一屏一焦点"

**D. 三层视觉层次（代码级落地）**
- 背景层：虚化模板图 + Ken Burns 极慢推近（已有，保持）
- 主体层：卡片/文字（已有）
- **氛围层：Vignette 暗角 + Grain 颗粒 + AccentOverlay 主色调和（已实现，必须挂载）**
- 前景装饰 ≤1-2 处，少而精

**E. 视差**
- 背景运动速度 ≈ 前景 1/3~1/4（Ken Burns 1.0→1.04 全片量级已符合）
- 装饰元素与主体不同速，制造深度

**F. 质感细节（"不完美"才高级）**
- 颗粒 3.5% 杀色带（已实现未挂载）
- 暗角径向渐变聚焦中部（已实现未挂载）
- 大数字用等宽/tabular 数字防跳动
- 投影分层：卡片用三级投影 `elevation()`（已有），文字阴影别用纯黑 hard shadow，加一层透明度更柔

**G. 数据屏必须有数字（V-S07 落地）**
- StatCounter 0→value 滚动，duration 30-45 帧，expo-out
- panel 屏 metrics 必须有 value 字段——**"数据屏没有数字"是设计缺陷不是风格选择**

**H. 转场**
- 12 帧（0.4s）标准；不每屏同一种（五键已有）
- 共享元素转场（如数字/图标跨屏延续）比纯黑场/空转场高级，可作为进阶方向

**I. 字幕（对齐 §2.7）**
- 字重 500（代码现为 600，需改）、多行 10-20 字、语义断句
- 关键字与口播重音对齐（AccentWord 已实现，保持按需使用）
