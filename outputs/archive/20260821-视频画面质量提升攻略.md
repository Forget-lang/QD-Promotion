# 视频画面质量提升攻略：从"AI 只会放大字体"到"Remotion 高质量输出"

> 日期：2026-08-21 ｜ 定位：解决"视频 UI 效果无法让人满意"这一核心难题
> 现状：用户多次提供优秀参考（视频页面/创可贴设计图）给 AI，但 AI 优化结果只是"字体放大、卡片放大"，未触达设计本质；用户缺少专业表达话术，反馈被 AI 简单化处理。

---

## 一、问题诊断：为什么 AI 优化不到点上

### 1.1 表面现象
AI 拿到优秀参考图后，只做"字号调大、卡片调大、颜色调亮"这类表层修改，画面结构、层级、留白、焦点毫无变化。反复试多次，结果雷同。

### 1.2 五个根因（按重要性排序）

**根因 A · 没有"参考图拆解框架"，AI 看不懂设计意图**
AI 是语言模型，看到参考图只会提取"表面元素"（大字、卡片、图标、颜色），提取不到"设计决策"（为什么这样排版、层级怎么组织、视线怎么引导、留白为什么留这里）。除非被强制要求"按固定框架拆解"，否则它不会主动分析。用户说"参考这个优化"，AI 的最省力执行就是放大字体卡片——因为那是最容易观察到的表面差异。

**根因 B · 设计稿的语言是"元素清单"，不是"设计决策"**
现有分镜表模板（M2 §2.4）的"画面布局"字段，AI 写出来的是"标题在上、卡片在中、数字在右"这类元素罗列。元素清单只能产生"信息放进去"的画面，产生不了"设计过的"画面。缺的是：视觉层级、对齐关系、焦点分配、间距系统这些"设计决策"的强制字段。

**根因 C · 没有可执行的"视觉层级参数"，AI 只会调大小**
字号、间距、留白、色彩没有标准化的参数阶梯，AI 只能凭感觉给数字，参考图里的大字它就跟着放大。没有"字号阶梯表/间距网格/色彩比例"，AI 就无法判断"多大算大、多小算小、比例是否失衡"。

**根因 D · 现有标准是"检查项"，不是"生成指南"**
R4 的 V-R01~V-R08（红线）、V-S01~V-S14（建议）是"检查清单"——设计完对照打勾用的。AI 在设计**生成阶段**用不上它们（不知道"如何实现 3 层视觉层次"）。缺一个"设计生成配方"：布局模式 + 参数表 + 焦点规则。

**根因 E · 代码层缺陷拖后腿（画面质感的地基坏了）**
- VTemplate 未挂氛围层三件套（Vignette 暗角 / Grain 颗粒 / AccentOverlay 主色调和）→ 画面"平、黑、廉价"
- PanelScene 数据屏无数字滚动 → 信息单薄
- ContrastHook 不渲染主标题 → 钩子屏丢焦点
- TimelineScene 非 spring 插值缺 easing、颜色瞬切 → 动效生硬
- 多个场景标题 top:100 越安全区（应 ≥120px）
- 组件默认 motion 未透传风格 → 动画性格不统一
→ 即使设计稿完美，这些缺陷也会让成片观感打折。**必须先修代码，再谈设计**。

### 1.3 用户侧的困难：表达难
用户不是设计师，说不出"层级对比不够""焦点分散""留白失衡"这类话，只能描述感受："画面很平""看起来很廉价""不知道看哪"。AI 把感受翻译成"放大字体"是最差解。需要一个"感受 → 专业指令"的翻译表，让用户能用大白话精准驱动 AI。

## 二、核心方案：建立"设计语言系统"

> 一句话：把"设计感觉"翻译成"AI 可执行的规则"。AI 不需要"看懂设计"，只需要"按规则生成"。这是 LLM 做视觉设计的唯一可靠路径。

### 2.1 布局模式库（Layout Patterns，12 种）

> 从优秀竖版短视频/创可贴设计中提炼的**标准布局模式**。AI 设计稿每屏必须"先选模式，再填内容"，禁止凭空排列元素。每种模式 = 结构描述 + 区域坐标 + 视觉要点 + 适用屏型。

| # | 模式名 | 结构描述（1080×1920 坐标） | 视觉要点 | 适用屏型 |
|---|---|---|---|---|
| L-01 | 大字中心型 | 超大标题居中（y:300-700），四周大量留白，底部一行小标注 | 焦点唯一：大字即一切；留白撑高级感 | 钩子屏 |
| L-02 | 上下分栏型 | 上 1/3 标题区（y:200-500），下 2/3 内容区（y:550-1650） | 标题与内容间距 40-60px；内容区卡片承载 | 信息屏 |
| L-03 | 左右对比型 | 中线 VS 徽章，左右各一卡（红/绿） | 对比靠色相+方向箭头，不靠大小 | 痛点-解法屏 |
| L-04 | 数字冲击型 | 超大数字（160-200px）居中偏上 + 下方 1-2 行说明 | 数字是绝对焦点，说明字 ≤44px 弱化 | 钩子/数据屏 |
| L-05 | 卡片网格型 | 2×2 卡片（每卡 400×400 上下两行） | 卡片等大、间距统一（≥卡片高 20%）；焦点靠卡片内图标+数字 | 卖点/数据屏 |
| L-06 | 流程线性型 | 3-4 节点横向排列 + 箭头连接（y:600-900 中线） | 节点由连接线串起，逐步点亮；节点等距 | 步骤屏 |
| L-07 | 纵向列表型 | 3-5 行列表从上到下（每行图标+标题+说明） | 视线一条线；行间距 ≥24px；图标统一 | 清单/规则屏 |
| L-08 | 标签徽章型 | 主体内容 + 1-2 个角标/徽章（右上/左下） | 徽章是"额外信息"不是主体；≤2 处 | 进阶提示屏 |
| L-09 | 时间线型 | 中部曲线/时间轴 + 关键点标注 | 曲线平滑绘制动画；关键点用亮点+文字 | 客流/周期屏 |
| L-10 | 聚焦对比型 | 中央大焦点（数字/券面）+ 两侧弱化元素 | 焦点 ≥ 两侧元素 2 倍；两侧降透明 | 核心卖点屏 |
| L-11 | 票券展示型 | 券面/卡片为主体（居中 600×800），上下文字 | 券面有厚度（阴影/倾斜/撕边）；角度微倾更活 | 产品展示屏 |
| L-12 | 收尾品牌型 | 品牌名居中大字 + 一句价值主张 + 底部装饰线 | 品牌名 ≥120px；装饰线 draw-on 动画 | CTA 屏 |

**落地**：此表加入 M2 分镜表模板——"画面布局"字段改为"布局模式: L-XX + 区域坐标 + 焦点元素"三要素，AI 必须从 12 种中选，禁止自由发挥。

### 2.2 视觉层级参数表（字号/间距/留白/色彩的标准阶梯）

> AI 设计稿的**硬参数**，解决"放大字体"问题——不再是凭感觉给数字，而是按阶梯取值。

**字号阶梯**（焦点数字 > 主标题 > 副标题 > 正文 > 标注）：

| 层级 | 字号 | 用途 | 约束 |
|---|---|---|---|
| 焦点数字 | 160-200px | 大数字（百分比/金额/数据） | 全屏最大，唯一可超 150px |
| 主标题 | 96-120px | 每屏标题（≤14 字） | ≥副标题 1.5 倍 |
| 副标题 | 56-72px | 辅助说明（≤30 字） | ≥正文 1.4 倍 |
| 正文 | 36-44px | 卡片内描述 | ≥标注 1.3 倍 |
| 标注 | 26-30px | 脚注/提示/来源 | 最小可读字号，不低于 26px |

**层级比例铁律**：焦点元素 ≥ 相邻元素 **2 倍**（大小）+ 至少一项额外对比（颜色/明暗/位置居中）。达不到 2 倍，就缩小相邻元素，不是放大焦点。

**间距网格**（8px 基准）：
- 卡片内 padding ≥ 43px（已有，保持）
- 卡片间距 ≥ 卡片高度 20%（已有）
- 标题与内容间距 40-60px（已有）
- 列表行间距 ≥ 24px；图标与文字间距 16px

**留白规则**：
- 标题区顶部 y:200 起（已有）
- 内容区 y:200-1100 集中（已有）
- **每屏至少保留 1 个"呼吸区"**（≥画面 15% 的连续空白，无任何元素）——高级感的主要来源
- 底部 y:1600-1760 为留白缓冲（字幕上方）

**色彩比例**（60/30/10 法则）：
- 主色（背景/大面积）≈ 60%、辅色（卡片/次要）≈ 30%、强调色（焦点/数字/箭头）≈ 10%
- 强调色只用在焦点元素上；次要元素一律降饱和/降明度
- 全屏色彩 ≤ 3 个色系（主/辅/强调 + 黑白灰，已有 V-S13）

### 2.3 一屏一焦点规则（V-R03 的可执行版）

每屏必须回答"观众第一眼看哪"，设计规则：
1. **焦点选择**：该屏最重要的信息（大数字 / 主标题 / 对比中心 / 核心券面）
2. **焦点实现**：三选二——大小对比（≥2 倍）/ 颜色对比（强调色）/ 位置居中或视觉中心
3. **降级处理**：非焦点元素必须主动弱化——字号缩小、饱和度降低、透明 0.6-0.8、或移出视觉中心
4. **反例**：全屏所有元素同字号同明度 = 无焦点 = 必返工

### 2.4 质感四件套（"高级感"的来源，代码层已有组件）

| 项 | 参数 | 状态 |
|---|---|---|
| 暗角 Vignette | 55% 中心透明 → 四角 rgba(0,0,0,0.25) | 已实现，VTemplate 未挂 → **必修** |
| 颗粒 Grain | feTurbulence 噪点，opacity 3.5% | 已实现，未挂 → **必修** |
| 主色调和 AccentOverlay | 背景图叠 palette 主色 soft-light 18% | 已实现，未挂 → **必修** |
| 卡片投影 elevation | 三级投影（浅底/深底两套），全片光影方向一致 | 已实现，须统一取用 |
| 圆角 | 卡片统一 20-24px；图标容器 squircle | IconBadge 已实现，卡片须统一 |
| 背景模板图 | 毛玻璃微虚化 blur 4px + Ken Burns 1.0→1.04 | g02v3 已用，新视频必配 |

> 质感是"全片氛围层 + 元素统一规范"的结果，不是某个单点。代码层组件都在，**缺的是挂载和强制执行**。

### 2.5 参考图拆解模板（AI 拿参考图必须走这个流程）

> 解决根因 A：用户给参考图时，AI 必须按固定框架拆解，拆解结果写进设计稿，禁止"看一眼就放大字体"。

**用户给参考图 → AI 输出以下拆解**（写进设计稿"参考拆解"小节）：

```yaml
参考图: （用户提供，可多张）
拆解结果:
  ① 视觉焦点: 这张图第一眼看到什么？怎么突出的？（大小/颜色/位置）
  ② 区域划分: 画面分几个区？各占多少比例？（上标题/中内容/下留白…）
  ③ 色彩分配: 主色/辅色/强调色各是什么？各占多少？
  ④ 字号层级: 最大的字 vs 最小的字差几倍？层级几档？
  ⑤ 留白位置: 哪里是空的？空多少？为什么空？
  ⑥ 质感细节: 圆角/阴影/纹理/光效？有什么让画面"不廉价"的细节？
  ⑦ 转化到本屏: 本屏布局模式（L-XX）+ 焦点元素 + 借鉴的具体手法（不照搬，只借鉴手法）
```

**纪律**：拆解不出 7 项 = 该参考图没被真正理解 = 设计稿不达标。每屏至少 1 张参考图（或 1 条已提炼的布局模式）。

### 2.6 设计质量四维评分（迭代有基线，不靠感觉）

> 解决"AI 不知道哪里不够"：每次设计稿/无声版，AI 自评 + 用户验收都用同一张评分表，分数不达标不进入下一阶段。

| 维度 | 评分项（0-5 分） | 5 分标准 |
|---|---|---|
| 层次 | 字号阶梯是否符合 §2.2？焦点 ≥2 倍？ | 层级分明，一眼看出主次 |
| 焦点 | 是否一屏一焦点？非焦点已降级？ | 观众第一眼知道看哪 |
| 节奏 | 相邻屏布局模式是否不同？动效是否有错峰？ | 每屏有变化，不重样 |
| 质感 | 氛围层挂载？阴影/圆角统一？留白呼吸感？ | 画面"高级"，不是"会动的 PPT" |

**使用方式**：设计稿完成后 AI 自评四维并写进设计稿；无声版渲染后用户按四维打分（给感受即可，AI 翻译）。任一维 ≤3 分 → 定位到对应规则返工，**不做"整体重做"式模糊返工**。

## 三、用户反馈翻译表（"感受" → "专业指令"）

> 解决用户表达难：说感受，AI 按表翻译成可执行指令。

| 你的感受（大白话） | AI 翻译成什么专业指令 | 对应规则 |
|---|---|---|
| "画面很平/很素" | 层级对比不足：按字号阶梯重排，焦点 ≥2 倍，增加明暗对比 | §2.2 |
| "看起来很廉价/像 PPT" | 质感缺失：检查氛围层挂载、阴影统一、圆角统一、色彩克制（≤3 色系） | §2.4 |
| "不知道看哪" | 焦点分散：明确一屏一焦点，非焦点元素降级（缩小/降透明/降饱和） | §2.3 |
| "字太大了很傻" | 字号超阶：主标题回落到 96-120px，靠留白和对比而非大字号 | §2.2 |
| "太空了/很空" | 留白失衡：内容区填充到 y:200-1100，用装饰/副信息补位（但保留 1 个呼吸区） | §2.2 |
| "太挤了/很乱" | 间距超标：检查 padding ≥43px、卡片间距 ≥20%、列表行距 ≥24px，删减元素 | §2.2 |
| "动效很生硬" | 缓动缺失：非 spring 插值补 EASE_OUT，入场用 spring 或 expo-out | R3 §2 |
| "颜色很脏/不协调" | 色彩失控：主辅强三色比例 60/30/10，强调色只给焦点 | §2.2 |
| "像上一条的翻版" | 同质化：风格五维 ≥3 维不同 + 布局模式换一种 | M2 §2.3 |
| "没有参考图那种感觉" | 参考未拆解：按 §2.5 模板补拆解，把具体手法落进布局 | §2.5 |

## 四、操作流程落地（设计稿新流程）

```
用户给参考图（可选）→ AI 按 §2.5 拆解（写进设计稿）
  ↓
设计稿每屏：选布局模式（§2.1 L-XX）→ 定视觉参数（§2.2）→ 明确焦点与降级（§2.3）→ 填内容
  ↓
AI 四维自评（§2.6）→ 分数写进设计稿 → 人确认
  ↓
代码执行：氛围层必挂 + 阴影/圆角统一 → 无声版渲染
  ↓
用户按四维打分（可只说感受，AI 按 §三 翻译）→ 任一维 ≤3 分定位返工
  ↓
合格 → TTS → 成片
```

## 六、一句话总结

**AI 做不好设计的根因是"没有设计规则可执行"，不是能力不足。** 给它布局模式、参数阶梯、焦点规则、质感标准、拆解模板、评分表——它就能从"放大字体"升级为"按设计语言出图"。这套系统一次建成，之后每条视频都受益，且大幅减少"不满意→重做"的返工成本（token 总账反而更省）。
