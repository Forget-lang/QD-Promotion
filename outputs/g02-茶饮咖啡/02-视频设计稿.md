## 画面风格总览

- **主色**：暖橙 `#FF6B35`（咖啡/茶饮行业，温暖有活力）
- **辅助色**：奶白 `#FFF8F0` / 深棕 `#5D4037` / 绿色 `#4CAF50`（解法/正向）
- **背景**：行业专属背景图（咖啡店内景/咖啡杯特写），高斯模糊 30px + 30% 不透明度 + 暖橙渐变蒙版叠加。只做氛围层，不抢文字的戏。
- **字体**：标题用得意黑（冲击力），正文用阿里普惠体 700（清晰）
- **组件风格**：圆角卡片（16px）+ 轻投影（柔和不硬）+ 图标内联
- **动效**：Spring 弹入（overShoot 轻微），信息逐条出现，节奏明快

### 背景图层级结构

```
┌─────────────────────────┐
│  第三层：文字 + UI 组件    │  代码绘制，最清晰
├─────────────────────────┤
│  第二层：暖色渐变蒙版      │  代码绘制，统一色调
├─────────────────────────┤
│  第一层：行业背景图        │  模糊 + 降透明，只做氛围
└─────────────────────────┘
```

## 转场设计

- **统一转场方式**：交叉溶解（Cross Dissolve），0.4s（12 帧）
- **特殊转场**：S2→S3（痛点→解法）用颜色过渡：红色调 → 暖橙调，配合解法出现的爽感
- **声画同步**：采用 J-cut 方案（13 §2.6），上句尾音 0.4s 淡出，下一句从转场开始满音量进入

## 安全区规范（竖屏 1080×1920）

> 加字幕的视频必须遵守安全区规则，画面内容与字幕不重叠。

| 区域 | 距离 | 用途 |
|---|---|---|
| 顶部安全区 | 距顶部 120px | 避开手机状态栏 + 平台顶部 UI |
| 底部安全区 | 距底部 160px | 字幕区域（48px 字体 + 描边 + 上下留白） |
| 左右安全区 | 距左右各 60px | 避免内容贴边 |

**画面内容活动区**：960 × 1640（x:60-1020, y:120-1760）
**字幕区**：y:1760-1920（字幕在底部安全区内，不侵入内容区）

---

## 字幕规范

- **位置**：底部安全区内居中，字幕基线 y = 1840（距底部 80px）
- **字体**：阿里普惠体 700
- **字号**：48px
- **颜色**：白色 `#FFFFFF`
- **描边**：黑色 3px 描边（保证任何背景都清晰）
- **行数**：最多 2 行，居中对齐
- **最大宽度**：960px（不超出左右安全区）
- **同步**：与口播逐句对齐，语音开始时字幕淡入，语音结束后随转场淡出
