## 5.2 风格配置

```yaml
style:
  palette: caramel          # 焦糖棕 — 精品咖啡馆质感，深棕+奶白+焦糖金
  motion: buttery           # 丝滑黄油 — spring damping=50 stiffness=50，柔缓不弹跳
  typography: impact        # 得意黑粗体冲击 — 标题得意黑900，正文普惠体500
  transition: wipe          # 底部擦入 — 从下往上 wipe，12帧
  hookStyle: contrast       # 左右对比 — 左红右绿VS式分屏
```

**风格五维与旧 G02 对比：5 维全部不同。**

**caramel 配色方案（从 palette.ts PALETTES 读取）：**

- bg（场景背景色）：深咖啡棕 `#2C1810`
- surface（卡片底色）：奶咖色 `#F5E6D3`
- text-primary（标题字）：深棕 `#1A0F0A`
- text-secondary（正文字）：中棕 `#6B4423`
- success（正向/解法）：焦糖金 `#C68B59`

**6 项全部不同，远超 ≥3 项的最低要求。**

### 场景序列对比

| 旧 G02（7 屏） | G02 v2.0（8 屏） | 差异类型 |
|---|---|---|
| S1 hook（question） | S1 hook（contrast） | 类型相同但 hook 子类型不同 |

| S5 grid（6 种券类型网格） | S5 solution（为什么好使，3 个逻辑要点） | **类型不同**：grid → solution |

| — | S8 cta | — |

**差异统计：**
- 新增场景：1 个（S5 solution「为什么好使」）
- 消失场景：1 个（旧 S5 grid「6 种券类型」）
- 重排场景：panel 从第 6 位移到第 7 位
- 同类型结构升级：hook 子类型更换、pain 从单列变左右对比、solution 从单卡片变 3 要点

**结论：场景类型序列差异 ≥ 3，符合放行标准。**

### 叙事结构差异分析

| 维度 | 旧 G02 | G02 v2.0 |
|---|---|---|
| 核心切入点 | 「早鸟次卡填空档」（闲时运营角度） | 「别让顾客充卡，用次卡锁客」（反常识对比角度） |
| 叙事模式 | 痛点 → 功能罗列（早鸟卡 + 6种券 + 数据） | 对比钩子 → 痛点深挖 → 核心方案 → 操作路径 → 逻辑支撑 → 进阶裂变 → 数据透明 → 品牌收尾 |
| 痛点层次 | 1 层（空位浪费 + 打折没利润） | 2 层（3 个问题 × 对应 3 个后果，左右对比式） |
| 方案层次 | 1 层（早鸟次卡一个概念） | 3 层（核心方案 + 为什么好使 + 进阶裂变） |
| 信息组织方式 | 功能清单式（次卡 + 券类型 + 数据） | 逻辑递进式（是什么 → 怎么做 → 为什么 → 还能怎么玩） |
| 行业话术 | 通用咖啡店话术 | 精品独立咖啡馆专属（手冲/吧台/老客社群感） |

**判断：把行业词去掉后，两条视频的结构和内容重合度 < 30%，不属于换汤不换药。**

### S2 · 痛点深挖屏（左右对比式）

```yaml
屏号: S2

  【每行结构】
  ┌──────────────┬───┬──────────────┐
  │  问题（左）   │ → │  后果（右）   │
  │  大图标+标题   │   │  大图标+标题   │
  │  小字说明      │   │  小字说明      │
  └──────────────┴───┴──────────────┘
  
  第一行（核心痛点 1 · 推不动）：
  · 左问题：「顾客抵触」—— 钱包裂开图标 + 「充一次几百块」 + 「怕跑路、觉得掉价，精品店顾客尤其抵触」
  · 右后果：「新客留不住」—— 逃跑人形图标 + 「试一次就走」 + 「永远成不了老客」
  
  第二行（核心痛点 2 · 不推不行）：

  左侧卡片：暗红棕半透明底，浅边框
  右侧卡片：更深的暗棕底，更重的警示感
  中间箭头：焦糖金色，指向右侧（问题导致后果）
  
  视觉风格：每行卡片圆角 20px，轻微投影，图标在卡片左侧，大而醒目
  安全区：顶部 140px（标题），底部 160px，左右 60px

  - 帧 0-6: 背景渐入
  - 帧 6-24: 顶部标题 FadeInDown（motion=heavy，dist=30px）
  - 帧 18-36: 副标题 FadeInUp（motion=buttery，dist=12px）
  
  - 帧 36-66: 第一行左卡片 SlideInLeft（motion=heavy，dist=60px）
  - 帧 48-72: 第一行中间箭头 FadeIn（EASE_OUT）
  - 帧 54-84: 第一行右卡片 SlideInRight（motion=heavy，dist=60px）
  
  - 帧 90-120: 第二行左卡片 SlideInLeft（motion=heavy，dist=60px）
  - 帧 102-126: 第二行中间箭头 FadeIn（EASE_OUT）
  - 帧 108-138: 第二行右卡片 SlideInRight（motion=heavy，dist=60px）
  
  - 帧 150-450: 两行卡片轻微悬浮（错相位正弦浮动 ±2px）
图片素材: 无（纯代码 UI 组件）
图标: wallet-cracked / person-run / hourglass / trending-down
备注: |
  痛点 2 层递进：第一层是「推不动」（顾客抵触充卡），第二层是「不推不行」（老客流失、生意不稳）。
  从 3 行减到 2 行，讲深不讲多，信息密度更集中，15 秒能消化。
  痛点屏动效偏硬偏快，跟方案屏的舒缓形成对比——紧松节奏。
```

#### 深度 4 问（全过才算合格）

- [x] **钩子够不够狠**：「别再让顾客充卡了」—— 反常识开场，直接打破老板的固有认知。充卡是所有咖啡店老板都想过或做过的事，一上来就否定，自然会停下来听「那怎么办」。不是平平无奇的「今天给大家介绍…」。
- [x] **痛点够不够深**：不是只说「充卡不好」，而是说清了「为什么不好」—— 三个问题每个都对应一个后果（门槛高→新客跑了、消耗慢→卡睡死了、矛盾多→口碑坏了），形成完整的逻辑链条，老板感同身受。
- [x] **方案够不够具体**：不是「用次卡锁客」这种空话，而是「十杯次卡、六十天有效期、核销间隔零天每天一次、私密发放给老客、扫码核销、转赠裂变玩法」—— 具体到次数、天数、操作步骤、进阶玩法，老板看完能直接抄作业。
- [x] **有没有「哦，还能这样」的感觉**：有两个惊喜点：① 「次卡比充卡好」的反常识思路；② 「转赠裂变」的进阶玩法（用不完的次数变成拉新机会）。不是平铺直叙的功能介绍。

#### 同质化检查（与旧 G02 对比）

- [x] **切入点不同**：旧 G02 是「早鸟次卡填空档」（闲时运营角度，功能罗列），G02 2.0 是「别充卡用次卡」（反常识对比角度，完整解决方案）。切入点完全不同。
- [x] **内容结构不同**：旧 G02 是「痛点 → 方案 → 功能罗列（6种券） → 数据」的扁平结构；G02 2.0 是「对比钩子 → 痛点深挖（2层） → 核心方案 → 操作路径 → 逻辑支撑 → 进阶裂变 → 数据透明」的多层递进结构。结构有本质差异。
- [x] **行业话术不同**：旧 G02 是通用咖啡店话术（空位、打折、早鸟）；G02 2.0 是精品独立咖啡馆专属话术（手冲、十杯卡、老客社群、品质感）。不是换个行业词就行，而是整个语境都不一样。

**判断**：把行业词去掉后，两条视频的结构、切入点、叙事逻辑完全不同，重合度 < 30%，不存在同质化问题。
