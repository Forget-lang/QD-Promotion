## 二、母题详细设计

### 2.1 背景底
- **选型**：`背景素材/材质肌理/` 暖色系（目前库内暂无适配烧烤的炭火/木纹实景）
- **处理方案**：走 SKILL §五 背景素材入库流程——AI 出规格与检索词，用户找图回传，三关验收后入库
- **检索词建议**：炭火特写、烧烤炉火光、木质桌面俯视、夜市烟火、烧烤食材特写（必须商用授权）
- **氛围**：暖橙色火光、深色底、质感粗粝——跟 g10 的粉柔完全对立

### 2.2 构图与内容区
- 左右边距 120px（安全区硬线）
- 构图：**留白主导 + 一镜一主语**——超大数字 / 超大关键词 / 手机 / 券各占一镜、大留白，不做三栏信息块并排（错层三栏信息块 = 旧 PPT 语法，已随第 4.5 步三层结构废弃）
- 与 g10 差异：g10 是"居中对称两栏 + 卡片"，g11 是"留白 + 大数字大词 + 手机/券证据"——一个柔美卡片、一个图层化电影感

### 2.3 标题承载
- **主标题**：粗黑体 + 大字压屏（字号约 72~88px），左对齐或错层位置，不居中
- **副标题**：标签式胶囊（圆角矩形底 + 小字），挂在主标题左上方或右下方
- **强调字**：用暖色高亮（橙红/金黄），高亮字不超过 2~3 个
- 与 g10 差异：g10 是"双行居中 + 细字对比"，g11 是"粗字压屏 + 胶囊标签"——一个精致、一个粗犷

### 2.4 图层语言（2026-09-15 起升三层结构，替代旧"容器语言"）
- **Atmosphere 氛围层**：炭火底（BG-TEX-002）+ 火星粒子 + 烟雾 + 暗角——永远动、但很慢，只做情绪
- **Typography 排版层**：超大数字 / 超大关键词 / 细线标签 / 大留白——没实拍后最重要的画面力量
- **Product 产品层**：手机 Mockup / 券 / QR——产品是"证据"不是背景
- **禁用**：默认毛玻璃卡当主结构 / 左右两栏信息对比 / 传统流程图框 / 密集 icon（承 SKILL 第 4.5 步设计禁令）
- 与 g10 差异：g10 是"柔美圆角卡片"，g11 是"图层化 + 大数字大词 + 手机/券证据"——载体完全不同

### 2.5 装饰母题
- **火焰图形**：简化几何火焰（不是写实火苗），用作标题锚点或分隔符
- **炭火光斑**：暖橙色散景光斑，叠在背景上增加烟火气
- **点状虚线**：模拟菜单板上的粉笔虚线，用作分隔或引导线
- **禁忌**：不用花、不用曲线柔美装饰、不用渐变光斑（g10 用过了）

### 2.6 色彩与质感配方
- **色板方向**：暖橙+深褐+米白（不在现有 7 套 palette 里生搬，烧烤的暖是炭火暖，不是 g08 火锅的暖橙红）
- **炭火专属色板（hex，2026-09-15 定稿）**：深底 `#120B08` / `#24130C` / `#42180D`；强调 `#F06A24` / `#FF8B38` / `#FFC05A`；文字 `#F7F1EA` / `#C6BDB5`；辅灰 `#81766E`。**避免蓝/紫/荧光绿**（承 SKILL 第 4.5 步色彩基准，本片即纯片默认基准）。
- **主色**：深褐/炭黑（底色）
- **强调色**：橙红/金黄（火光色）
- **中性色**：米白/暖灰（文字）
- **质感**：噪点颗粒感（grain）+ 轻微暗角（vignette），整体偏暗调暖光
- 与 g10 差异：g10 是"粉紫 + 柔光"，g11 是"深褐 + 火光"——色系族不同、质感方向不同

### 2.7 动效语法
- **motion 性格**：`snappy`（干脆利落），不用 bouncy（太弹太柔美）
- **入场**：渐显 + 轻微位移（从下/从侧边推入 20~30px），不是弹跳
- **转场**：`dissolve`（热雾渐隐），不是 g10 的 slide
- **钩子风格**：`contrast` 沿用（本片实验变量是"开口文案"不是"钩子结构"，钩子结构保持对照）
- **节奏**：前快后稳——开头钩子快切、中间讲功能时稳、结尾金句时慢下来
- 与 g10 差异：g10 是 bouncy + slide（弹跳+滑动），g11 是 snappy + dissolve（干脆+渐隐）——动效性格完全不同
