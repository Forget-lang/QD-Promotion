## 视觉定位卡（情绪先行，先于物理载体）

- **核心痛点**：周五夜里翻台三轮、排队叫号，周一晚上半店空桌——火都在周末烧，房租按天交。

## 开工视觉语言隔离声明（动手前锁方向；五轴真图坐实待一屏标杆渲出后并排补）

本片三件事：
- **行业母题**：深夜烧烤档「**手写黑板牌**」语言——街边烧烤档最经典的物料（今晚特价 / 粉笔字 / 手绘框），每屏信息长在一块被炭火光照着的黑板上。不是"邀请卡"（g10）、不是"磁条次卡"（g09）、不是"朱红海浪纹"（g08）、不是"小票/菜单板"（g07）。
- **背景风格族**：材质肌理族 · `BG-TEX-002 炭火虚焦肌理`（暖橙红炭火、重度虚化、深底浅字；与 g10 粉晕光弧浅底、g09 深蓝光斑、g08 朱红海浪纹天然区隔）。
- **转场字幕风格**：转场 `wipe`（g06 用过通用直线擦除；本片边缘形态=**粉笔擦粗边横扫 + 余温橙边**——行业专属边缘按母题扩展，落法在第 5 步实现）；钩子 `contrast`（同一家店两种夜：周五满座 vs 周一空桌——g10 contrast 是"群发 vs 转赠"价值对比，标签同、叙事不同）；motion `snappy`（顿挫贴炭火爆点）。

## 三层视觉结构（第 4.5 步执行口径预告）

- **L1 氛围层**：炭火虚焦底缓推 + 火星粒子缓慢上浮 + 光晕呼吸——永远动、很慢，不碰文字可读性。
- **L2 排版层**：超大数字 / 超大关键词 + 粉笔细线 + 大留白——"开奖感"数字是本片画面力量核心。
- **L3 产品层**：手机领取页（倒计时 → 抢到手气）+ 券面 + 核销台——产品永远是证据，不是背景。

## 纯 Remotion 片硬约束自查（§4.5 清单）

- 禁用依赖：烧烤店街景、排队人群、老板/顾客人物、烤串实拍、夜市场景照——零假设，画面全部由 文字/数字/UI/图形/动态关系 完成。
- 可用资产：炭火背景（一张底）· 手机 Mockup · 券 UI · QR · 文本 · 数字 · 线条 · 几何 · 火星粒子 · 烟雾/Glow。
- 一镜一主语；语义动效（开抢→倒计时归零、抢到→面额揭晓、时段外→券面压暗、核销→券消失）。

## 与 g10 的 ≥3 处非颜色结构差异（声明版；真图坐实后回填 ✔）

1. **栅格**：g11 = 通栏单牌三分带（标题带/信息带/结论条）；g10 = 左右双段（55% 卡 hero + 右引线注释组）+ 底部通栏注意卡。
2. **容器形状**：g11 = 横版黑板牌（深板面 + 木框 + 粉笔手绘框）；g10 = 竖版邀请卡（缎带顶 + 撕齿 + 磁条感收口）。
3. **标题承载**：g11 = 超大数字粉笔质感 + 手绘下划线（数字主导）；g10 = 得意黑大标题 + 紫分隔线（标题主导）。
4. **入场语法**：g11 = 粉笔逐笔写出 + 木牌挂入；g10 = 整卡递入 + 字段擦入 + 引线浮出。
5. **明度结构**：g11 = 深底浅字 + 火光局部亮斑；g10 = 浅底深字 + 柔光满铺。
