## 视觉定位卡

- **核心痛点一句话**：朋友聚完这一顿，老板缺的是让下一顿继续发生的经营关系。
- **情绪关键词**：热·真实·烟火气·克制·社交
- **视觉关键词**：夜宵电影感·深色炭火·暖橙·浅景深·少 UI
- **禁止出现**：SaaS PPT·蓝紫科技风·全屏毛玻璃·密集 icon·传统流程图
- **背景素材张数**：1 张

## 母题名

**「一桌人的下一顿」**

## 核心视觉关系

不是“优惠券展示”，而是**一张券在两部手机之间发生关系**：

`A 手机领券 → 券被转给 B → B 核销 → A 手机收到奖励券`

整个视觉系统围绕“券的关系变化”展开。

## 三层视觉结构

### Layer 1 · Atmosphere

- 夜间烧烤摊的暖橙/炭火氛围，但不做写实门店场景。
- 低速火星、烟雾、暖光边缘，只承担时间与情绪。
- 背景永远慢，不与 UI / 大字争主语。

### Layer 2 · Typography

- 主视觉关键词围绕“下一顿 / 转给朋友 / 核销 / 再得一张”。
- 每个镜头只保留一个主关键词。
- 数字只在机制确实需要时使用，不制造虚假优惠数字。

### Layer 3 · Product

- 两部手机是主要证据实体。
- 优惠券是运动中的“关系对象”，不能做成静态信息卡墙。
- 核销通过状态变化表达，奖励通过“新券生成”表达。

## 视觉禁令

- 不做传统流程图“1→2→3→4”。
- 不做左右两栏人物对照。
- 不把转赠拆成四张卡片列表。
- 不用海报式节日大字覆盖整个屏幕。
- 不用“优惠券卡片墙”讲产品。
- 不用虚构顾客头像、虚构聊天记录或虚构门店评价。

## 记忆点

**同一张券离开 A 手机后，不是消失，而是在 B 手机变成下一次到店的理由；B 核销之后，新的券又回到 A。**

这条“离开 → 到店 → 回来”的循环就是本片的视觉签名。
