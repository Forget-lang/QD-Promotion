## S2 · 道理屏（讲道理）

**叙事职责**：idea——先立错（老办法没用）再给对（损失厌恶）
**本屏讲哪一项设置**：无（机制层，讲道理）
**这一环商家在想什么**：打折送啤酒充卡都试过，还是留不住人，到底差在哪
**口播（承第 3 步）**：
1. 老板们最常干的三件事：打折、送啤酒、充两百送一百。
2. 有用吗？没用——客人一看就知道你要套路他，充卡那点钱他还怕你跑路了呢。
3. 真正能把人留住的，不是让他掏更多钱——是让他觉得，自己在你这儿"有点东西没花完"。
4. 人对"即将失去"的难受，比"可能得到"的高兴强得多——这就是为什么，一张快过期的券，比十句"欢迎再来"都管用。

**口播句 → 指向**：
- 句1 → 三个老办法大字逐个出现

- 句3 → 超大关键词「有点东西没花完」推出
- 句4 → 结论「一张快过期的券 > 十句欢迎再来」

**信息全景**：① 三老办法「打折 / 送啤酒 / 充卡」被打叉 ② 关键词「有点东西没花完」③ 结论句

## S3 · 证明屏（核销奖励机制演示）

**叙事职责**：proof——用真实机制过程（核销成功 → 自动新券）证明"留住人"
**本屏讲哪一项设置**：开启核销后赠券（顾客侧核销奖励：到店核销后再得本券一张）
**这一环商家在想什么**：怎么让"这单吃完"自动变成"下单一由头"
**口播（承第 3 步，2026-09-15 去虚构案例改机制演示）**：
1. 真正能把人留住的，不是坐等回头客——是把"核销"变成下一单的开始。

## S4 · 落地屏 1（手气券怎么设）

**叙事职责**：落地 1——手气券的每一项设置怎么填、为什么这么填
**本屏讲哪一项设置**：手气券（金额区间 / 消费门槛 / 有效期 / 可用时段 / 发放方式）
**这一环商家在想什么**：怎么用低门槛，把过路客变成夜宵常客
**口播（承第 3 步，句1 带一次品牌名）**：
1. 用「券到卡包」做这套玩法，其实就三张牌。
2. 第一张，手气券——就是金额随机的券，像刮奖一样。
3. 怎么设？金额三块到三十块随机，高了心疼、低了没感觉，这个区间正好。
4. 有效期给三天——趁热用，太长了忘、太短了赶不来。
5. 可用时段定在晚五点到凌晨两点——烧烤就是夜宵生意，白天用不上。
6. 发放方式选公开领取——桌角贴个码，坐下扫一下就能领，门槛越低领的人越多。

**口播句 → 指向**：
- 句2 → 标题「第一张牌 · 手气券」+ 券卡
- 句3 → 超大数字「3 元 ~ 30 元」
- 句4-5 → 数字「3 天」+「17:00 – 02:00」
- 句6 → QR 码 + 关键词「公开领取 · 人人不落空」

**信息全景**：① 「第一张牌 · 手气券」② 3 元~30 元随机区间 ③ 3 天有效期 ④ 17:00–02:00 时段 ⑤ QR 桌码公开领取

## S5 · 落地屏 2（核销赠券 + 转赠奖励）

**叙事职责**：落地 2——核销后赠券（锁客）+ 转赠奖励（裂变）两个联动怎么跑通
**本屏讲哪一项设置**：开启核销后赠券 / 允许转赠 / 开启转赠奖励 / 转赠奖励券（兑换券）
**这一环商家在想什么**：让老客带新客，自己不用当"推销员"
**口播（承第 3 步）**：
1. 第二张牌更狠——核销后赠券，就一个开关，一开，客人核销完自动再得一张。
2. 核销一张、送一张，再核销、再送一张——客人手机里永远有一张你家的券。
3. 第三张牌，转赠奖励。客人把券转给朋友，朋友到店核销了——转的那个人手机里自动收一张奖励券。
4. 奖励用什么？用兑换券，比如"招牌烤串一把"。
5. 为什么是烤串不是满减券？满减券还要凑单，烤串一把是实打实的东西——朋友省了钱，他白得一把串，他当然愿意转。

**口播句 → 指向**：
- 句1 → 开关 Toggle 打开 + 手机核销后新券生成
- 句2 → 关键词「永远有一张券」
- 句3 → 券从老客手机横移到朋友手机
- 句4-5 → 朋友核销 → 奖励券「招牌烤串一把」回流到老客手机

**信息全景**：① 「核销后赠券」开关 ② 券转赠横移 ③ 奖励券「招牌烤串一把」回流 ④ 关键词「永远有一张券」
**k 字段真值**：开启核销后赠券 / 允许转赠 / 开启转赠奖励 / 转赠奖励券（兑换券 · 兑换内容「招牌烤串一把」）
