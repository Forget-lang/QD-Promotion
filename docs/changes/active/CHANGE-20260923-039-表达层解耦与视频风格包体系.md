# Change Contract

## 一、基本信息

- changeId：`CHANGE-20260923-039`
- 标题：表达层解耦——视频风格包体系与 AI 导演驱动（行业线）
- 负责人：用户（方向与拍板）／AI（侦察、契约、迁移、验证）
- 范围：`global`

## 二、Goal

一句话：把**画面的诞生权**从"Remotion 组件能力"移交给"导演＋可插拔风格包"，使同一份行业攻略能按不同风格产出；产品真值、平台红线与功能可理解性一寸不让。

- 现状根因（用户判断，2026-09-23）：创造力被锁在"怎么排列组件"，产出必然收敛为卡片/手机模型/图标/字幕的排列组合 ⇒ 千篇一律、像说明书与 PPT、观众提前预判下一幕。
- 变更边界：**只改表达层**。内容层（行业场景、经营问题、营销方法、产品能力与用法）与真值/红线共享层不动。

## 三、新口径 New Policy

1. **五层分工**（2026-09-23 用户补正：以后不能再只有一个"视觉规则"，必须显式分层，否则新增风格必然与真实性规则打架）：

```text
事实真实性层  产品界面/字段/数字/规则/流程   spec/APPLET + D-1 截图 + R10    ← 不动；只认真实资产
创意表达层    场景/人物/环境/情绪/隐喻/空间   AI 可自由创作（边界＝§三.5 三层协议）
风格 Skill 层  怎么导演这类视频              R9（唯一 Owner）＋ 风格包（可插拔件）  ← 收口＋扩展
实现能力层    怎么画出来                    Remotion ｜ 生成式 ｜ 白板引擎 ｜ 后期合成  ← 并列手段
验收层        什么算过                      gate-all ＋ 风格包「验收位图」声明    ← 加一维声明
```

2. **风格＝导演能力包**（不是一个万能流程，是可插拔家族）。每个风格包必须填满十栏：① 身份 ② 叙事法 ③ 视觉语言（含本风格允许/禁止的画面元素）④ 素材生成法（画面从哪来＋禁止生成清单）⑤ 产品证据位 ⑥ 红线落位图 ⑦ 验收位图（逐条声明闸门适用性）⑧ 实现说明（执行工具与工程落点）⑨ 交付物清单 ⑩ 隔离与轮换。其中 ③④ 受 §三.5 L2 约束、⑤ 受 L1 约束、⑥ 受 L3 约束。

3. **画面来源由所选风格包定义**；AI 生成（人物／场景／漫画角色／氛围／隐喻物）为**合法手段**。用户 2026-09-23 明示：确实没有外部图片素材，要靠 AI 能力发挥；即使初期效果不佳，也以迭代进化替代预先限制。

4. **解耦验收判据**：新增第 N 个风格 = 只新增一个风格包文档 + 在注册表登记一行；若还需改动别处，即未解耦。

5. **AI 创作边界协议（三层，单源，不得复制进各风格包）**——取代旧的"AI 生成限制"式绝对禁令。用户 2026-09-23 裁定：**原则保留、表达升级**——从"禁止 AI 生成"升级为"区分事实与表达"；产品事实必须真实，视觉表达可以自由。原两条绝对禁令按此重写：
   - **L1 不可生成（产品真实性层）**：产品界面、功能字段、金额数字、规则、操作流程、数据结果——来源只能是真实产品资产：真实产品截图（D-1 登记且 `current-verified`）／按 R6 像素真值在实现层复刻／真实录屏。**AI 不得生成或推测**。
   - **L2 可以生成（创意表达层）**：商业场景、人物、环境、情绪、隐喻、空间、视觉故事。抽象手机、光影中的手机轮廓、顾客收到福利的情绪场景等**均为合法**（旧禁令把"产品界面"扩大成了"所有涉及产品的视觉"，本协议纠正之）；但不得出现可被误认为真实产品的界面。
   - **L3 信息层统一控制（文字归属）**：① **信息文字**（需要观众理解、承担信息传递职责的字）→ 一律由实现层排版生成，并接受与现有上屏文字相同的红线与真值检查；② **品牌文字** → 沿用既有 `brand_display` 口径（画面零品牌、口播必提一次）；③ **环境文字**（招牌／海报／包装等氛围字）→ 允许存在于生成画面，但**不得承担信息传递职责**，且**默认须不可辨读**（虚焦／远景／低对比）——若确需可辨读，则视同"信息文字"回到排版层；④ 环境文字同样受红线约束（不得出现导流词、极限词、站外生态词、品牌名）。
   - **能力边界（如实标注，不假装能验）**：L1 由风格包「产品证据位」栏 ＋ 人工逐屏对账把关（`check-ui-truth` 现仅覆盖上屏字段名，不识生成界面）；L2 由人判 + 审查风格包声明的"禁止生成清单"；L3 的信息文字受现有红线闸门约束，环境文字主要靠人判；识别 AI 画面的机检增强留后续事务。

6. **防新模板化**：① 同风格不得连续复用（先记录、后机检：每片必须声明所用风格 id）；② 相似度/布局指纹闸门的"上一条"基准改为**同风格内比较**，跨风格不比较；③「母题一页」机检改为**由风格包声明是否适用**。

7. **风格清单与声明源**：唯一落在 `scripts/ref-registry.json`（**新增 `styles` 维度，不新建第二注册表**）。未声明闸门适用性的风格 = 硬错误（沿用 `EXPLICIT_REQUIRED` 机制），不得静默继承为 Remotion 帧设计的判据。

8. **入口不变**：`AGENTS.md` 仍是唯一 AI 入口；行业线唯一作业 Owner 仍是 `SKILL.md`（风格包是 SKILL 与 R9 之间的可插拔件，不构成第二流程、第二入口）。
