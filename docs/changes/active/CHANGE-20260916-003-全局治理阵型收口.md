# CHANGE-20260916-003 · 全局治理阵型收口

- 状态：MIGRATING
- Issue：#3
- 目标：把“先统筹全局、后局部执行”的原则升级为仓库最高治理戒律，彻底降低文档维护成本，杜绝 Owner/入口/规则/历史边界反复漂移。

## 1. 最高原则

> **先察全局，后定阵型；先立中军，后分兵执行；先清旧阵，后布新阵；任何局部修改，不得破坏全局唯一性、边界、Owner、入口和历史/当前分层。**

## 2. 六条不可破戒

1. 任何规则必须有明确落点。
2. 任何落点只能有一个 Owner。
3. 任何引用只能指向 Owner；非 Owner 只能解释、引用、导航，不得重新定义同一规则。
4. 任何替代必须清理旧阵：新口径进入 Owner 后，旧口径必须删除或进入明确的 deprecated registry，不能长期并存。
5. 任何历史必须退出当前指挥链：archive/changelog 只能提供证据与回顾，不得成为当前入口、当前规则或当前状态源。
6. 任何全局改动必须先完成战场侦察与影响面布阵：资源、Owner、规则、入口、依赖、重复、冲突、断档、当前/历史边界、P0/P1/P2，再进入 Migration。
