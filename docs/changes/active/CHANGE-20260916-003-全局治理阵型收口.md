## Goal

把“规则 / Owner / 入口 / 当前 / 历史”五类边界彻底厘清，并明确“用户怎样启动 AI 工作”与“AI 进入仓库后怎样接管”是两个不同角色：前者只是个人工作控制台，后者才是仓库自动入口。

## 新口径 New Policy

> **先察全局，后定阵型；先立中军，后分兵执行；先清旧阵，后布新阵；任何局部修改，不得破坏全局唯一性、边界、Owner、入口和历史/当前分层。**

本事务确认：

1. 任何规则必须有明确落点。
2. 任何落点只能有一个 Owner。
3. 任何引用只能指向 Owner；非 Owner 只能解释、引用、导航或提供证据。
4. 任何替代必须清理旧阵；不能长期新旧并存。
5. 任何历史必须退出当前指挥链。
6. 任何全局改动必须先完成战场侦察与影响面布阵，再进入 Migration。
7. `AI工作启动指令.md` 是**用户自己的工作控制台**，只提供开工口令与任务模板，不定义项目规则，也不承担项目入口职责；`AGENTS.md` 是**AI 进入仓库后的唯一自动入口**。
