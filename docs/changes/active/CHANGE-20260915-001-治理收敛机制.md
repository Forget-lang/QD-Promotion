# Change Contract

## 一、基本信息

- changeId：`CHANGE-20260915-001`
- 标题：建立全局变更收敛机制，降低用户监督成本
- 负责人：内容与视觉方法论负责人
- 范围：`global`
- 状态：`MIGRATING`

## 二、Goal

把“用户提出全局想法”从普通文档修改升级为可追踪、可验证、可关闭的迁移事务，避免新旧口径并存、规则只新增不清理、完成状态只能靠用户反复追问确认。

## 三、新口径 New Policy

以后所有跨片、跨行业、共享组件、全局方法、规则或流程变更，都必须进入 Change Contract → Impact Map → Migration → Verification → Closure 生命周期。

用户只负责确认方向与最终视觉；执行 AI 负责迁移与自证；机器负责机械约束；涉及视觉的事项必须提供真实产物证据。

## 四、Replace

- “改几个文档 + 跑一次 gate + AI 口头说已落实”的非事务式变更方式。
- 只新增新规则、不检查旧规则是否回潮的做法。
- 用户通过重复追问确认执行是否完整的工作方式。

## 五、Remove

- 将“已完成”定义为“AI 自评完成”。
- 将单次 grep 命中为零视为语义迁移完成。

## 六、Preserve

- 现有 `AGENTS.md` 决策层/执行层分离。
- 现有 `ref-registry.json` 的唯一口径、废止话头机制。
- 现有 `gate-all`、负向测试、真图审批与整改对账单。
- 历史已交付视频与历史 changelog 不回溯重做，除非另有明确重制决策。
