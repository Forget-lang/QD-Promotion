## 二、Goal

## 三、新口径 New Policy

1. `gate-all` 文字安全区探针闸门支持 **`safeAreaWaivers`** 豁免（`scripts/ref-registry.json`，键＝片号 `gXX`，从最新静帧路径提取）：命中且原判失败 → 该行转 `⏭️ 已裁放行（批准人）· 原判照旧显示 ｜原msg｜理由`——**措辞与尺子豁免行逐字同构**。
2. 探针本体 `scripts/probe-safe-area.mjs` **零改动**：原判照旧独立可复核（豁免只发生在 gate-all 汇总层，不吞检查器的真实输出）。
3. g11 两道红各登记一条豁免（`motionWaivers`＋`safeAreaWaivers`），`approvedBy`＝用户 2026-09-18（g11 发布后拍板「都放行」），理由含完整诊断依据。
4. 豁免按片号匹配：g12 及以后的新片**天然不命中**，探针与尺子对其全效力。
5. 探针判据缺陷（明亮纹理假红）**仍登记为已知待修项**——本事务放行 ≠ 修判据；未来若在别的片复发，另立事务修判据（总纲 :63 判例：应修检查器而非改合法产物）。
