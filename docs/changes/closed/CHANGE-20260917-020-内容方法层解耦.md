## 三、新口径 New Policy

**中军军令（契约级原则，三个 Owner 共同服从）**

> **五拍规定"认知职责"，不规定"表达方式"；洞察规定"理解机制"，不直接规定"台词"；爆款规律提供"可选传播策略"，不提供"每片必须执行的模板"。**

1. **五拍＝认知功能骨架（PRESERVE + 升格）**：五拍描述"这一段内容要完成什么认知任务"——吸引／保持／理解／相信／得到，**不规定用什么写法完成**。「错误示范」「生活类比」「不是 X——是 Y」「定律句」等具体手法**全部从五拍解耦**，不得再作为某拍的默认形态。
2. **双入口＝设计入口，不是两种模板（REPLACE）**：讲道理/理解段的进入方式有**机制入口**（先定机制再找情境）与**场景入口**（先有具体行业情境再回指机制）两条通道；两者是**设计入口**，不得固化为两套可套用的模板，也不得要求每片说明"我走的是哪条通道"。
3. **18 通则＝候选传播规律／研究索引（PRESERVE 本体，REMOVE 必用性）**：通则回到"候选规律 + 研究索引"身份；**删除"每片至少各落一条""全链参与"类作业式要求**。禁止用"任选 N 条"等形式变相恢复配额。
4. **写法原则＝可选表达工具（REPLACE）**：写法条目是可选工具，不是必过清单；并新增纪律——**上一片使用过的表达方式，不构成下一片的默认选择**（不是禁止复用，而是必须重新证明"这次为什么仍然适合"）。
5. **洞察库用途重定义（REPLACE）**：定律句＝**理解机制的索引语言**，不是可直接复制的口播语言。层级链条钉死：`定律 → 机制理解 → 当前行业/人物/情境 → 选择表达形态 → 原创表达`。**切断"定律→台词"直连**；不删除定律句、不改写成术语表。
6. **讲法形态空间（ADD 到洞察库机制旁，不新建 Owner）**：属**知识资产完整度要求**（不是生产配额）——每条机制必须具备表达形态空间，**至少有两个已被明确区分的可用实现示例**（观察型／故事型／算账型／反例型／现场型／对话型等，按机制实际可承载者列）；单条片只需选用适合它的那一个。
7. **表达形态选择及理由（ADD 到既有内容输入包）**：本片选择了什么表达形态、为什么；上一片用了什么、本片为什么继续用或主动避开。**是选择证据，不是数量配额**——不得写成"每片必须选择 N 种"。
8. **Pattern 证据纪律（RECOVER）**：回收旧技能包 §6 的研究纪律——高频≠有效；Pattern 需独立案例支持；高表现与普通表现需有对照；候选规律与已验证规律分层；**自己的数据可以推翻外部语料得到的假设**。只回收研究方法论，不复活评分器／拆零件 RAG／旧生产流程。
