## 三、新口径 New Policy

1. **导演稿＝新架构片的硬要求**：凡**声明了 `styleId`** 的片（即 039 新架构下的片），其 `08-R9视觉决策卡.md` 必须含「导演稿」节，节内逐项含 **叙事结构／观看动力／悬念／转折／情绪曲线／信息释放顺序** 六项判据关键词 ＋ `styleId`。未声明 `styleId` 的片（g06–g11 历史片）**按旧口径跳过、不回溯**；尚无新架构片时输出"接线就位、待首片"。
2. **爆款检索动作（升级）**：检索同类语料时不只 grep 关键词——① 使用语料自带**标注字段**（`domain`／`tags`／`hook_type`／`structure`／`proof_devices`／`retention_devices`）；② **分层抽样**：≥3 篇同赛道 Tier A（点赞 Top 10%）＋ ≥1 篇低表现做**对照**；③ 每案例按 `内容资源调用协议.md` §4 七问记录（含"什么不能迁移"）；④ 结论回填内容输入包、通则修订回流 `爆款整片解剖.md` 生命周期节。
3. **图文线版式归属判定**（登记，不改现状）：图文（抖音图文／小红书图文／搜狐长文）的版式与字体规范属**发布线共享规范**（`SKILL.md` 第 7 步）；风格层服务**视频表达**——若将来要为图文做"版式风格包"，是独立议题（另立事务）。
4. **清旧验收标准**：检查集内逐文档产出"保留／改／迁／删／冲突／断档"结论；旧观念复扫归零（允许废止注记）；新发现只登记不扩范围。
