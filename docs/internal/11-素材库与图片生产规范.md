# 11 · 素材库与图片生产规范

> 本文档定义素材库有什么、怎么取用、AI 生图规则、文章/视频配图规范。
> **代码怎么引用图片、路径引入机制**，见 13 §4。
> **封面来源流程与尺寸**，见 07 §3。
> **红线/合规**，见 `quandao-content` skill §二。

---

## 1. 素材库结构

仓库根目录下，与 `docs/` 同级：

| 目录 | 角色 | 内容 | 数量 | 维护方 |
|---|---|---|---|---|
| `商用字体/` | 字体库 | 阿里巴巴普惠体/得意黑/阿里妈妈方圆体等，已 bundle 6 个文件到 `video/public/fonts/` | 33 个字体文件 | 人（AI 可建议补充） |
| `背景素材/` | 背景图库 | 古朴风格 15 张 + 小红书风格 20 张 | 35 张 | 人 |
| `图标素材/图鱼素材/` | 纹理与装饰 | 纹理图案（PNG/JPG/GIF，数字命名），可作 UI 卡片底纹/装饰 | 771 个 | 人 |
| `插图库/` | 情境插画 | AI 生成经人确认后归档，当前为空 | 0 | AI 生成 + 人确认 |

> `截图素材/` 已于 2026-08-14 删除。当前制作不使用截图、不显真实产品 UI（非永久约束）；事实来源始终是同级 `../applet/` 代码。

### 1.1 取用规则

**AI 制作时按类取用，不扫全库**：
1. 主文档只写"库名 + 取用规则"，不列具体文件名；
2. 视频主视觉优先用代码 UI 组件和代码装饰（DotGrid/GlowOrb），不依赖图片素材；
3. 已确认素材入库后，引用只说"从插图库取 XX 风格插画"，不读全库。

**各库取用细则**：

- **背景素材/**：封面与视频背景层可选。AI 列出需求（风格/色调/构图），人在子目录中浏览选择。库不足时从 Unsplash/Pexels/Pixabay 等 CC0 源补取（须确认可商用）。视频使用时复制到 `video/public/backgrounds/gXX/`（路径引入机制见 13 §4.1）。
- **图标素材/图鱼素材/**：视频场景优先用代码内联 SVG 图标库（`icons.tsx`）和代码装饰。确需纹理底纹时，AI 输出需求（图案类型/颜色/平铺方式），人浏览选取后复制到 `video/public/textures/gXX/`（13 §4.1）。
- **商用字体/**：封面字体优先用本库已授权字体；视频 Remotion 字体规范见 13 §2.3（字体性格映射见 13 §3.1）。方圆体仅 400 单一字重，层级靠字号区分。
- **插图库/**：已入库插画按场景标签复用。当前为空，主视觉用代码 UI，AI 生图仅作补充（见 §3）。
- **新增图标**：先用 Icon MCP Server（`.mcp.json` 已配置）的 `search_icons` 从 Element Plus + Ant Design 检索（无需 Key），搜不到用 `generate_icon` AI 生成（需 `DASHSCOPE_API_KEY`），返回 SVG 转内联组件加入 `icons.tsx`（见 13 §8.3）。禁止直接引用外部 SVG/CDN。

## 2. 「确认即入库」机制

- AI 生成的图片（插画/过渡元素），**必须经人确认**后才归档进对应库，后续直接复用。
- 未确认前仅作「待确认草稿」留在当次交付物中，不进公共库。
- 人补充的真素材（门店实景照等）也按对应目录归档，在交付物「素材清单」中登记。

## 3. 画面元素规范

**原则**：视频与文章配图以**代码驱动 UI 组件**为主视觉，配合商用字体排版 + SVG 内联图标 + 关键字大字标题。AI 生图原则上不用于主视觉（质感不可控、与代码 UI 风格不统一）；元素可增删重组，无强制组合。

| 元素 | 来源 | 规范 |
|---|---|---|
| **UI 组件** | Remotion 代码绘制 | 卡片/对比面板/流程图节点/数据指标卡/列表；颜色有语义（绿=解法/红=痛点/橙=强调/青=科技）；不画不存在的功能界面 |
| **商用字体** | `public/fonts/` | 得意黑=冲击力标题（900）、普惠体=正文层级（500-800）、方圆体=亲和场景（400，单一字重）；必须本地 `@font-face` 加载 |
| **SVG 图标** | `icons.tsx` 内联 | 单色描边风格统一；新图标走 Icon MCP Server 流程（13 §8.3）；不引用外部图标文件/CDN |
| **关键字** | 口播稿提取 | 每屏 1 个核心词/金句（≤14 字最佳）；大字标题 + spring 入场；数字以 00§6 为准；禁极限词；不凸显品牌名（07 §5） |
| **纹理/底纹** | 图鱼素材（可选） | UI 卡片底纹/装饰层；优先用代码 DotGrid/GlowOrb 零素材装饰 |

**AI 生图定位**：仅当某屏确需情境插画且代码 UI 不足以表达时，AI 可生成草稿，附 §4 可用性声明，人确认后入 `插图库/`。风格锚定避免跳脱显廉价。

## 4. AI 生成图可用性声明（强制）

每张 AI 生成的图片，交付时必须附声明：

```
【AI 生成 - 待你确认】
文件：xxx.png
类型：情境插画 / 氛围背景 / 转场元素
用途：用于某 G 类行业视频第 X 屏 / 搜狐长文配图
我的可用性初判：可直接用 / 需调整 / 不建议
风险点：文字是否有误、风格是否统一、是否误增功能界面元素、是否过度艺术加工导致失真
```

人检查后回「可用 / 不可用 / 改这里」，AI 据此迭代。AI 不替人拍板"这张能用"。

## 5. 文章配图规范

- 搜狐长文配图与视频统一视觉语言（代码 UI + 商用字体 + 关键字），**不混真实截图**。
- 每篇交付物带「素材清单」小节：UI 组件/字体来源说明 + （若有）图片素材（来源库路径或外部来源 + "AI 生成·待确认/已入库"标注）。

## 6. 跨平台合规：小程序码边界

> 完整红线见 skill §二。本节为小程序码边界执行细则。

- **仅微信生态可用小程序码**：视频号、朋友圈、社群、企微、官网、线下物料。
- **抖音/小红书/搜狐严禁小程序码**：封面、视频画面、文章配图均不得出现小程序码或任何微信系二维码（会被判站外导流）。CTA 用文字「券到卡包」+ 账号资料位承接（07 §5）。
- logo 与「券到卡包」文字角标在三平台均可用。

## 7. 缺口与补充

- `插图库/` 为空：以代码 UI 为主视觉，AI 生图作补充（待人确认入库）。
- `背景素材/` 35 张可用，不足时从 CC0 源或会员站补取（须商用授权）。
- AI 需要而库里没有的素材，列「素材补充清单」交人，人找/拍后归档；推荐补取渠道见 07 §3。
- 封面来源流程见 07 §3（AI 从背景素材索取→无则出引导→人制作→AI 核对）。

## 8. 视频图片管理

- **资产类（插画/背景）**：AI 生成后先作「待确认草稿」留 `outputs/gXX-行业/`，附 §4 声明；人确认后归档进对应库（§2）。
- **过程/临时类（预览帧、静帧导出、中间图）**：留 `video/.cache/preview/`，不进资源库、不进 outputs/，可随构建清理。
- **视频引用的本地素材**：已从根目录复制到 `video/public/` 对应子目录（13 §4.1 路径引入机制），无需重复操作。
- **封面**：随交付物存 `outputs/gXX-行业/`；人确认后优质封面底图可提升进 `背景素材/` 复用。
