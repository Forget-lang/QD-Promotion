# 11 · 素材库与图片生产规范

> 本文档定义「券到卡包」宣传运营的**素材目录结构**、**「确认即入库」机制**、**画面元素规范（代码 UI 组件 + 项目商用字体 + 关键字，AI 生图原则上不用于主视觉）**、**AI 图可用性声明**，以及文章/视频的配图规范。
> 与 10（视频）、07（封面）、04（红线）配套。所有配图相关工作以本文档为准。
> **封面机制（2026-08-17 统一口径）**：封面视觉由 **AI 先从 `背景素材/` 索取、无合适时 AI 输出「详细引导」指引用户到创客贴等优秀设计网站查找制作（非代码生成、非 AI 生图主视觉）**，与视频 Remotion 代码模板是两套不混用资产；**新视频方案以代码驱动 UI 组件 + 项目商用字体 + 关键字等元素自由组合呈现，无截图需求、原则上不 AI 生图主视觉**（见 10/本 §3）；AI 提供封面文案包（系列条/主副标题/角标）与素材库推荐（商用字体/图标）作为引导的一部分，用户在创客贴等优秀设计网站完成设计、回传 png 后 AI 核对合规收口。资源库随此模式不断积累丰富（详见 07 §3 前置约束）。

| 目录 | 角色 | 内容 | 维护方 |
|---|---|---|---|

### 1.1 素材按类取用规则（防上下文膨胀）

**取用纪律（AI 制作时按类取用，不扫全库）**：
1. 主文档（04~12）只写"库名 + 取用规则"，不列具体文件名；
2. AI 制作时"按类取、按需读"，不把整库路径塞进脚本/上下文；
3. 已确认素材入库后，引用只说"从插图库取 XX 风格插画"，不读全库；视频主视觉优先用代码 UI 组件，不依赖插画库。

**各库取用细则**：
- **背景素材/**：封面与视频背景层；库不足时 AI 生成或从 Unsplash/Pexels/Pixabay 等 CC0 源补取（须确认可商用）；AbsoluteFill 铺底 + 压暗，保证上层文字可读。
- **图标素材/**：AI **不扫描全库列路径**；优先用已接入的 Icon MCP Server 按名检索（`search_icons` / `generate_icon`），或按关键词在「图鱼素材/」等子类定向查找；人可后续按行业建子目录（如 图标素材/餐饮）以便检索。
- **商用字体/**：封面字体优先用本库已授权字体，亦可按需补充其它可商用字体；仅要求可商用授权；视频 Remotion 字体规范见 10/11。
- **插图库/**：已入库插画按场景标签复用，AI 只补缺口；主视觉优先用 Remotion 代码 UI + 项目商用字体 + SVG 内联图标。
- **截图素材/**：已于 2026-08-14 由用户删除；当前制作不使用截图、不显真实产品 UI（与 MEMORY §3、`quandao-content` skill 红线一致）。如未来需回查产品真实界面，须先与用户对齐；事实来源始终是 `applet/` 代码。

## 2. 「确认即入库」机制

- AI 生成的图片（插画 / 过渡元素 / 封面），**必须经人确认**后，才归档进对应库（见 §1），后续直接复用，不再重复生成。
- 未确认前，图片仅作为「待确认草稿」停留在当次交付物中，不得进入公共库。
- 人主动补充的真素材（门店实景照、实物图等）也按对应目录归档，并在交付物「素材清单」中登记。
- 入库即意味着该素材可跨选题复用，AI 后续引用时标注来源库路径即可。

## 3. 画面元素素材规范（代码 UI 组件 + 项目商用字体 + 关键字 等）

**原则**：视频与文章配图以**代码驱动 UI 组件**为主视觉，配合项目商用字体排版层级 + SVG 内联图标 + 关键字大字标题，**不编虚构界面**（硬红线）；当前制作不使用截图素材、不显真实产品 UI（非永久约束）。AI 生图原则上不用于主视觉（质感不可控、与代码 UI 风格不统一）；元素可增删重组，无强制组合。

**① UI 组件（代码绘制，主视觉）**
- 用 Remotion 代码绘制（卡片/对比面板/流程图节点/数据指标卡/列表/要点），参考标杆：程序员鱼皮信息图/视频的「讲解级 PPT Motion Graphics」风格。
- 颜色有语义：绿=解法、红=痛点、橙=强调、青=科技。
- 呈现：每屏一个明确信息目标，信息密度可高但靠分区与层级组织不显乱。

**② 项目商用字体（排版层级）**
- 用 `商用字体/`（已复制到 `video/public/fonts/`，index.tsx @font-face 注册）：得意黑=冲击力标题、阿里巴巴普惠体=正文层级、阿里妈妈方圆体=亲和场景。
- 必须本地加载，否则渲染缺字。

**③ SVG 内联图标（语义辅助）**
- 代码内联自绘业务图标（咖啡杯/券/核销/人群/箭头等），单色描边风格统一；不引用未授权图标库。

**④ 关键字（Keyword）**
- 从口播稿提取核心词/金句（每屏 1 个，≤14 字最佳），见 10 §5；大字标题 + `textShadow`，spring 入场 / stagger / 逐词弹入。
- 数字以 00§6 为准；禁用极限词；不凸显品牌名（07 §5 三类禁用表述）。

**⑤ 纹理/底纹（可选）**
- 可选用 `图标素材/图鱼素材/` 的纹理图案作 UI 卡片底纹/装饰层（商用授权即可）。

> 插画（AI 生成）定位为**补充素材**而非主视觉：仅当某屏确需情境插画且代码 UI 不足以表达时，由 AI 生成、附 §4 声明、人确认入 `插图库/`；风格锚定避免跳脱显廉价。

## 4. AI 生成图可用性声明（强制，仅当使用 AI 生图时）

每张 AI 生成的图片，交付时必须附声明，格式：

```
【AI 生成 - 待你确认】
文件：xxx.png
类型：情境插画 / 氛围背景 / 转场元素 / 封面
用途：用于某 G 类行业视频第 X 屏 / 搜狐长文配图
我的可用性初判：可直接用 / 需调整 / 不建议
风险点：文字是否有误、风格是否统一、是否误增功能界面元素、是否过度艺术加工导致失真
```

人检查后回「可用 / 不可用 / 改这里」，AI 据此迭代。AI 不替人拍板"这张能用"。

## 5. 文章配图规范

- **文章（搜狐长文等）配图 = 代码 UI 组件 + 项目商用字体 + 关键字 风格**，与视频统一视觉语言，不混真实截图（11 §3）；保证干净、可信、合规。
- 每篇交付物带「素材清单」小节：UI 组件/字体来源说明 + （若有）插画（来源路径 + "AI 生成·待确认/已入库"标注）单列。
- 若某场景确需展示产品真实界面以供人工核查，仅在内部文档引用 `截图素材/`（脱敏），**不进入对外宣传物料**。

## 6. 视频画面元素规范

- 视频 = 代码 UI 组件层（卡片/对比/流程/面板）+ 字体层（项目商用字体）+ 图标层（SVG 内联）+ 关键字层（大字标题，从口播稿提取）；原则上不 AI 生图主视觉。
- 转场优先代码（SVG/CSS）实现。
- 禁用：截图/产品 UI、虚构界面（10 §8）、AI 生图作主视觉（质感不可控，2026-08-14 用户否定）。

## 6.5 跨平台合规：小程序码使用边界

> 完整铁律红线见 `quandao-content` skill §二（单一权威）。本节为小程序码边界的执行细则。

- **仅微信生态可用小程序码**：视频号、朋友圈、社群、企微、官网、线下物料（台卡/海报/传单）。
- **小红书 / 抖音 / 搜狐 严禁小程序码**：上述平台的封面、视频画面、文章配图均不得出现小程序码或任何微信系二维码（审核严，会被判站外导流，导致限流/下架/封禁）。这些平台的 CTA 用文字话术「券到卡包」+ 主页/置顶评论/私信承接（正文文案与视频均不出现微信搜索/小程序类表述（导流仅限账号资料位））。
- logo（品牌标识，非二维码）与"券到卡包"文字角标在三平台均可用。
- 此边界覆盖 07 §3（封面）、07 §5（转化口径）、12 步骤 7（封面生成与文案包交付）。
- 封面整体设计须遵循 07 §3 原则：干净简洁、标题清晰结合内容、不堆"免费"等促销文案、具备第一直觉引流力。

## 7. 缺口与补充流程

- 当前已知缺口：**`插图库/` 为空**——新方案以代码 UI 组件为主视觉、插画作补充，仅当代码 UI 不足以表达情境时由 AI 生成并经人确认后入库（流程见 §2/§3-②）。建议每行业先出 1~2 张代码 UI 风格样张锚定调性。
- `背景素材/` 现有 55 张（根 20 + 古朴 15 + 小红书 20）可用作背景层；不足时从 CC0 源（Unsplash/Pexels/Pixabay）或会员站（须商用授权）补取。
- AI 需要而库里没有的素材（如特定字体、特定实拍图），列「素材补充清单」交人，人去找/拍后归档；推荐补取渠道见 07 §3 末「推荐专业设计网站」（均须确认可商用授权）。
- 封面制作指引随首个行业（G02）产出，落 `outputs/[行业]/`：封面来源口径（2026-08-17 统一，SKILL §5.0）即「AI 先从 `背景素材/` 索取合适模板；库内无合适时 AI 输出「详细引导」——给检索词/尺寸/风格/版权要求，指引用户到创客贴等优秀设计网站查找制作、回传后 AI 核对收口」（非代码生成、非 AI 生图）；AI 提供封面文案包与素材库推荐作为引导的一部分。后续行业复用并迭代。**outputs/ 为过程产物，审核后可能删除，文档不引用具体产物路径**（G02 产物已于 2026-08-15 由用户删除待重制）。**AI 应主动输出「详细引导」并推荐优秀设计网站（07 §3 末）。**

## 8. 视频处理图片管理方案

视频处理生成的图片分两类，保存规则不同：

- **资产类（插画 / 背景 / 封面）—— 不自动保存进资源库**，沿用 §2「确认即入库」：AI 生成后先作「待确认草稿」留 `outputs/<编号>-<行业>/`，附 §4 声明；**人确认后才归档进对应库**，未确认不得进入公共库。
- **过程 / 临时类（Remotion 预览帧、静帧导出、合成中间图、草稿迭代图）—— 默认不入库**，留 `video/.cache/preview/`，不进资源库、不进 outputs/，可随构建清理。
- **封面落点**：随交付物存 `outputs/<编号>-<行业>/`；人确认后优质封面底图可「提升」进 `背景素材/` 复用（不强制、不新建顶层库）。

**分类规则（三维度叠加）**：
1. 来源类型（顶层库）：`背景素材/` `插图库/` `图标素材/` `商用字体/`；过程图归 `video/.cache/preview/`（不入库）。
2. 业务场景（二级归类）：选题编号-行业（如 G02-茶饮咖啡）/ 平台渠道（抖音·小红书·搜狐）/ 用途（钩子·转场·CTA·正文·封面）。
3. 时间（命名）：`类型-日期-选题-平台-描述.png`（例：`插图-20260813-G02-抖音-撬走老客.png`）；可选按周/月建归档子目录。
