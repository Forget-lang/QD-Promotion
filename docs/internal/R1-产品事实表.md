## 1. 产品定位（一句话，来自小程序分享文案原文）

> **免费实体店电子券制作工具，快速创建优惠券、券包、次卡，支持企业微信自动发券。**

> ⚠️ 对外口径：引文中的"企业微信自动发券"是产品分享文案原文；对外内容（文案/视频/文章）一律按 R5-内容红线 §4.1 改写为功能泛称"加好友/进群自动发券"，不直说"企业微信/企微"。

- 产品名：**券到卡包**
- 形态：一个微信小程序，双端合一——同一个小程序内，顾客用「我的卡包」，商家用「商户中心」（底部两个 Tab）
- 运营主体：郑州百桨数字科技有限公司（依据小程序隐私政策页）
- 商业模式：**当前免费**（代码分享文案明确「免费」）。后续是否收费/增值服务为未定事项，对外不得承诺或暗示

## 2. 产品解决什么问题（基于功能的客观表述）

实体店商家通过券到卡包完成「制作电子券 → 多渠道发放 → 顾客领取 → 到店扫码核销 → 数据统计」的完整闭环，并可借助企业微信实现加好友/进群自动发券，把线下客流沉淀为可反复触达的客户资产（客户列表、手机号采集、客户导出）。

## 3. 三大核心产品（优惠券 6 型 / 券包 / 次卡；次卡含 通卡·次卡·权益卡 三种类型）

### 3.1 优惠券（核心）
- 6 种券类型：**代金券、套餐券、满减券、折扣券、兑换券、随机金额券**
- 3 种发放方式（制券时选定，创建后不可改）：**公开领取、私密发放、券包专用**（供券包挂载）
- 有效期三种模式：固定时间段 / 领取当日起 N 天 / 领取次日起 N 天（1~365 天）
- 可用时段：全天，或指定星期 + 时间段（最多 2 段）
- 发放渠道：公开支持微信好友/群、二维码、海报、公众号、企微进群、企微小助理、企微客户群发；私密支持微信好友、二维码、企微加好友
- 核销：顾客出示二维码，商家扫码或手动输券码；另有条形码、数字卡号兜底。（「核销活码/5 分钟刷新」为产品可选功能，**不在宣传内容中使用**，事实保留备查）
- 特色玩法：**转赠好友**（先到先得，可取消）、**核销奖励**（核销后再得本券一张）、**转赠奖励**（受赠人核销后奖励原转赠人一张指定私密券）
- **领取口令（2026-08 新增，宣传可用）**：制券可开启，固定口令=商家设 5 位数字；随机口令=每 3 分钟自动变化、可手动刷新；顾客领券须输入口令；仅优惠券支持（券包强制不支持）。详情页有"收款口令码"面板（切类型/改口令/倒计时/复制文案）
- **指定手机号领取（2026-08 新增，宣传可用）**：制券可开启白名单，每行一个手机号、去重、最多 500 个、可批量粘贴；开启后自动勾选留手机号，白名单内顾客领券须填手机号

### 3.2 券包
- 把 **2~10 种**「券包专用」类型的优惠券打包成一个商品，每种 1~5 张，按「个」计库存（2026-08-25 代码核实：原"最多 5 种、每种 1~10 张"有误，已修正）
- 三种领取玩法：**一键全部领取 / 随机领取一种（抽奖玩法）/ 自选一种**
- 仅支持**私密发放**（微信好友/群、二维码、企微加好友）
- 顾客领取后拆为包内各优惠券，逐张独立核销；9 种主题卡面配色

### 3.3 次卡（卡产品族：3 种类型）
- 入口：商户中心「制作次卡」→ 先选类型（对应 choose_type 页）：
  - **通卡**（UNLIMITED）：有效期内**不限次数**使用，凭卡核销进入（如景区年卡 / 会员卡 / 月卡）；
  - **次卡**（TIMES）：每张含 **1~1000 次**，按次核销（如洗车 10 次卡）；
  - **权益卡**（BENEFIT）：逐项权益核销，**最多 30 项**优惠内容（金额 / 折扣 / 服务三种类型），按核销顺序依次使用（如护理套餐卡）。
- 有效期三模式：固定时间段 / 领取当日起 N 天 / 领取次日起 N 天（1~365 天）。
- **使用说明（使用须知）**：商家创建次卡时可自定义文本（≤500 字，可一键套用模板），属次卡数据字段之一（同名称/次数/有效期/发放数量）；视频展示次卡时按业务场景显示该字段内容（2026-08-25 明确，与 applet pages_card/card/create.vue 的 content 字段一致）
- 核销间隔限制：开关开启后 0~30 天（0 = 每天可用 1 次）。
- 开启动态核销码（可选，**不在宣传中使用**）；支持转赠（默认开）、手机号采集（默认关）。**次卡仅支持转赠，无转赠奖励**（转赠奖励仅优惠券支持，不要把次卡转赠和优惠券转赠奖励混在一条链路里说）。
- 卡面：磁条卡面组件，**9 种主题配色**（尊享红 / 酒窖红 / 鎏金黄 / 墨玉绿 / 午夜蓝 / 赤铜棕 / 曜石黑 / 御紫 / 深海蓝，深色系，**券包/次卡共用**）。
- 发放方式：**仅私密发放**（微信好友/群、二维码、企微加好友发次卡）；无公开领取。
- **发放前置审核**：次卡创建后需 `auditStatus` 审核通过方可发放（发放按钮审核未通过前禁用）；属平台安全合规机制，**对外宣传一律不提"审核/待审核"**。
- 作废粒度细：可整卡作废，也可作废「某一次」核销；支持暂停/恢复/修改/删除/调整库存/适用门店/发券员工。
- 商户详情：领取明细 / 核销明细 / 优惠内容 / 数据统计；顾客端「我的卡包」展示磁条卡面 + 剩余次数（通卡展示已使用次数）。

## 4. 功能清单（按模块）

### 4.1 制券与券管理（商户端）
- 优惠券创建（封面 5 张、名称 18 字、库存 1~10000、门槛/面额/折扣/兑换物/随机区间、有效期、可用时段、限领规则、核销限制、使用须知一键套用模版/清空、套餐组合、预约说明、到期提醒、手机号采集开关、分享设置、转赠与奖励设置、**领取口令（固定/随机）**、**指定手机号白名单（≤500 个）**）
- 复制创建（基于已有券回填表单）、草稿自动保存（退出未提交自动存草稿，下次可续编）
- 修改券（已被领取后关键字段自动锁定）、库存调整（**只增不减**）、适用门店管理、发券员工管理
- 暂停发放 / 恢复发放、作废（模板级：已领取未核销的一并作废）、删除（仅已作废/已过期可删，需逐项勾选确认）
- 券包、次卡具备同构的管理能力（创建/修改/暂停/恢复/作废/删除/库存、使用须知一键套用模版）；次卡详情页支持查看/修改适用门店（至少选 1 家）
- 适用门店/发券员工选择规则：**仅审核通过的门店可选、仅正常在职员工可选**，异常状态项展示但置灰不可选

### 4.2 发券（商户端）
- 公开领取：微信分享卡片、下载二维码、海报生成（canvas 绘制，含券面信息与小程序码，可保存相册）、**公众号**（获取小程序 AppID／路径／公众号图文链接／短链，用于已绑定公众号推送或图文插入领券卡片；**此乃产品功能，代码常量 PUBLIC_OFFICIAL=4 已验证存在，请勿与"宣传渠道"混淆**；公众号不在内容宣传的发布渠道内——发布平台仅限抖音/小红书/搜狐，本功能不对外宣传，见 `R5-内容红线.md`）
- 私密发放：一对一链接/二维码，**发放数量 1~10 张、超时时间 5 分钟~永久五档**，领后链接失效，可写发放备注（仅商家可见）
- 定时开抢：公开领取可设置自定义领取开始/结束时间（领取页倒计时）
- 企微自动发券：加好友发券（员工专属二维码 + 自动发卡片的规则配置）、进群欢迎语模板、企微客户群发任务（成员需在企微「群发助手」确认发出）、企微小助理
- 活动海报：把多张公开券聚合为一个活动海报，四种分发渠道（微信卡片/二维码/海报/公众号），可展示在商家主页，统计浏览量

### 4.3 核销（商户端）
- 核销台：扫码核销（扫顾客出示的核销二维码）+ 手动输入券码两种方式
- 核销前自动校验：已使用/已过期/转赠中/核销码过期均拦截并提示（活码超时为内部机制，不对外宣传）
- 核销时选择核销门店、可填核销备注（仅商家可见）
- 核销奖励自动发放与状态跟踪（成功/失败/待补偿）
- 次卡核销显示「第 X 次：抵扣 ¥xx / 享 x 折 / 服务名称」与剩余次数，支持核销间隔校验、作废单次
- 核销记录列表：筛选（时间/渠道/门店/员工/券码搜索）、导出 Excel
- 领取记录列表：同维度筛选、导出 Excel、单条详情（可对未使用券作废）

### 4.4 数据统计（商户端）
- 时间维度：今天 / 昨天 / 本月 / 上月 / 累计（五档）
- 我的业绩（员工个人）：有效发放张数、核销率、在店核销张数
- 本店数据：门店发券/核销业绩
- 排行榜：发券渠道排行、门店发券排行、门店核销排行、员工发券排行、员工核销排行、顾客转赠排行、顾客核销排行
- 券详情页即时数据：已领取、已核销、核销率、剩余库存进度
- **注意：统计呈现为指标卡 + 排行榜，当前没有趋势图表**

### 4.5 顾客端（C 端）
- 我的卡包首页：资产统计（优惠券/券包/次卡/商家数）、有效次卡轮播、未使用券列表、**客户码**（向商家出示识别身份的二维码 + 客户编码）、支持分享给微信好友
- 券列表四态：未使用 / 已使用 / 已作废 / 已过期
- 券详情：二维码 + 条形码 + 数字卡号（可复制）；联系商家电话（活码防截屏为可选功能，不在宣传中使用）
- 三种领券入口：公开领取页（倒计时、已抢光等状态）、私密领取页（超时倒计时）、转赠领取页；优惠券各领取页的商家信息可点击跳转商家主页
- 转赠：发起（填备注）→ 分享给微信好友/朋友圈 → 可多次分享、仅首位领取者得券 → 领取前可随时取消；转赠记录列表
- 券包详情（包内券逐张查看使用）、次卡详情（剩余次数、权益项、核销码）
- 我的商家、商家主页（门头照、认证标识、行业、地址导航、电话、活动海报列表）
- 账号设置、注销账号、意见反馈/投诉

### 4.6 商户经营（商户端）
- 商户注册：门头照、名称、地区、地图选点、行业、营业时间、微信手机号快捷获取、**「您是从哪里了解到我们的」必选项**（抖音/小红书/视频号/朋友推荐；特定链接来源自动识别带入）
- 商家认证（主体认证）：营业执照 + 法人身份证，人工审核（页面提示预计 3 个工作日），认证后顾客端展示「已认证」标识
- 多门店管理：门店增删改、营业状态切换（正常/关店）、门店审核状态
- 员工管理：分享链接邀请（设角色 + 有效期 5 分钟~1 天）、**申请-审批制**加入、员工冻结/解冻（需员工修改权限）、隐私数据脱敏开关、操作日志（含 IP）、超级管理员变更（双短信验证）
- 角色权限体系：模块级入口权限（8 个模块）+ 操作级权限（制券/发券/核销/统计/导出等 50+ 权限点），控制商户中心入口与按钮显隐
- 客户中心：今日/昨日新增与总数统计、客户列表（按领券/核销次数排序）、客户详情（券与次卡的领取/核销数据、备注、手机号维护）、客户列表导出 Excel；**客户码仅商家员工凭权限扫码可访问客户详情**（顾客或无权限者访问会被拦截）
- 客户注册方式设置：微信授权注册 / 匿名注册（仅对新客户生效）
- 站内消息中心（未读角标、富文本详情、图片附件）
- 商家主页（C 端展示面）：门头照每月修改次数有限制
- 素材库：上传图片需平台审核（审核中/通过/违规），自带图片裁剪与压缩

### 4.7 企业微信（商户端进阶）
- 企微主体授权（扫码授权）、企微环境内绑定商户
- **四个已上线能力**（加好友发券 / 进群欢迎语发券 / 客户群发 / 群小助理），均通过企微环境触达顾客：
  - 加好友发券：为每个企业成员配置规则（关联产品、每次张数 1~10、超时时间、欢迎消息、备注）→ 生成**员工专属联系我二维码**（可打印在台卡/海报/传单）→ 顾客扫码加好友后**自动收到领券卡片**
  - 进群发券：创建群欢迎语模板 → 商家在企微群中配置欢迎语 → 新成员进群自动弹领券卡片
  - 企微客户群发：选择成员、编辑卡片标题与消息内容，创建群发任务（成员在企微群发助手确认）
  - 群小助理：在企微群内开启「小助理」后，群成员 @小助理 并输入关键字即可自助领券（群内关键字自助领券，无需员工干预）
- 产品覆盖差异：加好友发券 券/券包/次卡三产品均支持；进群欢迎语、群小助理、客户群发当前仅从「优惠券」详情发券面板进入（券包/次卡暂未暴露入口）

## 8. 能力边界（对外内容禁止提及/暗示的功能）

以下为产品**当前不具备**的能力，宣传与教程中一律不得出现：

1. **无在线支付/交易**：券是免费发放领取的营销工具，不含收款、买单、会员付费购券、线上下单核销等任何交易能力。产品不做收款，但商家可经**自己的收银系统线下收款**后，再用本产品**私密一对一发券**——「买 X 次送 X 次、钱先到账」类文案指商家线下收款后的促销活动，产品不参与收款，口径可用。
2. **无短信验证码领券**：顾客填手机号仅做 11 位格式校验，无短信验证环节（不要宣传「短信验证更安全」）。
3. **统计无趋势图表**：只有指标卡与排行榜，没有折线图/柱状图。
4. **券包/次卡无私公开领取**：券包与次卡仅支持私密发放（只有优惠券支持公开领取）。
5. **无在线预约系统**：券可写「需提前预约」的文字说明，但没有预约下单/日历系统。
6. **核销方向固定**：商家扫顾客的码（或输顾客的券码），不存在顾客扫商家码核销。
7. **无会员等级/积分体系**：「客户码」仅用于身份识别，勿称为会员体系。
8. **无第三方系统对接**：无收银系统/POS/外卖平台对接。
9. **企微群发不是全自动**：群发任务创建后，需员工在企业微信「群发助手」中确认才发出（教程必须说明，避免商家误解）。
10. **企微「群发卡券」聚合入口未完成**（页面未上线），对外讲已上线的四个企微能力：加好友发券、进群欢迎语发券、客户群发、群小助理。⚠️ **代码缺陷待修复**：企微首页「群发卡券」卡片当前仍挂载并跳转 `/pages_wecom/batch/index`（该页未上线，点击进入空白/报错，属死链）；对外若需演示企微群发，应引导至「客户群发」（优惠券详情发券面板内的 `wecom_batch`），并请开发移除该死链卡片或补占位页。
