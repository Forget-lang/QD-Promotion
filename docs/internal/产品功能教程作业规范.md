# 产品功能教程作业规范

> 定位：**产品功能教程（下称"教程线"）的唯一方法 Owner**，属生产流程层——与 `SKILL.md`（行业场景视频方法）同层，**不占 R2–R10 编号**（那些属协议/参考层）。
> 本文件**不拥有**产品事实（回 `APPLET / spec/`）、**不拥有**红线（回 `spec/redlines.json`）、**不复制**工程约定（回 `video/` 与 R3 / R7）；与行业线方法**互不继承**。
> 建立事务：`CHANGE-20260920-032`。判线（contentLines）与闸门适用性的**机器可读声明在 `scripts/ref-registry.json`**——本文件解释口径与理由，不重复登记值。

## 一、这条线是什么

- **一条教程 = 一个完整使用任务**。使用任务 := `spec/*-fields.json`（券类/次卡/会员权益/积分）的**原生分组**或**跨组的一条真实操作链**；不得凭空发明产品分类。
- **教程八段骨架**：功能目标 → 入口 → 操作路径 → 字段意义 → 联动 → 实际结果 → 易错/边界 → 完整闭环。骨架从 Product Truth **投影**（只读不写回）；真值表里没有的说法不上屏、不进口播。
- **不设时长档、不设硬上限**：按"一个使用任务是否讲透并闭环"决定；只有内容自然分叉成两个独立使用任务时才拆片。**禁止**在文档里写"不受 200s 上限约束"这类否定式复述（会命中数值口径的属主外复述判定）。
- 不用行业、不用经营痛点、不把功能包进故事；主角是产品能力本身。
- 每条教程的**视觉隔离基线 = 同线（f↔f）**；跨线默认互不比较。

## 二、事实与素材纪律

- 功能、数字、字段、限制一律回 `APPLET / spec/`；「假定具备完整能力」= 不提版本/档位/升级（依据 spec 既有对外口径），**禁止据此虚构**。
- **截图作为教学材料的门槛**：须先入 D-1 登记且 `verificationStatus` 为 `current-verified` 才能进成片；`reference-only` 只能当界面地图/找图参考。存量截图默认 `reference-only`。
- D-1 字段与校验落点：`spec/assets.json` 的 `D.screenshotLedger`（写入格式与机检在 `scripts/check-facts.mjs`／`scripts/list-assets.mjs`）；证据链主锚＝`screenshotId → sha256 → appletSnapshot → truthRef → sourceLocation`，`capturedAt` 只作采集元数据。
- **缺图流程**：出规格与检索词 → 人回传 → 按 D-1 字段核验登记（来源可追溯 ＋ 真值对应 ＋ 裁切确认）。缺哪些画面以教程画面清单为准，不启动存量全量重拍。
- **反低质设计参考**："测试录屏／单图+简单特效／音画无关"等语汇出自平台推广任务审核场景的**经验性参考**——只作设计提醒并标注来源，**不作判据**。

## 三、品牌与平台口径（只做指针 ＋ 已拍板边界）

- 品牌：口径真源在 `spec/redlines.json` 的 `rules.brand_display.applicability`——教程线**允许**标题出现「券到卡包」、封面出现「券到卡包」、真实产品教学画面出现产品识别信息；该允许**不自动解除**账号资料位（`account_profile`）、平台规则、导流禁令与其他红线；"话题标签不带品牌词"对两线均适用（用户 2026-09-20 拍板）。
- 教程线**不继承**行业线"口播必提一次"的硬义务；品牌露出以标题/封面为主。
- 平台硬禁（词/元素级）以 `spec/redlines.json` 为准，两线一体适用。

## 四、闸门适用性（教程线）

> 机器声明源在 `scripts/ref-registry.json` 的 `gateApplicability`；下表解释口径，改动时两处同步由该事务负责。

| 闸门 | 状态 | 口径 |
|---|---|---|
| `check-redlines`／`check-ui-truth`／`check-voice-discipline`／`check-facts` | APPLY | 两线共同底座：平台硬禁、上屏真实性（字段名回源码）、口播听感纪律、素材对账 |
| `check-bg`／`check-motif-card` | N/A | 行业线视觉条款**不继承**；教程线视觉方法见 §五 |
| `check-similarity`／`check-layout-diversity`／`check-voice-brand` | N/A | 现行判据按行业线方法构建、未适配本线；机检适配留待首条教程实测后另立事务 |
| `gate-all-motion`／`gate-all-safearea` | OBSERVE | 照测照出读数、不判红（观察/诊断用） |
| 本线 `defaultApplicability` | `EXPLICIT_REQUIRED` | **该线不设默认**：每个闸门必须显式登记适用性；未登记即硬失败（不许静默落 N/A） |

**N/A ≠ 无验收**：机检不适用的项由**人工验收**承接——首条教程的教学正确性（观众能否照做）与视觉（截图画质/可读性/版式）在成片验收时逐屏人判；该验收是 f01 事务的关闭条件。
