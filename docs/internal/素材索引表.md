## 登记流程（新素材入库）

1. 人把素材放入对应目录（`背景素材/`、`插图库/`、`图标素材/`…）
2. **AI 或人在本表登记一行**：编号 / 名称 / 内容描述（AI 可看图代写）/ 色调 / 适用场景 / 路径 / 状态
3. 编号规则：背景 `BG-ABS-序号-语义名`、插画 `IL-行业-序号-语义名`、纹理 `TX-序号-语义名`
4. A 类背景/封面复用前，先渲染 1 帧 still 验证前景兼容（M2 §6.2）
5. 登记后 AI 设计稿即可直接引用
