### 搜图技巧（为什么总搜出带字模板，怎么避开）

> 创客贴/稿定这类是"设计模板站"，搜"背景"默认返回**设计模板**（海报/封面，自带文字+插画），不是**纯背景图**。避开方法如下：

1. **换入口，别在"模板"里搜**：进创客贴编辑器后，在「**素材 → 背景**」分类里搜，那里是纯背景图；在「模板」分类搜到的都是带字海报。
2. **搜索词避开模板词**：别带"模板/海报/封面/手账/小红书/卡片"这类词，它们会勾出带字模板；多带"**纯背景 / 渐变 / 抽象 / 壁纸 / 无文字 / 光斑**"。
3. **换平台效果更好**：纯抽象背景在图库站远比模板站好找，且免费可商用——
   - **Unsplash / Pexels / Pixabay**（免费可商用），用英文搜命中率最高
   - 英文关键词：`pastel gradient background`（马卡龙渐变）、`soft bokeh background`（柔焦光斑）、`abstract gradient wallpaper`、`blue green gradient`、`purple soft light`、`haze gradient`
4. **兜底——从模板里抠背景**：看中某模板的背景但带字，进编辑器选中背景图层 → 删掉文字/插画层 → 只导出背景（你现在用的办法）。**优先挑背景是"独立一张图"的模板**（背景层能单独选中），背景是"一堆矢量图形拼出来"的不好抠，直接放弃。

### 挑不到合适的？AI 直接生成（更省事的兜底路线）

> 搜半天不如直接生成。AI 文生图做"抽象光影渐变背景"是强项（不用写字，不存在错字问题），项目流程本就支持（M2 §6.3「AI生成描述」字段）。
> **用法**：跟 AI 说"帮我生成一张〔蓝绿系〕视频背景，竖版"，AI 出图 → 按四条红线自检 → 合格入库（编号顺延）。缺哪个色系就让 AI 补哪个，不用一直搜。

### 挑选四条红线（不符合的不要下载）

1. 纯抽象光影——**无文字、无 logo、无具体物体**（花/杯子/人物都不行）、无人脸
2. **画面中间偏上位置要留白干净**（将来放标题和卡片的内容区，约 y:200-1100）
3. 颜色 ≤2-3 个色系，避开高饱和撞色块
4. 可商用（会员素材需含商用授权）

### 交付流程

1. 用户把找到的图发给 AI
2. AI 判断（四条红线 + 与行业 palette 适配）→ 合格则复制到 `背景素材/抽象模板/{暖色系|冷色系}/`
3. 命名 `BG-ABS-{下一序号}-{语义名}.png`（下一序号查 A 级表最大编号 +1，例：BG-ABS-007-粉雾网格渐变底）
4. 在本表 A 级表登记一行（编号/色系/内容描述/适用行业/路径/状态）
5. 按需渲染 1 帧 still 验证前景兼容（M2 §6.2 背景图兼容验证）

> 批量验收可在新会话启动「背景图入库验证」专用提示词（场景 E，见 outputs/archive/ 的 AI 启动提示词文档），AI 按本节标准逐张验收，合格自动走入库流程。
