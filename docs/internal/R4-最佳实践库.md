## 4. 视觉审美标准（V-R 红线 / V-S 建议）

> 从历次用户反馈中提炼的风格偏好，指导后续视频设计。分三层弹性标准：红线必须遵守、建议择优使用、创意自由发挥。

### 4.1 风格总偏好速查

| 维度 | 偏好 | 不偏好 | 来源 |
|---|---|---|---|
| 背景 | 行业专属背景图（模板图直接显示原图，blur: 0，有氛围不抢戏。详见 M2-视频制作手册「背景模板图」） | 纯渐变+噪点纹理（太素） | 用户拍板 B 方案 |
| 角标 | 不要进度指示器（SLIDE xx/xx） | 左上角任何数字编号 | 用户要求移除 |
| CTA 风格 | 品牌名 + 价值主张（具体文案由设计稿根据视频内容定制，不硬推关注/收藏/免费） | 硬推关注/收藏/免费 | G02 CTA 拍板 |
| 叙事方式 | 场景带入 + 问题→解法→升级 层层递进 | 功能罗列、7 屏全是痛点 | G02 v2 时间线叙事获认可 |
| 视频时长 | 目标 120-150s（8-10 屏），上限 200s | 过短（<60s）信息量不足，过长（>200s）掉完播 | 深度标准 |
| 钩子时机 | 前 3 秒必须出钩子 | 铺垫太长、慢悠悠 | 抗划走原则 |
| 视觉重心 | 文字是主角，视觉是骨架 | 花哨装饰、喧宾夺图 | 鱼皮风格参考 |
| 信息密度 | **高密度但不杂乱**——一屏装下尽可能多的有效信息，但视觉上井然有序 | 空荡荡没内容 / 塞太满看着累 | 用户拍板 + 创可贴封面验证 |

> 注：时长、钩子时机、叙事方式的**闸门化判断**（≥6 信息单元 / ≥2 层递进 / 深度 4 问）以 M1-内容策划手册（质量标准：方向锚 / 深度闸门）为准；本表只作速查。

### 4.2 高密度不杂乱 · 实现手法（压缩版）

> 核心目标：单位时间内让商家看到尽可能多的价值点，但视觉上不拥挤、不混乱。以下 6 个手法与第 4.3 节 V-S 建议一一对应，写设计稿时直接对照使用。

1. **统一视觉语言** —— 全片同色系、同圆角、同字体风格（对照 V-S06：卡片/图标风格全片统一）
2. **清晰视觉层级** —— 大标题/中标题/小字/说明，字号差拉开 2 倍以上（对照 V-S04：关键词有视觉强调）
3. **网格对齐** —— 所有元素对齐到隐形网格，等距分布（对照 V-R02：内容填满上 2/3）
4. **重复元素样式** —— 图标、标签、对勾、卡片，同款样式重复出现（对照 V-S13：色彩只用在关键点）
5. **分组明确** —— 相关信息放一起，用卡片/色块/线条区隔（对照 V-S10：纵向列表视线一条线）
6. **留白呼吸** —— 元素之间有足够间距，不是挤在一起（对照 V-S12：画面填满不留大块空白）

**反例（写了会返工）**：
- 一屏只有一句话，虽然干净但信息效率太低
- 什么都想放大，结果没有重点，看起来反而乱
- 颜色超过 3 种主色，视觉噪音大

### 4.3 视觉设计红线 · 建议 · 创意（三层弹性标准）

> **定位**：本标准是视频画面的"审美底线 + 方向指引 + 创意空间"。红线必须遵守，建议择优使用，创意自由发挥。
> **依据**：从创可贴设计参考图（7 张）+ 自有视频迭代经验 + 用户历次反馈中提炼。
> **更新规则**：每次出片后根据验证结果更新红线/建议，活标准。

#### 🔴 红线（不遵守就不及格，必须返工）

| 编号 | 红线 | 说明 | 反例 |
|---|---|---|---|
| V-R01 | **标题必须醒目** | 标题是全屏最大元素之一，字号 ≥ 56px，颜色深色或主色（与背景有强对比），位置要么居中要么左上但必须有存在感，不能淡、小、飘在角落看不清 | 标题白色半透明放在左上角，和背景融为一体 |
| V-R02 | **内容填满上 2/3** | 标题 + 主体内容必须集中在画面上 2/3 区域（top: 120px 到 y: 1400px），不能 3 张小卡片只占中间 40%、上下全空 | 3 张小方块挤在画面中央一条，上下各空 1/3 |
| V-R03 | **一屏一个视觉焦点** | 每屏必须有且只有一个主焦点（大数字/大标题/大图标/大卡片），所有元素围绕焦点排布，不能所有元素一样大、没有主次 | 3 张卡片尺寸完全一样，眼睛不知道先看哪 |
| V-R04 | **文字对比度足够** | 任何文字在背景上必须清晰可读，对比度 ≥ 4.5:1。模糊/看不清的文字就是失败 | 浅绿字放在浅蓝色背景上，看不清 |
| V-R05 | **相邻屏布局不重复** | 连续两屏不能用同一种布局模式（比如不能连续两屏都是"3 张卡片纵向列表"），必须有节奏感变化 | S2 卡片列表 → S3 卡片列表 → S5 卡片列表，审美疲劳 |
| V-R06 | **安全区内排版** | 内容在安全区内：顶部 ≥ 120px，底部 ≥ 160px（字幕区），左右 ≥ 60px | 内容贴边、被字幕遮挡 |
| V-R07 | **禁止全屏遮罩盖住背景图** | 背景图直接作为画面基底（blur: 0，显示原图），内容直接放在上面。**禁止**铺满全屏的半透明纯色/渐变遮罩把背景图完全盖住。文字看不清时用局部处理（文字加描边/投影、卡片加白底），不用全屏遮罩 | 深色渐变 + 发光光斑 + 点阵底纹铺满全屏，背景图完全看不见 |
| V-R08 | **每屏信息点 ≥ 3 个** | 不能一屏只有一句话或一个孤零零的元素撑场面 | 结尾屏只有两行字飘在中间，像半成品 |

#### 🟡 建议（择优使用，显著提升质感）

| 编号 | 建议 | 说明 |
|---|---|---|
| V-S01 | **每屏选排版参照** | 从本文件第 5 章排版参照库选一个匹配的参照类型，标注"参照：#X（XXX 型），借鉴了 Y 手法"，不凭空发明布局 |
| V-S02 | **至少 3 层视觉层次** | 背景层（虚化模板图）+ 主体层（卡片/图标/文字）+ 装饰/强调层（高亮底条/大数字/标签/投影），三层叠加画面才有厚度 |
| V-S03 | **颜色承担信息功能** | 主色用在最重点（标题/核心数字/CTA），辅色用在次要信息，灰色用在说明文字。颜色不只是装饰，是引导视线的工具 |
| V-S04 | **关键词有视觉强调** | 重要词汇用高亮底条、变色、放大、加粗、描边等方式强调，和普通文字拉开差距 |
| V-S05 | **装饰元素少而精** | 每屏用 1-2 个装饰元素（角标/标签/大图标/分割线/底条）增加层次和填充空间，但不堆砌（全片装饰件 ≤1-2 处，见 M2-视频制作手册「组件库 / 装饰件规则」） |
| V-S06 | **卡片/图标风格全片统一** | 圆角大小、阴影强度、图标风格、字体字号在全片保持一致，不混搭 |
| V-S07 | **数字/数据做放大处理** | 凡是出现数字（百分比/步骤数/统计数据），一律放大做视觉焦点，配合动效（弹入/跳动/计数）增强冲击力 |
| V-S08 | **对比屏用左右/上下分色** | 痛点对比屏（传统做法 vs 新方法）用分色/分栏做强烈对比，左边冷/暗/灰（传统痛点），右边暖/亮/鲜（解法好处） |
| V-S09 | **内容多寡决定布局形态** | 左右两栏内容量不一样时，不要硬做成一样大的卡片。内容多的占主体空间（列表/大卡片），内容少的用"强调感"补分量（大字/气泡/印章/结论条），形态不同就不会有"一边空一边满"的违和感 |
| V-S10 | **纵向列表，视线一条线** | 清单/步骤/痛点类内容优先用纵向列表布局（从上到下一条线），视线不左右横跳，读起来顺。配合图标/序号/分隔线，每一条都有存在感 |
| V-S11 | **白底卡片 + 浅背景，清爽干净** | 内容放在白色/浅色卡片上，背景是浅色系（渐变/模糊底图）。对比度足够、文字清晰、整体不花哨，信息是主角而不是设计 |
| V-S12 | **画面填满，不留大块空白** | 标题 + 主体内容要把上 2/3 区域填饱满，不能上下各空 1/3、中间挤一小块。内容不够用大字号、大图标、装饰元素来撑，不能空着 |
| V-S13 | **色彩只用在关键点** | 全片颜色控制在 2-3 个色系内（主色 + 黑白灰 + 1 个强调色）。颜色用在标题、图标、关键词高亮这些"引导视线"的地方，不用颜色堆砌装饰 |
| V-S14 | **标题有"容器感"** | 标题不是飘在画面上的一行字，而是有"容器"——底色条/便签纸/顶部栏/标签框，让标题有重量感、第一眼就看见 |

#### 🟢 创意（自由发挥，鼓励创新）

| 维度 | 空间 |
|---|---|
| 特殊屏布局 | 钩子屏、结尾屏可以跳出常规布局，用大字冲击、品牌升华等创新形式 |
| 动效设计 | 入场动画、强调动画、转场方式，在 M2-视频制作手册（技术硬规则：动画/转场规则）范围内自由设计 |
| 装饰选择 | 具体用什么装饰元素（波浪线/手绘圈/贴纸/光效），根据内容和行业自由选择 |
| 色彩微调 | 在 palette 色系范围内，可以根据场景微调饱和度、明度，制造节奏变化 |
| 新手法尝试 | 发现新的好用设计手法，验证后沉淀回本标准 |

> **出片前自查**：设计稿完成、成片渲染前，把 V-R01~V-R08 红线逐条过一遍（操作化检查清单在 M2-视频制作手册「美感 & 内容密度自查」）；V-S01~V-S14 择优使用。

### 4.4 用户反馈翻译表（"感受" → "专业指令"）

> 用户不是设计师，只会说感受。AI 收到以下感受时，**按表翻译成可执行指令**，禁止简单化成"放大字体/放大卡片"。

| 用户感受（大白话） | AI 翻译成什么专业指令 | 对应规则 |
|---|---|---|
| "画面很平/很素" | 层级对比不足：按 M2 §2.9 字号阶梯重排，焦点 ≥2 倍，增加明暗对比 | M2 §2.9 |
| "看起来很廉价/像 PPT" | 质感缺失：检查氛围层挂载、阴影统一、圆角统一、色彩克制（≤3 色系） | M2 §3.3 / R3 §3.4 |
| "不知道看哪" | 焦点分散：明确一屏一焦点（M2 §2.10），非焦点元素降级（缩小/降透明/降饱和） | M2 §2.10 |
| "字太大了很傻" | 字号超阶：主标题回落到 96-120px，靠留白和对比而非大字号 | M2 §2.9 |
| "太空了/很空" | 留白失衡：内容区填充到 y:200-1100，用装饰/副信息补位（保留 1 个呼吸区） | M2 §2.9 |
| "太挤了/很乱" | 间距超标：检查 padding ≥43px、卡片间距 ≥20%、列表行距 ≥24px，删减元素 | M2 §2.9 |
| "动效很生硬" | 缓动缺失：非 spring 插值补 EASE_OUT，入场用 spring 或 expo-out | R3 §2.3 |
| "颜色很脏/不协调" | 色彩失控：主辅强三色比例 60/30/10，强调色只给焦点 | M2 §2.9 |
| "像上一条的翻版" | 同质化：风格五维 ≥3 维不同 + 布局模式换一种 | M2 §2.3 / R4 §5.9 |
| "没有参考图那种感觉" | 参考未拆解：按 M2 §2.11 模板补拆解，把具体手法落进布局 | M2 §2.11 |

**拿不准怎么办**：用户的感受对应不到表中任何一行 → 回到 M2 §2.12 四维评分，让用户按"层次/焦点/节奏/质感"四维给分（0-5），分数 ≤3 的维度即返工方向。

### 5.1 编号列表型（ref-01）

**参照图**：`outputs/archive/排版参考/ref-01-编号列表型-重启人生计划.png`
**适用屏类型**：方案屏（S3）、判断屏（S5）——多要点纵向排列
**好在哪**：

**可借鉴手法**：
- 编号用主题色高亮，正文用深色
- 要点之间留 1/3 行距，不挤不空

### 5.2 手写风大字 + 荧光笔高亮型（ref-02）

**参照图**：`outputs/archive/排版参考/ref-02-手写风高亮型-暑期实习.png`
**适用屏类型**：钩子屏（S1）、痛点屏（S2）——需要视觉冲击力
**好在哪**：
- 手写风大字有温度感，不像模板
- 荧光笔高亮标记关键词，视觉引导清晰
- 整体紧凑，一眼看完
**可借鉴手法**：
- 标题用特殊字体（得意黑/手写体）增加个性
- 关键词用高亮底条（半透明色块）强调
- 信息密度高但不杂乱，靠字号/颜色分层
- （2026-08-21 图核验补充）高亮条**略微倾斜**更有手写感，不要平贴；强调词可用**波浪形下划线**做第二层级标记

### 5.3 多层信息分区型（ref-03）

**参照图**：`outputs/archive/排版参考/ref-03-多层分区型-CKT价格表.png`
**适用屏类型**：数据屏（S7）、方案屏（S3）——多区块信息展示

- 图标辅助文字，降低认知负担
**可借鉴手法**：
- 多区块用不同底色卡片区分
- 每个区块配一个小图标做视觉锚点
- 区块之间间距统一，节奏感好
- （2026-08-21 图核验补充）区块标题用**横幅/丝带容器**（V-S14 容器感）；卡通装饰堆砌**不借鉴**（违反 V-S05 装饰少而精，只学结构不学装饰）

### 5.9 布局模式库 L-01~L-12（标准布局，设计稿必选其一）

> 从优秀竖版短视频/创可贴设计中提炼的**标准布局模式**。AI 写分镜表时每屏必须"先选模式，再填内容"，禁止自由排列元素（M2 §2.4 分镜表"布局模式"字段必填）。坐标基于 1080×1920 画幅。

| # | 模式名 | 结构描述（1080×1920 坐标） | 视觉要点 | 适用屏型 |
|---|---|---|---|---|
| L-01 | 大字中心型 | 超大标题居中（y:300-700），四周大量留白，底部一行小标注 | 焦点唯一：大字即一切；留白撑高级感 | 钩子屏 |
| L-02 | 上下分栏型 | 上 1/3 标题区（y:200-500），下 2/3 内容区（y:550-1650） | 标题与内容间距 40-60px；内容区卡片承载 | 信息屏 |
| L-03 | 左右对比型 | 中线 VS 徽章，左右各一卡（红/绿） | 对比靠色相+方向箭头，不靠大小 | 痛点-解法屏 |
| L-04 | 数字冲击型 | 超大数字（160-200px）居中偏上 + 下方 1-2 行说明 | 数字是绝对焦点，说明字 ≤44px 弱化 | 钩子/数据屏 |
| L-05 | 卡片网格型 | 2×2 卡片（每卡 400×400 上下两行） | 卡片等大、间距统一（≥卡片高 20%）；焦点靠卡内图标+数字 | 卖点/数据屏 |
| L-06 | 流程线性型 | 3-4 节点横向排列 + 箭头连接（y:600-900 中线） | 节点由连接线串起，逐步点亮；节点等距 | 步骤屏 |
| L-07 | 纵向列表型 | 3-5 行列表从上到下（每行图标+标题+说明） | 视线一条线；行间距 ≥24px；图标统一 | 清单/规则屏 |
| L-08 | 标签徽章型 | 主体内容 + 1-2 个角标/徽章（右上/左下） | 徽章是"额外信息"不是主体；≤2 处 | 进阶提示屏 |
| L-09 | 时间线型 | 中部曲线/时间轴 + 关键点标注 | 曲线平滑绘制动画；关键点用亮点+文字 | 客流/周期屏 |
| L-10 | 聚焦对比型 | 中央大焦点（数字/券面）+ 两侧弱化元素 | 焦点 ≥ 两侧元素 2 倍；两侧降透明 | 核心卖点屏 |
| L-11 | 票券展示型 | 券面/卡片为主体（居中 600×800），上下文字 | 券面有厚度（阴影/倾斜/撕边）；角度微倾更活 | 产品展示屏 |
| L-12 | 收尾品牌型 | 品牌名居中大字 + 一句价值主张 + 底部装饰线 | 品牌名 ≥120px；装饰线 draw-on 动画 | CTA 屏 |

**使用纪律**：
- 每屏从 12 种中选 1 种，可微调但不得自由发明新布局（新布局需沉淀回本表）
- 连续两屏**不得选同一种**模式（对应 V-R05 相邻屏不重复）
- 布局模式与排版参照库（ref-01~08）互补：模式定"结构"，参照定"手法"

## 6. 竞品拆解可复用清单（压缩版）

### 6.3 封面与首屏衔接手法（前 3 秒接住流量）

> 核心认知：封面是流量的第一道门，首屏（前 3 秒）是第二道门。封面决定"有没有人点"，内容决定"有没有人看完"。封面和首屏必须**连起来设计**，不能各做各的。人在刷视频时判断封面只有 **0.3 秒**，大脑只处理 3 件事：**这是什么？（行业识别）→ 有什么好处/威胁？（利益点/痛点）→ 跟别人有什么不一样？（反差/好奇）**。

**4 种承接方式**：
1. **自问自答型**：封面问"下午 3 点没人怎么办？"，首屏答"试试这 3 招"—— 接住问题，给出希望
2. **场景延续型**：封面是咖啡店空座照片，首屏接着讲"下午 3 点的咖啡店，员工比客人多"—— 延续场景，加深共鸣
3. **数字开场型**：封面有大数字，首屏开口就报数字—— 强化冲击，快速进入正题
4. **反差升级型**：封面说"不打折也能锁客"，首屏说"反而赚更多"—— 把反常识进行到底

**绝对不能做**：
- 封面问 A 问题，首屏讲 B 内容 → 用户感觉被骗，秒走
- 首屏慢悠悠铺垫（logo 转一圈 / "大家好我是 XX"）→ 等你铺垫完，人都走了

### 6.4 封面避坑速记

| 坑 | 表现 | 怎么避 |
|---|---|---|
| 文字太小 | 封面标题字低于 80px | 最小 80px，标题建议 120px+ |
| 信息过载 | 一屏塞 5 个以上信息点 | 最多 3 个信息点，主次分明 |
| 行业不明 | 没有行业元素，全是文字 | 必须有 1 个一眼识别的行业元素 |
| 文不对题 | 封面说的跟内容没关系 | 封面是钩子，首屏必须接住 |
| 太"干净" | 纯白底 + 几个字，没设计感 | 至少有背景色 + 1 个装饰元素 |
| 用长句 | 标题超过 15 个字 | 控制在 12 字以内，断行不超过 2 行 |

> **可选动作（有条件时做）**：同一视频做 2 个不同封面投放测试点击率，相同投放条件下点击率高 20% 以上才算显著差异（维度可换：标题风格/主色调/版式/有无真人）。

| T-005 | 红线闸门最后跑 | 内容写完统一跑一次 `node scripts/check-redlines.mjs`，不用写一句查一句 |
| T-006 | 语音复用规则（省 TTS 额度） | **改画面/字幕 → 直接重渲染，复用已有 wav（音频与字幕时间轴分离）；只有改口播文字 → 才重录对应屏 TTS**。G03 v3 验证：字幕重写全程未重跑 TTS。口播定稿后再合成，避免浪费额度 |
