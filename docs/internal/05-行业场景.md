# 05 · 行业场景库

> 按行业拆解「券到卡包」的落地玩法。每个场景 = 痛点 → 功能组合 → 玩法步骤 → 宣传话术要点。
> 所有组合均由真实功能构成（依据 00-产品事实表）。写行业向文章/视频时，从本文档取材；场景示例统一用「示例」口吻、不伪装成真实案例；商户指代一律用行业泛称（咖啡店/火锅店/美容店等），**不编任何虚构具体店名**（如「半刻茶咖」）。

---

## 通用说明：三大产品的行业分工

- **优惠券**：引流与促活的主力，适合「让新客第一次进店、让老客再来一次」；
- **券包**：组合让利、节日礼包、新客大礼包，一次发放多张券拉长消费周期；
- **次卡**：高频消费行业锁客神器，把「一次性顾客」变成「常来的熟客」。

---

## 1. 餐饮（正餐/快餐/小吃）

**典型痛点**：门口客流不少但进店率低；工作日午市/晚市客流不均；老客没有回来的理由。

**玩法组合 A：新客引流**
- 满减券（消费满 100 减 20）或代金券（80 代 100），公开领取；
- 生成海报贴在门口/收银台，或下载二维码做台卡；
- 设置「每人每天限核销 1 张」控制成本。

**玩法组合 B：闲时填坑**
- 可用时段设为「周一至周五 14:00–17:00」的折扣券，只在闲时生效；
- 顾客群定时开抢（设置领取开始时间，领取页自带倒计时，制造抢购感）。

**玩法组合 C：回头客**
- 开启「核销奖励」：顾客用券核销后再得一张本券，自然形成二次到店；
- 配合到期提醒订阅消息，券快过期时自动提醒顾客。

**话术要点**：满减/代金数字要具体（「满 100 减 20」比「大额优惠」有力）；强调「券在顾客手机卡包里，不用装 App」。

## 2. 茶饮 / 咖啡 / 烘焙

**典型痛点**：客单低、复购是命脉；周边同行多，拼价格伤利润。

**玩法组合 A：次卡锁客（主推）**
- 例：「咖啡 10 次卡」权益项为金额抵扣（如每次抵扣 9.9 元）；
- 核销间隔设「每天 1 次」，防一次核完；
- 次卡可转赠：喝不完送朋友，朋友来核销，新客自然进店。

**玩法组合 B：随机金额券活跃社群**
- 随机金额券（1~99 元随机）发到顾客群，模拟「抢红包」氛围；
- 公开领取 + 允许分享，群内互相转发扩散。

**玩法组合 C：新品/套餐推广**
- 套餐券配「套餐组合」明细（如「主食+饮品+小食 4 选 3」），券面直接写清内容。

**话术要点**：次卡强调「一杯的钱先收住十次的客」；随机券强调「群里抢券，气氛先热起来」。

## 3. 零售（便利店/服装/母婴/数码）

**典型痛点**：促销只会打折，没有抓手；店庆/节日活动没沉淀。

**玩法组合 A：店庆活动海报**
- 把多张公开券（满减、折扣、兑换）聚合为「活动海报」：一张页面发所有券；
- 活动海报可分享、可展示在商家主页，配海报发社交平台。

**玩法组合 B：清库存/推新品**
- 兑换券（凭券兑换指定商品）做赠品引流；
- 私密发放给老顾客：一对一链接限时 1 天，制造专属感。

**玩法组合 C：拉新裂变**
- 开启转赠 + 转赠奖励：老客把券转给好友，好友核销后老客再得一张指定券，双向得利。

**话术要点**：活动海报强调「一个链接发全店活动」；私密发放强调「一对一、限时、领后失效，比群发更被珍惜」。

## 4. 美业 / 生活服务（美容、美发、美甲、SPA、宠物）

**典型痛点**：靠手艺吃饭但获客贵；顾客做一次就走；办卡推销让人反感。

**玩法组合 A：次卡替代传统办卡（主推）**
- 例：「美发 5 次卡」权益项为服务型（免费洗剪吹一次）或折扣型（第 2 次起 8 折）；
- 核销间隔「间隔 3 天 1 次」，符合服务节奏；
- 次卡是送的（免费发放），不是卖的——**话术上避免「卖卡」，强调「送次卡锁客」**（产品无收费能力，不可宣传售卡）；但「买 X 次送 X 次」可指**商家线下收款后的促销活动**（商家经自己收银系统收款、再私密一对一发券，产品不参与收款），如「买10次送2次，钱先到账」口径可用（2026-08-15 用户确认）。

**玩法组合 B：体验券引流**
- 兑换券「凭券体验头皮护理一次」，公开领取 + 门店二维码；
- 需提前预约的，在券上写明预约说明与电话（券自带预约说明字段与一键拨号）。

**玩法组合 C：老带新**
- 转赠奖励：顾客转赠体验券给朋友，朋友到店核销后，双方各有所得。

**话术要点**：强调「顾客在手机里就能看到剩余次数，不用记小本子」；核销扫码即扣次，不怕扯皮。

## 5. 汽车服务（洗车、保养、美容）

**典型痛点**：洗车是入口业务但不赚钱；锁客全靠纸质卡，容易丢、难管理。

**玩法组合**：
- 次卡：「洗车 10 次卡」，权益项金额抵扣，核销间隔每天 1 次；
- 满减券：保养项目满 300 减 50，私密发放给洗车老客户；
- 员工专属二维码（加好友自动发券）：车主扫码加店长好友，自动收到洗车券，同时沉淀到私域好友，后续可群发保养提醒活动。

**话术要点**：「纸质次卡会丢，电子次卡不会」；「每次核销扣一次，剩几次一目了然」。

## 6. 连锁 / 多门店

**典型痛点**：总部想统一做活动，各店执行参差不齐；不知道哪个店做得好。

**玩法组合**：
- 总部统一制券，适用门店选全部门店或指定门店；
- 各门店员工按权限分发（发券员工名单可控制谁能发）；
- 核销时自动记录核销门店，门店发券/核销排行榜横向对比；
- 员工排行 + 我的业绩，激励一线。

**话术要点**：「一张券，十家店通用；谁发得多、哪个店核得多，排行榜见」。

## 7. 私域自动发券玩家（跨行业）

**典型痛点**：顾客好友加了不少，但除了聊天不知道干嘛；手动发券费人力还容易漏。

**玩法组合**：
- 加好友发券：把员工专属二维码铺到收银台/包裹卡/线下活动，顾客加好友自动得券；
- 进群欢迎语：新客进群自动弹领券卡片；
- 客户群发：大促前创建群发任务，员工确认后即触达全部客户；
- 客户中心沉淀：所有领券顾客可查、可备注、可导出。

**话术要点**：「加好友=自动发券，员工不用动手」；「私域不是好友数，是能随时触达的券」。

## 8. 扩展行业与客群（开放式，持续补充）

> 上面 1~7 类是已展开的示例，不是全部。券到卡包作为通用电子券工具，适用客群远不止于此。新增行业/客群时，先对照 00-产品事实表确认功能支撑，再补玩法。

| 客群 | 典型场景 | 可借力的功能 |
|---|---|---|
| 大商场 / 购物中心 | 统一做活动、多商户核销、楼层/门店排行 | 多门店、活动海报、门店/员工排行 |
| 企业行政（员工福利） | 节日/周年给员工发福利券包、内购券 | 券包、私密发放、群发（自动发券能力） |
| 物业 / 社区 | 社群运营、业主福利、便民服务券 | 加好友发券、客户群发、转赠 |
| 教培 / 生鲜 / 健身房 等 | 高频到店、锁客需求强 | 次卡、核销奖励、到期提醒 |

## 9. 发券用途场景（与「行业」交叉的另一维度）

同一行业可因「为什么发券」而用不同组合；用途场景本身是独立维度，规划时一并考虑：

- **员工 / 客户福利**：券包 + 私密发放 + 自动发券，不公开领；
- **会员回馈 / 老客锁客**：次卡 + 核销奖励 + 到期提醒；
- **节日 / 店庆礼包**：活动海报聚合多券 + 定时开抢；
- **异业合作 / 引流**：转赠 + 转赠奖励 + 公开领取。

- 每篇行业文章建议选 **1 个行业 + 2~3 个玩法组合**，讲透一个主线（如「茶饮店怎么用次卡锁客」），不要贪多；
- 文章结构参考 06-内容选题库；具体功能步骤细节以 02-业务流程.md 为准；
- 行业可根据实际拓展（如教培、生鲜、健身房），拓展时先对照 00 文档确认功能支撑，再补充本文档。
