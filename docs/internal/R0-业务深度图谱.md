## 一、产品全景

- 三产品：**优惠券（6 型）/ 券包 / 次卡（通卡·次卡·权益卡）**
- 主链路：制券 → 发券 → 领券 → 核销 → 统计；辅：作废 / 领取核销明细 / 转赠
- 商户体系：商户 → 门店（多门店）→ 员工（角色 + 权限）；客户中心（名单/导出）
- 企微四能力：加好友发券 / 进群发券 / 群小助理 / 客户群发

## 二、次卡（pages_card）

**数据字段（create.vue 核实）**：cardType（1 通卡/2 次卡/3 权益卡）、name≤32 字、cover 1 张（300×240）、totalStock 1~10000、userLimit 1~100 张/人、times 1~1000 次（仅次卡）、validType（固定/领当日/领次日）+ validDay 1~365、isVerifyInterval+verifyIntervalDay 0~30、isVerifySign（动态核销码）、theme（9 色）、benefitContent≤500、items（权益项：金额/折扣/服务）、storeIds/staffIds 必填、isTransfer 默认开、isGetMobile 默认关、content≤500（使用说明/使用须知，一键套模版）、productImages≤9。

**业务规则（视频干货核心）**：
- **核销间隔 0~30 天（0=每天 1 次）→ 锁客节奏的底层逻辑**：设 3 天=顾客每 3 天来一次，卡不睡死（P-01 玩法核心）
- 通卡/次卡/权益卡三种卖法：年卡不限次 / 10 次卡 / 权益逐项 → 对比型视频
- 动态核销码 + 转赠锁核销 = 防黄牛/防冒用
- 核销提示"第 X 次 / 剩余 N 次 / 最后一次" → 稀缺性话术
- 作废单次须选门店+填原因（顾客可见）→ 透明运营
- 转赠默认开，转赠期间锁核销

**统计维度**：指标=有效发放张数/核销次数/在店核销次数；排行=门店/员工发放核销、顾客核销、顾客转赠（总次数/成功率）、渠道；导出=领取/核销记录（需导出权限）。

## 三、优惠券（pages_coupon）

**新增功能（2026-08 代码更新，R1 需补录）**：
- **领取口令**：cipherType 0 关/1 固定/2 随机。固定=商家手输 5 位数字；随机=每 3 分钟变化、可手工刷新。C 端领券须输入口令。详情页"收款口令码"面板（切类型/改口令/倒计时/复制文案）。券包强制不支持。
- **指定手机号领取**：isMobileLimit 白名单，每行一个、去重、正则 `^1\d{10}$`、**最多 500 个**、可批量粘贴；开启自动勾选留手机号；C 端白名单/留手机号时每次领券必填手机号。

**字段/规则**：6 型券（代金/套餐/满减/折扣/兑换/随机，随机 1~99 整数）；发放 3 种（公开/私密/券包）；每人限领/自定义领取时间/每次 1~10 张/领取周期；每天核销限制/核销赠券/可用时段；核销=扫码或输券码，转赠中锁核销。
**状态机**：商家券 发放中/暂停/作废/过期/冻结（冻结不可删）；用户券 未使用/已用/作废/过期；转赠 转赠中（可取消）/取消/已领；核销奖励 默认/成功/失败/待补偿。
**统计**：我的业绩/发券渠道/门店发核销/员工发核销/顾客转赠/顾客核销（后 5 项按权限）。

## 四、券包（pages_bundle）

- **包券规则（2026-08-25 代码核实，R1 曾误写"最多 5 种、每种 1~10 张"）：2~10 种券、每种 1~5 张**；仅可选"券包"类型券、不可重复
- 领取玩法：1 一键全部 / 2 随机一种（官方"适合抽奖玩法"）/ 3 自选一种
- 字段：封面(5:4)、名称≤18、数量 1~10000、每人限领 1~100、主题、发券员工多选、使用须知≤500、留手机号开关

## 五、活动海报（pages_activity）

- 多券聚合（仅有效公开券、UI 无上限），顾客打开自选领取
- 海报画布 750×1200、主题色可切换（封面/名称/二维码/文案）
- 4 分发：微信好友/群、二维码、海报、公众号

## 六、商户 / 门店 / 员工 / 权限（pages_merchant）

- **商户认证**：4 态（未认证/审核中/已认证/审核拒绝）；营业执照+法人身份证，人工约 3 个工作日
- **门店**：编号 MD-xxx、省市区+地图选点、营业时间（24h 开关+多段）、客服电话；状态 正常/关店；审核 4 态
- **员工**：编号 YG-xxx、隐私脱敏开关（150\*\*\*\*3210）、状态 待确认/正常/离职/冻结（**冻结立即踢下线**）、绑定门店
- **角色**：品牌级（总部不绑店）/门店级/员工级；超管不可改、可"变更超级管理员"（双短信验证，旧超管降为普通员工）
- **邀请**：微信分享链接、先定默认角色+有效期（5 分钟/30 分钟/1 小时/12 小时/1 天）、绑定门店则入店；加入→申请-审批制（管理员批量通过/拒绝）
- **权限双级**：模块级（商户/门店/员工/券/券包/次卡/客户/海报，控入口显隐）+ 操作级（View/Create/Update/Delete/Issue/Verify/Export/Stat，控按钮显隐）
- **客户中心**：今日/昨日/总数；列表（昵称/手机/备注筛选，6 种排序）；详情（客户编码/手机补填/备注仅商家可见 255 字/领取核销数）；**导出 Excel（脱敏联动）**
- **操作日志**：操作人/角色/门店/IP/成功失败，可按员工查

## 七、企微（pages_wecom）

- **加好友发券**：员工专属"联系我"码、每次 1~10 张、超时 5 档（5 分钟/1 天/7 天/30 天/永久）、消息≤500（客户可见）+备注≤32（仅商家）；券/包/次卡均支持
- **进群发券**：欢迎语模板、新成员自动弹卡片；券/包/次卡均支持
- **群小助理**：群内 @小助理 + 关键字自助领券（仅优惠券）
- **客户群发**：选成员、卡片标题≤64+内容≤500；任务需成员在企微"群发助手"确认；每位客户每月条数受限（仅优惠券）
