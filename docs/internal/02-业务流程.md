## 1. 优惠券全链路（核心链路）

### 1.1 制券
1. 商户中心 →「制作卡券」→ 选择「制作优惠券」→ 选择券类型（代金/套餐/满减/折扣/兑换/随机金额）。
2. 填写表单：封面、名称、库存、门槛、面额类字段、有效期、可用时段、**发放方式（公开/私密/券包，创建后不可改）**、限领规则、适用门店、发券员工、使用须知等。
3. 提交成功 → 券进入「有效中（发放中）」状态。
4. 细节：
   - 未提交退出会自动保存草稿，下次进入提示续编（切换商家/登出会清除草稿）；
   - 支持「复制此券」快速创建新券；
   - 套餐券可配置套餐组合明细；
   - 使用须知支持「一键套用模版」与清空（券/券包/次卡通用能力）；
   - 适用门店仅「审核通过」的门店可选、发券员工仅「正常在职」可选，异常项展示但置灰。

### 1.2 券模板状态流转

```
制作成功 → 发放中(1) ⇄ 已暂停(2)     （暂停/恢复可反复切换）
发放中/已暂停 → 已作废(3)（模板级作废，不可恢复）
发放中 → 已过期(4)（有效期截止）
任意 → 已冻结(5)（冻结中的券不可删除）
已作废/已过期 → 删除（需逐项勾选确认）
```

### 1.3 发券
前提：券为「发放中」状态、操作人有发放权限（后端 `hasIssuePermission` + 权限点）。

**公开领取**（制券时选「公开领取」）：
- 渠道：微信好友/群（分享小程序卡片）、二维码（下载领券码）、海报（canvas 生成，保存相册）、公众号（已绑定公众号推送领券卡片/链接）、企微进群、企微小助理、企微客户群发。
- 可配置：自定义领取时间（定时开抢 + 倒计时）、每次领取 1~10 张、领取周期（日/周/月/年限额）、分享标题与封面、是否允许顾客分享。

**私密发放**（制券时选「私密发放」）：
- 每次发放生成一条发放记录：**数量 1~10 张、超时时间 5 分钟/1 天/7 天/30 天/永久、发放备注（仅商家可见）**。
- 渠道：微信好友（分享卡片，仅能领取一次领后失效）、二维码（扫码领取，领后失效）、企微加好友自动发。
- 私密记录状态：待领取(1) → 已领取(2) / 已过期(3) / 已作废(4)。

### 1.4 领券（顾客侧）
1. 顾客从分享卡片/扫码/海报小程序码进入对应领取页。
2. 页面展示：封面、券面、适用门店、使用须知、倒计时（公开定时抢/私密超时）。
3. 点击「领取卡券」→ 订阅消息授权（领取成功通知/到期提醒）→ 按商家设置走资料校验：
   - 商家开启「填写手机号」→ 顾客输入 11 位手机号（**无短信验证码**）；
   - 商家注册方式为「微信授权注册」且顾客未授权 → 微信一键授权登录；
   - 「匿名注册 + 免手机号」→ 静默注册直接领。
4. 领取成功 → 券进入顾客卡包，可弹「打开卡包」。
5. 领取拦截态：未开始 / 已结束 / 已抢光（库存为 0）/ 活动已停止 / 已作废；私密链接超时失效。
6. 领取记录状态：未使用(1) / 已使用(2) / 已作废(3) / 已过期(4)。

### 1.5 核销
1. 顾客打开券详情，出示核销码：**二维码（主）+ 条形码 + 数字卡号（兜底，可复制）**。
2. 商家入口：商户中心「扫码核销」（扫任意核销码直达）或核销台手动输入券码。
3. 系统自动校验：已使用/已过期/转赠中不可核销；开启「核销活码」时二维码 5 分钟刷新，过期码会被拦截提示。
4. 商家选择核销门店、可填备注（仅商家可见）→ 确认核销。
5. 核销完成：券变「已使用」；若开启核销奖励，系统自动再发本券一张（奖励状态：成功/失败/待补偿）。
6. 核销记录可查询、筛选、导出。
7. 误核销的补救：次卡支持「作废单次」；优惠券的核销记录详情无撤销入口（**不要对外承诺核销可撤销**）。

### 1.6 转赠（优惠券的社交玩法）
```
持券顾客（券未使用 + 券允许转赠）
   │ 填转赠备注（≤32字）→ 确认转赠
   ▼
券被锁定：核销码隐藏，显示「转赠中」，可取消
   │ 分享给微信好友/朋友圈（可多次分享）
   ▼
好友打开转赠领取页 → 校验有效性（已被领取/已取消会提示原因）→ 领取（同样走手机号/授权校验）
   ▼
仅首位领取的好友获得券 → 转赠成功，记录展示领取人
（若开启转赠奖励：受赠人核销后，原转赠人自动获得一张指定私密券）
```
- 转赠记录：转赠中(1) / 已取消(2) / 已领取(3)；转赠中可再次分享或取消。
- 次卡转赠流程相同（无转赠记录列表页）。

### 1.7 作废与删除
- **模板级作废**：作废券模板，该模板下所有「已领取未核销」的券一并作废；不可恢复；作废后才可删除。
- **领取记录级作废**：对单张已领取未使用的券作废（领取详情/核销台入口），需填原因。
- **删除**：仅已作废/已过期可删，冻结不可删；需勾选全部确认项。

### 1.8 统计
- 时间五档：今天/昨天/本月/上月/累计。
- 维度：我的业绩（员工个人）、本店数据、渠道排行、门店发券/核销排行、员工发券/核销排行、顾客转赠排行、顾客核销排行。
- 口径示例：渠道排行展示各渠道领取张数、被核销张数、核销率。

## 2. 券包全链路

1. **前提**：包内券必须是「发放方式=券包」的优惠券。制券时发放方式选「券包」，该券即可被券包挂载（该券不能单独发放）。
2. **创建券包**：封面、名称、库存（按个）、每人限领、领取玩法（一键全部/随机一种/自选一种）、主题色、包内券（≤5 种，每种 1~10 张）、须知。
3. **发放**：仅私密发放（微信好友/群、二维码、企微加好友），与私密券相同有超时时间设置。
4. **领取**：顾客打开领取页 → 按玩法领取（自选型先选一种券）→ 包内券按规则发出，成为顾客账户中独立的优惠券。
5. **使用**：券包详情页逐张查看包内券，点击跳各券详情页，按普通券核销。
6. **管理差异**：
   - 统计口径为「个（包）+ 张（券）」双层；
   - 作废券包：已领取的券包一并作废，领出后未核销的券一并作废，已核销的保留；**包内券模板本身不受影响**；
   - 领取详情可「批量作废所有待使用优惠券」。
7. 券包制券后直接可用；详情页会展示审核状态警示标签，但发放不受审核阻断（商家制券即生效，不提"审核/等待通过"）。

## 3. 次卡全链路

1. **创建**：次卡含 3 种类型（通卡/次卡/权益卡，详见 00 §3.3）。权益卡类型核心是「优惠内容」——最多 30 项权益，每项为金额/折扣/服务之一，**按核销顺序依次使用**（第 1 次核销用第 1 项，依此类推）；次卡（按次）类型填「每张次数」；通卡类型不限次数。
2. **发放**：仅私密发放（微信好友/群、二维码、企微加好友）；无封面不可发放。
3. **领取**：领取页展示磁条卡面、权益项、使用间隔说明 → 领取入卡包。
4. **核销（扣次）**：
   - 顾客出示次卡核销码，商家扫码/输码；
   - 校验：卡有效、有剩余次数、核销间隔满足（如「间隔 3 天可用 1 次」未满会提示）、动态码未过期、未转赠中；
   - 核销成功后展示「第 X 次：抵扣 ¥xx / 享 x 折 / 服务名称（已核销），剩余 N 次可用」；
   - 支持**作废单次**（误核销补救，恢复该次权益）。
5. **转赠**：与券相同（先到先得、可取消）。
6. **作废**：模板级作废（使用中的卡一并作废）；整卡作废（领取详情）。
7. **适用门店管理**：次卡详情页可查看/修改适用门店（至少选 1 家，作废态不可改）。
8. **统计**：已领取（张）、已核销（次）、已作废（次）；其余与券同构。
9. 次卡创建后需经平台审核通过（`auditStatus`）方可发放，审核未通过前发放按钮禁用（属平台安全合规机制，宣传中不提"审核/待审核"）；优惠券/券包均无此硬阻断。

## 4. 活动海报全链路

1. **创建**：把多张**有效的公开领取优惠券**聚合为一个活动（封面、名称、须知、是否展示在商家主页、是否允许顾客分享、上架/下架）。
2. **分发**：微信分享卡片 / 下载活动二维码 / 生成主题色海报 / 公众号（推送给已绑定公众号粉丝）。
3. **承接**：顾客打开活动海报 → 浏览活动内券 → 点「领取」逐张进入各券的公开领取流程。
4. **展示位**：勾选「展示在商家主页」后，商家主页（C 端）会列出该商家的活动。
5. **数据**：活动浏览量统计。
6. 注意：活动只是公开券的聚合展示页，券的库存、领取规则仍以各券自身配置为准。

## 5. 企业微信发券链路

### 5.1 授权与绑定（一次性配置）
1. 商家设置 →「企业微信」（需 CorpConfig 权限）→ 展示授权二维码 → 企业微信管理员扫码授权。
2. 企微环境内打开绑定页 → 校验（企微已授权、员工已加入对应商户）→ 选择/创建商户完成绑定。

### 5.2 加好友发券（顾客扫员工码，自动发券）
```
商家为某企业成员配置规则：关联产品（券/包/卡）+ 每次张数 + 超时时间 + 欢迎消息
   → 生成该员工专属的「联系我二维码」（可打印：台卡/海报/传单）
   → 顾客扫码添加员工为企微好友
   → 系统自动发送领券卡片（无需员工干预）
   → 顾客点卡片领取（私密领取链路）
```

### 5.3 进群发券（欢迎语自动发券）
```
商家创建群欢迎语模板（模板名 + 卡片标题 + 消息内容）
   → 在企业微信后台把欢迎语配置到目标客户群
   → 新成员进群自动弹出欢迎语 + 领券卡片
   → 成员点卡片领取
```

### 5.4 客户群发
选择发送成员 → 编辑卡片标题与消息内容 → 创建群发任务 → **成员在企业微信「群发助手」中确认后发出**。

### 5.5 群小助理发券（群内关键字自助领券）
群内开启「小助理」后，成员 @小助理 并输入关键字 → 系统自动回复对应领券卡片 → 成员点卡片领取（无需员工干预）。

> ⚠️ 企微首页「群发卡券」卡片为**死链缺陷**（`/pages_wecom/batch/index` 未上线页面），请勿引导顾客点击；演示企微群发请走 §5.4 客户群发。

## 6. 商户入驻与经营链路

### 6.1 入驻
```
微信授权登录 → 创建商户（门头照/名称/地区/地图地址/行业/营业时间 + 微信手机号
              + 必答「您是从哪里了解到我们的」：抖音/小红书/视频号/朋友推荐）
   → 进入商户中心
   →（建议）商家认证：营业执照 + 法人身份证 → 人工审核 → 顾客端展示「已认证」
```
流量来源归因：企微绑定页、卡包页脚品牌入口、分享链接 source 参数、跨小程序跳转等会携带来源标识（wecom/quandao 等），注册页自动识别带入，无需商家手选。

### 6.2 多门店与员工
```
添加门店（可多家）→ 邀请员工：选角色 + 邀请有效期 → 分享邀请链接
   → 员工填资料提交申请 → 管理员审批（通过/拒绝）→ 员工按角色权限使用商户中心
```
- 权限体系：模块级（控制商户中心功能入口显隐）+ 操作级（制券/发券/核销/查看记录/导出/统计细分等）。
- 员工管理：冻结（立即退出并拒绝登录）、隐私脱敏（手机号脱敏展示与导出）、操作日志（含 IP）、超管变更（双向短信验证）。

### 6.3 客户资产链路
```
顾客领券（按商家设置留手机号/微信授权/匿名）→ 自动成为该商家「客户」
   → 客户中心：新增统计、列表（按领券/核销数排序）、详情（领取/核销数据、备注）
   → 客户列表导出 Excel
顾客在卡包首页可出示「客户码」供商家识别身份（客户码页面仅已登录、已选店的商家员工凭权限可访问，顾客本人扫自己的码无效）
```

## 8. 发放渠道全景（CHANNEL_TYPE）

| 分组 | 渠道 |
|---|---|
| 公开 | 微信好友/群、二维码、海报、公众号、小程序链接 |
| 私密 | 微信好友/群、二维码、小程序链接 |
| 活动 | 活动海报 |
