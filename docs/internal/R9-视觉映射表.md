# R9-S · 文案→视觉映射表

> 属主：`R9-视觉导演与审美决策.md` 的执行辅助表。目的：把“知道原则”进一步变成“选视觉时有默认答案”。
> 本表不替代 R9 的审美判断；它提供默认起手式，最终仍以镜头主语、peak frame、空间层级和真实关键帧为准。
> **定位（2026-09-23 CHANGE-041）**：本表是**导演层的通用默认起手式（工具无关）**——“这镜头发生了什么变化、观众该盯什么”是叙事判断，不随风格变；表内具体构件名（大字／BigNumber／Timer／Coupon／手机模型等）是**当前已建成风格的实现举例（`remotion-components`）**：风格化片以**所选风格包的表达能力**替换举例，判据不变。风格包**不得**改写本表的叙事判断（**换包不换导演稿**，见 `R9-视觉导演与审美决策.md` §十五）。

## 一、默认选择矩阵

| 叙事任务 | 第一选择（举例＝remotion-components 构件；风格化片按所选风格包替换实现） | 第二选择 | 尽量不用 | 核心检查 |
|---|---|---|---|---|
| 反常识/认知反转 | 大字 + 尺度反转 + 留白 | 快切 + 锐化 | 信息卡堆叠 | 第一眼是否只有一个结论 |
| 规模/增长/差距 | BigNumber / 密度变化 | 数字滚动 + 聚拢 | 多张统计卡 | 数字是否成为唯一峰值 |
| 稀缺/快失效 | Timer / 余量递减 | 逐渐熄灭 | 红色警告框 | “正在减少”是否真的被看见 |
| 记住/惦记 | 持续存在的券/未使用状态 | 未读点/残留对象 | 反复字幕 | 对象是否在镜头内持续存在 |
| 核销/消耗 | 对象消失 / 状态切换 | QR→成功 | 静态“核销成功”文字 | 动画是否表达“被使用” |
| 领取/生成 | 新对象生成 / reveal | 按钮状态变化 | 大量说明文字 | “得到了一张新券”是否一眼成立 |
| 赠送/复制 | Coupon copy / duplicate | 新手机出现 | 两栏文字解释 | 新对象是否由旧对象产生 |
| 转赠/传播 | 位移 / 线性传递 | 两手机空间关系 | 五节点流程图 | 观众是否看到“从 A 到 B” |
| 奖励回流 | 光线回流 + 第二对象生成 | 次级状态亮起 | 静态奖励卡 | 奖励是否像结果而非另一块信息 |
| 操作教学 | 产品 UI + 状态变化 | 局部放大 | 全屏页面录屏 | UI 是否只承担产品证据 |
| 行业痛点/情绪 | 大字 + 环境层 + 稀疏对象 | 抽象密度/光影 | 假场景插画 | 是否在表达关系而不是“假装实拍” |
| 结果收口 | 单一对象 + 单句金句 | 单数字 + 留白 | 多项总结列表 | 是否给下一步/结束一个明确落点 |

## 二、三问选型法

每次确定一个镜头前，依次问：

1. **这句话真正发生了什么变化？**（出现 / 消失 / 复制 / 位移 / 聚拢 / 扩散 / 锐化 / 变暗）
2. **观众应该盯哪一个对象？**（数字 / 关键词 / 产品状态 / 关系线）
3. **如果删掉 70% 元素，什么必须留下？**

如果三个问题答不出来，不进入实现。

## 三、默认构图模板不是固定版式

- `Anchor + Breath`：一个视觉锚点 + 一块明确呼吸区。默认首选。
- `Vertical Depth`：前景产品 / 中景信息 / 背景氛围，优先于左右双栏。
- `Object Relation`：两个对象只因“关系”同时出现，例如手机 A→手机 B；禁止为了填满画面而各自加卡片。
- `Peak Isolation`：peak 前主动减法，peak 后主动清场。

本表不是四套可复制模板；它只规定构图思路，具体坐标、字号、色彩和动效全部由单片锚稿决定。

## 四、Shot 表最小字段

每个关键镜头至少记录：

`Shot / Duration / VO / Visual Subject / Visual Metaphor / Layout / Motion / Peak Frame / State Change / Text / Asset / Remotion / Exit`

其中 `Visual Metaphor + Peak Frame + State Change` 为强制字段；缺任意一项，视为仍处于文案层，不得直接进入代码。
