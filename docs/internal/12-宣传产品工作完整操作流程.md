# 12 · 宣传产品工作完整操作流程（SOP）

> 本文件是「券到卡包」**宣传与运营主流程**的总操作手册，整合 00~07、10、11 的执行步骤。
> 当前阶段重点：**产品运营与宣传**（获新商户），本流程仅为宣传推广线单一流程。
> 视频可用代码 UI 组件 + 项目商用字体 + 关键字等元素**自由组合**呈现（见 10）；当前制作不使用截图素材（非永久约束），原则上不 AI 生图主视觉。
> 任何一步拿不准，先回 `00-产品事实表.md` 核对能力边界，或标注「待确认」交人核实。

---

## 一、目标与范围

- **目标**：通过内容（文章/视频）让实体店老板知道、心动、注册「券到卡包」，完成首次制券。
- **范围**：宣传推广线（获客）+ 素材生产（代码 UI 组件绘制/可选插画生成/关键字提取/封面）。
- **暂不做**：付费投流。

## 二、角色分工

| 角色 | 负责 |
|---|---|
| AI（我） | 选题建议、文案、券组合设计、视频脚本（画面元素参数）、插画生成、豆包 TTS 调用、Remotion 9:16 合成、**封面：先从 `背景素材/` 索取、无合适时输出「详细引导」指引用户到创客贴等优秀设计网站查找制作（不 AI 生成封面）**、合规自查、归档 |
| 人（你） | 确认 AI 产出的插画/背景可用性并授权入库、提供火山引擎 Key/音色、确认 TTS 语速样片、按 AI 的「详细引导」到创客贴等优秀设计网站查找制作封面并回传、确认封面、最终发布、纠偏 |

## 三、完整操作流程

### 步骤 1 · 选题与场景
- 依据 06（选题库）+ 05（行业场景）确定本篇行业与选题（如 G02 茶饮咖啡）。
- 写行业泛称画像——用「咖啡店」等行业泛称讲解玩法，**不编具体商户名、不编真实案例**（04§7）。

### 步骤 2 · 券组合设计 + 边界校验
- 从 05 玩法中选 2~3 个，形成券组合表（优惠券/券包/次卡）。
- **边界校验**：逐字段对照 00§6（数值上限）与 00§8（能力边界）。次卡走私密发放、随机金额 1~99 整数、套餐券只写文字预约说明（不暗示在线预约）。

### 步骤 3 · 四件套文案（G 类）
- 活动设计总览 + 卡券制作单（逐字段 + 边界 + 使用须知）+ 发放组合与执行顺序 + 攻略文章 + 封面文案包（06 §九）。
- 数值以 00§6 为准，状态文案以后端 Label 为准。

### 步骤 4 · 视频脚本与画面元素清单
- 按 10 §9 参数形式产出脚本：`hookText` / `关键字序列[词+屏]` / `每屏 UI 组件布局 brief`（卡片/对比/流程/面板选型，服务哪句旁白）/ `可选纹理底纹` / `旁白口播稿` / `分平台 CTA`（抖音/小红书 / 搜狐文章）。
- 关键字从口播稿提取（10 §5）：每屏 1 个核心词，禁用极限词、数字以 00§6 为准。

### 步骤 5 · 视觉素材生成与确认（闸门）
- **UI 组件与字体**：用 Remotion 代码绘制各屏 UI 组件 + 项目商用字体排版（10 §2 / 11 §3）；纹理底纹可选自 `图标素材/图鱼素材/`。
- **插画（补充，非主视觉）**：仅在代码 UI 不足以表达时由 AI 按 brief 生成情境插画（11 §3 ⑤），附「AI 生成·待确认」声明（11 §4），**人确认后入 `插图库/`**。
- **闸门（重要）**：无声版画面**经人确认后**，才进步骤 6 调用 TTS——避免画面大改致旁白返工、浪费 TTS 字符额度。

### 步骤 6 · 文章配图
- 文章（搜狐长文等）配图 = 代码 UI 组件 + 项目商用字体 + 关键字 风格，与视频统一视觉语言，**不混真实截图**（11 §5）。
- 交付物带「素材清单」小节：UI 组件/字体说明 + （若有）插画（来源路径 + 入库状态）单列。

### 步骤 7 · 封面：索取/详细引导 + 文案包交付（08-17 统一：AI 不生成封面）

- 封面来源口径（SKILL §5.0）：**AI 先从 `背景素材/` 索取合适模板/素材**，库内有合适模板直接用；**库内无合适模板时，AI 输出「详细引导」**——给出检索词/尺寸规格（抖音 9:16 1080×1920、小红书 9:16、搜狐 16:9 1920×1080）/风格要点/版权需可商用，手把手指引用户到创客贴等优秀设计网站查找制作，按平台尺寸（抖音 9:16、小红书 9:16、搜狐 16:9 文章头图）交付（DPI 纵向标准 72，以像素尺寸判定清晰度）。**AI 负责找素材与出引导，不负责把封面做出来（不 AI 生成）**。
- 随稿另附**封面文案包**（系列条/主副标题/用图方向/排版留白说明）作为引导的一部分与回退依据。
- **与视频关系（2026-08-15 统一）**：抖音/小红书 9:16 封面为**未播放态缩略图（≠ 第一帧，可独立构图、更海报化）**；首帧**复用封面 hero 视觉**（同背景/主视觉/标题，可加动效延续，不必逐像素等于封面）——共用同一 hero 视觉语言，避免「封面一张图、开场又一张图」的割裂；搜狐 16:9 头图用于图文文章，属不同载体。
- **兜底（当 `背景素材/` 无合适模板、或用户想体验更丰富设计时）**：AI 输出「详细引导」+ 推荐下方专业设计网站（07 §3 末），指引用户到创客贴等优秀设计网站查找制作；用户把模板图回传后，AI 核对合规收口、确认可商用。
- **平台分级（重要）**：小红书/抖音/搜狐 封面**不得含小程序码**，CTA 用文字「券到卡包」（07 §5）；小程序码仅用于视频号等微信生态封面。
- **封面设计原则（07 §3）**：干净简洁、标题清晰结合内容、不堆"免费"等促销文案、具备第一直觉引流力。

### 步骤 8 · 视频生产（9:16 + TTS）
- 脚本：按 10 §9 参数形式（`hookText` / `关键字序列` / `每屏 UI 组件布局 brief` / `旁白口播稿` / 分平台 CTA）。
- 视觉：步骤 5 确认的代码 UI 组件 + 项目商用字体 + SVG 图标，关键字层从口播稿提取；**首帧复用步骤 7 封面 hero 视觉**（见步骤 7「与视频关系」）。
- 语音（闸门）：脚本阶段产出「旁白口播稿」文本，**但豆包 TTS 调用须等步骤 5 视觉确认之后**才执行（10 §7）；先出 5–10s 样片由人确认 `speech_rate=0` 常速，再合成全片。输出音频 `public/audio/*.mp3`。
- 合成：Remotion 按当前视频的分镜设计渲染 **9:16（抖音/小红书）** 单画幅（10 §3）。

### 步骤 9 · 测试—纠正循环
- **最小测试单元**：每轮只做 1 个单元（如一篇攻略正文 / 一个视频参数脚本），人审 → 列问题 → AI 改 → 沉淀《风格与规范备忘录》。
- 人每指出一处，AI 即时沟通并轮末汇总"踩坑点"，避免重复错。过审再扩量。

### 步骤 10 · 确认素材入库 + 归档
- 人确认过的插画（若有）/纹理，AI 归档进对应库（插图库/图标素材），标注场景，后续复用（11 §2）。
- 成品归档 `outputs/<编号>-<行业>/`，与文稿同目录（07 §3）。

### 步骤 11 · 发布（按渠道）
- 抖音/小红书：发 9:16 视频，CTA 绝口不提微信，引导关注/收藏（07 §5）。
- 搜狐：发长文攻略（图文文章），文章绝口不提微信搜索/小程序（导流仅限账号资料位）。
- 社群/地推辅助。

### 步骤 12 · 生产回顾（纠正依据，固定动作）
- **每条真片发布（或人审定稿）后**，AI 按本步骤建一份回顾笔记（格式见本步骤第 2–3 行），存 `outputs/生产回顾/<编号>-<日期>.md`。
- **内容**：规范执行核对（照 docs/internal/10 勾选）+ 纠正点（规范哪里不好用 / 被打破）+ 插画质量（最匹配 / 最糙）+ 节奏观感 + 下次 TODO。
- **用途**：作为"出实际产品后纠正、补充规范"的原材料——真片暴露的问题记下来，轮末把「沉淀结论」回写 docs/internal/10 / docs/internal/11，**避免凭记忆改规范**。

## 四、红线汇总（全程不可破）

> **完整铁律红线见 `quandao-content` skill §二（单一权威，冲突以此为准）**。本流程执行时须始终守住以下要点：

- 不虚构功能（00§8）、不编案例数据（一律行业泛称）、数字以 00§6 为准；
- 视频/文章配图以代码 UI 组件 + 项目商用字体 + 关键字等元素自由组合（AI 生图原则上不用于主视觉）；**当前制作不使用截图素材、不显真实产品 UI**（非永久约束）；不编虚构界面（硬红线）。
- 分平台 CTA：三平台文章/视频绝口不提微信/小程序/搜索（导流仅限账号资料位）；
- 三平台封面/视频/文章配图严禁小程序码及微信系二维码；
- 抗同质化（风格轮换）、保完播率（前 3 秒强钩子、≤180s）。
