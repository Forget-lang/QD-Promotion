# 12 · 宣传产品工作完整操作流程（SOP）

> 本文件是「券到卡包」**宣传与运营主流程**的总操作手册，整合 00、02、04~07、10、11、13 的执行步骤。
> 当前阶段：宣传推广线冷启动（获新商户），无真实案例，正文用行业泛称。
> 任何一步拿不准，先回 `00-产品事实表.md` 核对能力边界，或标注「待确认」交人核实。

---

## 一、目标与范围

- **目标**：通过内容（文章/视频）让实体店老板知道、心动、注册「券到卡包」，完成首次制券。
- **范围**：宣传推广线（获客）+ 素材生产（代码 UI 组件绘制 / 可选插画 / 关键字提取 / 封面）。
- **暂不做**：付费投流。

## 二、角色分工

| 角色 | 负责 |
|---|---|
| AI | 选题建议、文案、券组合设计、设计稿（含本地素材检索与源路径标注）、代码执行（data/gXX.ts）、豆包 TTS 调用、Remotion 渲染、封面素材索取与引导输出（不 AI 生成封面）、合规自查、归档 |
| 人 | 确认设计稿、从本地素材库选取或按规格找图并复制到 `video/public/`、提供 TTS Key/音色、确认语速样片、按引导制作封面并回传、确认无声版画面、最终发布、纠偏 |

## 三、完整操作流程

### 步骤 1 · 选题与场景
- 依据 06（选题库）+ 05（行业场景）确定行业与选题（如 G02 茶饮咖啡）。
- 用行业泛称讲解玩法，**不编具体商户名、不编真实案例**。

### 步骤 2 · 券组合设计 + 边界校验
- 从 05 玩法中选 2~3 个，形成券组合表（优惠券/券包/次卡）。
- **边界校验**：逐字段对照 00§6（数值上限）与 00§8（能力边界）。次卡走私密发放、随机金额 1~99 整数、套餐券只写文字预约说明（不暗示在线预约）。

### 步骤 3 · 四件套文案（G 类）
- 活动设计总览 + 卡券制作单（逐字段 + 边界 + 使用须知）+ 发放组合与执行顺序 + 攻略文章 + 封面文案包。
- 数值以 00§6 为准，状态文案以后端 Label 为准。

### 步骤 4 · 视频设计稿（AI 核心产出，闸门）
- 按 **13 §5 模板**产出完整设计稿：视频元信息 / 风格配置五维 / 相似度检查（≥3 维不同）/ 逐屏分镜表（帧级动画时序）/ 图片素材清单 / 口播稿 / 合规自查。
- 口播稿、关键字、每屏 UI 布局 brief 全部在设计稿中定稿，不再单独产出「脚本」。
- 动画时序写到帧级（组件名、delay、easing），禁止模糊描述（13 §1.1）。
- **图片素材清单**：先按 13 §4.1 检索本地素材库，本地有合适的标注源路径；不足才输出外部找图规格（13 §4.3）。
- **闸门**：人确认内容方向/风格/素材来源后，才进步骤 5。

### 步骤 5 · 视觉素材准备与代码执行
- **素材（人执行 + AI 核对）**：本地素材从根目录复制到 `video/public/` 对应子目录（13 §4.1 路径引入机制）；外部找图放入同一目录结构。AI 核对尺寸/风格/版权。
- **代码（AI 执行）**：新建 `data/gXX.ts` 填入 scenes + style；复用 `components/` + `scenes/`；如需新积木按 13 §7.2 扩展；新图标用 Icon MCP Server 检索/生成后转内联组件（13 §8.3）；图片用 `staticFile()` 引用。
- **技术硬规则**：全部动画用 useCurrentFrame + interpolate/spring、禁止 CSS animation、motion 透传 style.motion、非 spring 插值用 EASE_OUT、场景间 TransitionSeries 转场（13 §2）。
- **验证**：`npx tsc --noEmit` 零错误 → 每屏单帧 still 验证 → 无声版全片渲染。
- **渲染命令必带** `NODE_OPTIONS=""` 前缀（skill §七硬执行约束）。
- **闸门**：无声版画面经人确认后，才进步骤 8 TTS。

### 步骤 6 · 文章配图
- 搜狐长文配图与视频统一视觉语言（代码 UI + 商用字体 + 关键字），**不混真实截图**。
- 配图素材清单标注来源（本地库路径或外部来源）。

### 步骤 7 · 封面（素材索取/引导 + 文案包）
- **AI 先从 `背景素材/` 索取**合适模板/素材；库内无合适时输出「详细引导」（检索词/尺寸/风格/版权要求），指引人到创客贴等设计网站制作。**AI 不生成封面。**
- 随稿附封面文案包（系列条/主副标题/用图方向/排版留白）。
- 封面 = 未播放态缩略图（≠ 第一帧，可独立构图、更海报化）；首帧复用封面 hero 视觉（共用同一视觉语言，13 §5.2/07 §3）。
- 尺寸：抖音/小红书 9:16（1080×1920）、搜狐 16:9（1920×1080）。
- 三平台封面不得含小程序码；设计原则见 07 §3。

### 步骤 8 · 视频生产（9:16 + TTS）
- 视觉：步骤 5 确认的代码 UI + 字体 + 图标，关键字层从设计稿口播稿提取；首帧复用步骤 7 封面 hero 视觉。
- 语音（闸门）：TTS 调用须等步骤 5 无声版确认后才执行（10 §7）；先出 5–10s 样片确认 `speech_rate=0` 常速，再合成全片。输出 `public/audio/gXX-narration.mp3`。
- 合成：无声版 + 音频压合，整片时长 = 音频时长，声画同步，无字幕。

### 步骤 9 · 测试—纠正循环
- 每轮只做 1 个单元，人审 → 列问题 → AI 改 → 沉淀踩坑点。过审再扩量。

### 步骤 10 · 确认素材入库 + 归档
- 人确认过的插画（若有）/纹理归档进对应库（11 §2）。视频引用的本地素材已在步骤 5 复制到 `video/public/`，无需重复操作。
- 成品归档 `outputs/gXX-行业/`（目录规范见 AGENTS.md）。

### 步骤 11 · 发布（按渠道）
- 抖音/小红书：发 9:16 视频，CTA 见 07 §5（自然收尾，不硬推关注/收藏，可轻署「券到卡包」）。
- 搜狐：发长文攻略，导流仅限账号资料位。
- 社群/地推辅助。

### 步骤 12 · 生产回顾（固定动作）
- 每条真片发布（或人审定稿）后，AI 建回顾笔记存 `outputs/archive/{日期}-gXX-生产回顾.md`。
- **内容**：规范执行核对 + 纠正点 + 插画质量 + 节奏观感 + 下次 TODO。
- **回写**：把沉淀结论回写到 13（视频技术）或 skill（红线/SOP），**避免凭记忆改规范**。

## 四、红线汇总

> 完整铁律红线见 `quandao-content` skill §二（单一权威）。本节仅列高频踩线点速查。

- 不虚构功能（00§8）、不编案例数据（行业泛称）、数字以 00§6 为准、禁极限词
- 分平台 CTA：三平台文章/视频绝口不提微信/小程序/搜索，导流仅限账号资料位
- 三平台封面/视频/文章配图严禁小程序码及微信系二维码
- **核销活码不在宣传中使用**（2026-08-17 决策），核销只讲「扫码核销、手动输码兜底」
- 视觉素材优先级：代码 UI → 本地素材库 → AI 补充插画（待人确认）→ 外部找图；AI 生图不用于主视觉
- 当前不使用截图、不显真实产品 UI（非永久约束）
- 「免费使用」可说但不着重强调；CTA 自然收尾，不硬推关注/收藏
- 抗同质化（风格轮换，相似度 ≥3 维不同，见 13 §3.2）、保完播率（前 3s 强钩子、≤180s）
