## 二、内容线：当前仅做宣传推广线

本产品当前只做**宣传推广线**——让实体店老板知道、心动、注册「券到卡包」。其余内容线不在本知识库范围。

| 维度 | 宣传推广线（当前唯一内容线） |
|---|---|
| 目的 | 获取新商户：让人知道、心动、注册 |
| 受众 | 还没用券到卡包的商家老板 |
| 语气 | 讲价值、讲场景、讲痛点，允许渲染 |
| 内容形态 | 软文、短视频、图文卡片、行业方案、案例故事 |
| 分发 | 抖音（9:16 视频）、小红书（9:16 视频）、搜狐（图文文章）+ 社群、地推物料 |
| 引用文档 | 00 + 04 + 05 + 06 + 07 + 10 + 11 + 12 |

写任何内容前先确认属于宣传推广线。宣传稿不是操作手册（不夹带操作步骤、不夹带营销式教程）。

## 三、AI 创作路由规则

拿到内容需求时，按以下顺序执行：

1. **确认内容线为宣传推广线**（当前唯一内容线）。
2. **必读 `00-产品事实表.md`**——尤其是「能力边界」一节，确认要写的功能点都在清单内。
3. **按需读对应文档**（见索引表「谁该读」列）。
4. **功能描述拿不准时**：宁可回同级 `../applet/` 代码里核对（页面路径、按钮文案以代码为准），也不要凭印象写；仍不确定则标注「待确认」交人工核实。
5. **术语统一**：使用 00 文档术语表中的标准叫法（如「核销」不写「消费验证」，「次卡」不写「计次卡」）。
6. **封面图必交付**：产出宣传线图文/文章/图集/视频内容时，AI 先从本项目资源库 `背景素材/`（商用字体/背景素材/图标素材，不含截图素材）索取合适模板；**库内无合适模板时，AI 输出「详细引导」**（检索词/尺寸/风格/版权要求）指引用户到创客贴等优秀设计网站查找制作，随稿附封面文案包，回传后 AI 核对合规收口（详见 07 §3）。AI 不生成封面。无封面不算交付完成。
7. **宣传线视频**：脚本按 10-视频制作方案 的参数形式交付（钩子/关键字序列/每屏 UI 组件布局 brief/旁白稿 + 分平台 CTA）；视频以代码驱动 UI 组件 + 项目商用字体 + 关键字等元素自由组合呈现（原则上不 AI 生图主视觉），Remotion 9:16 单画幅合成，豆包 TTS 补旁白（不使用字幕）；AI 负责代码绘制 UI、调用 TTS、Remotion 合成，人负责确认画面质量、确认 TTS 语速样片、最终发布。AI 不画虚构界面；当前制作不使用截图素材（用户决策，非永久）。

**链路总览（什么工具干哪件活）**：

| 生产环节 | 工具/方式 | 分工 |
|---|---|---|
| 行业痛点 | AI 搜集（行业知识 + 网络搜索）→ 痛点表 +「不写」清单（05） | AI 出草稿，人确认 |
| 文章标题/正文/标签 | AI 按 00/05/06（G 类四件套 / 文章六件套） | AI 出稿，人审核定稿 |
| 封面图 | AI 先从 `背景素材/` 索取合适模板；无合适时 AI 输出「详细引导」（检索词/尺寸/风格/版权要求）指引用户到创客贴等优秀设计网站查找制作；AI 不生成封面 | AI 找素材+出文案包+出引导，人按引导制作/兜底/发布 |
| 宣传视频 | Remotion（10）：代码驱动 UI 组件 + 项目商用字体 + SVG 内联图标 + 关键字，9:16 单画幅 + 豆包 TTS 旁白（无字幕），原则上不 AI 生图 | AI 代码绘制 UI/调TTS/9:16 合成，人确认画面质量+确认语速+发布 |
| 文章/内页配图 | 代码 UI 组件 + 项目商用字体 + 关键字 统一视觉语言（10/11），与视频一致 | AI 代码绘制/选背景纹理，人确认 |
| 发布/数据/复盘 | 各平台 + 手工记录 | 人 |

## 四、铁律（任何内容创作都必须遵守）

> **完整铁律红线见 `quandao-content` skill §二（单一权威，所有内容创作以它为准）**。核心三条底线：

1. **不虚构功能**：只写 00-产品事实表存在的能力（无在线支付/收款、无短信验证领券、无趋势图表、无在线预约、无第三方对接等）。
2. **不编案例与数据**：当前暂无真实商户案例，一律用行业泛称（咖啡店/火锅店/美容店等）指代，不编虚构店名、不编数据。
3. **数字与约束准确**：库存上限、券包种类、有效期范围等数值以 00 §6 为准；禁用极限词。

视频另守：不用截图/不显产品 UI、分平台 CTA（角标按 2026-08-15 决策当前暂不加，详见 skill）。

## 五、维护约定

- 产品功能变更后，**先改本知识库对应文档，再产出新物料**。重点同步：00（功能清单/能力边界）、02（链路变化）。
- **守门脚本**：`scripts/check-redlines.mjs`（违禁词唯一数据源 `scripts/redlines.json`）——改动红线/CTA/事实口径后必须运行收口（code 层零命中才算对齐完成），详见 `quandao-content` skill §八。
- 新增真实商户案例后，补充到 04-宣传策略.md 的「案例素材」一节，并同步更新 06 选题库中案例类选题的状态。
- 文档中出现「待确认」标记的条目，由产品/开发确认后消除。
- 本知识库不存放临时草稿与过程文件。
- **纠错机制**：用户纠正 AI 的理解时，AI 须在同一轮内完成：①改正 docs 对应文档；②写入长期记忆；③回查已产出的受影响稿件并标记或修订。只口头承认不改文档视为未完成纠正。
- **效力层级**：00-产品事实表 > 其余 docs 文档 > outputs 过程文档；发现冲突按上层当场修正下层。
- 文档与代码不符时标「待确认」交人工核实，不得虚构、不得默默猜测。
- 资产库（与 docs 同级，人工/AI 协同维护）：`商用字体/`（字体库，视频须 bundle）、`背景素材/`（封面/视频背景底图）、`图标素材/`（771 纹理图案/装饰，含 `图鱼素材/` 子目录）、`插图库/`（AI 生成插画/过渡元素，经确认后归档，新方向主视觉以代码 UI 组件为主、插画作补充）；`截图素材/` 已于 2026-08-14 由用户删除，**当前制作不使用截图、不显真实产品 UI**，如需回查产品真实界面须先与用户对齐（事实源始终是同级 `../applet/` 代码）。视频项目 `video/`（Remotion）已建。素材「确认即入库」机制见 11。视频视觉方向见 10（代码驱动 UI 组件，非 AI 生图主视觉）。
- 项目技能在 `.workbuddy/skills/`：**`quandao-content` 为单一权威**（红线+核心模型+生产SOP+风格库）；平台薄皮技能 `douyin-short-video` / `xiaohongshu-note` / `sohu-longform`（只写平台特有手艺，红线一律引用 quandao-content）。2026-08-15 精简：顶层 `skills/` 通用营销技能（copywriting / content-strategy / banner-design 等）已删除，避免与 quandao-content 冗余。特别提醒：本项目视频**不使用字幕**。技能管「怎么写怎么做」，docs 管「事实与规范」；**冲突时分层级裁决：红线/合规以 quandao-content（skill）为准，产品事实以 `docs/internal/00` 为准**。
