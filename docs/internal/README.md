## 四、维护约定

- 产品功能变更后，**先改本知识库对应文档，再产出新物料**。重点同步：00（功能清单/能力边界）、02（链路变化）。
- **守门脚本**：`scripts/check-redlines.mjs`（违禁词唯一数据源 `scripts/redlines.json`）——改动红线/CTA/事实口径后必须运行收口（code 层零命中才算对齐完成），详见 `quandao-content` skill §八。
- **纠错机制**：用户纠正 AI 的理解时，AI 须在同一轮内完成：①改正 docs 对应文档；②写入长期记忆；③回查已产出的受影响稿件并标记或修订。
- **效力层级**：00-产品事实表 > 其余 docs 文档 > outputs 过程文档；发现冲突按上层当场修正下层。
- **资产库**（与 docs 同级）：`商用字体/`、`背景素材/`、`图标素材/`、`插图库/`、`截图素材/`（2026-08-19 恢复使用，用于文章配图，视频不用）。
- **项目技能**（`.workbuddy/skills/`）：`quandao-content` 为单一权威（红线+核心模型+生产SOP+风格库）。
  - 冲突裁决：红线/合规以 SKILL 为准，产品事实以 00 为准，视频技术以 13 为准，SOP 以 12 为准。
