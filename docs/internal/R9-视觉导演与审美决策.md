# R9 · 视觉导演与审美决策

> 定位：视觉决策层。R3 负责“怎么实现”，R7 负责“有什么积木”，R9 负责“什么时候该用什么，以及为什么这样看起来更好”。
> 本文件不替代 SKILL 的作业流程；SKILL 决定做什么，R9 决定画面如何形成视觉表达。

## 一、核心目标

把“高级感 / 不像 PPT / 有质感 / 有节奏”转换成可复述、可执行、可审片的视觉决策。

## 二、六维视觉决策

每个关键镜头必须回答六件事：

1. **Visual Subject**：这一镜的视觉主语是什么。
2. **Visual Metaphor**：口播的抽象关系用什么视觉隐喻表达。
3. **Spatial Composition**：主体、留白、前中后层级如何组织。
4. **Motion Meaning**：为什么动、动向哪里、速度为什么这样设。
5. **Attention Curve**：这一镜的关注峰值在哪一帧，峰值前后如何留白。
6. **Exit Logic**：这一镜如何退出，以及如何把注意力自然交给下一镜。

## 三、视觉主语

“一个镜头一个主语”指的是一个视觉主导关系，不是一个镜头只能有一个元素。

允许：手机 A → 手机 B → 奖励券，只要主导关系始终是“券发生转移”。

禁止：标题、数字、三张卡、流程线、图标、字幕同时争夺第一注意力。

优先级：产品状态变化 > 结果数字 > 核心关键词 > 装饰。

## 四、视觉隐喻

当现实素材不可用时，不模拟廉价场景；提取叙事关系，再用程序化视觉表达。

| 叙事意图 | 优先视觉语言 |
|---|---|
| 规模/增长 | 大数字、滚动、密度变化 |
| 稀缺/即将失去 | 倒计时、余量、逐渐熄灭 |
| 记住/惦记 | 未读、未使用、持续存在的对象 |
| 核销/消耗 | 对象消失、状态切换 |
| 赠送/生成 | 新对象复制、生成、出现 |
| 转赠/传播 | 对象位移、连线传递 |
| 奖励回流 | 光线回流、第二状态生成 |
| 认知反转 | 快切、尺度反转、视觉留白 |

## 五、构图

每镜先定“主区域”，再决定次级元素。

默认遵循：
- 主体有明确空间锚点。
- 至少保留一块呼吸区。
- 装饰不得侵入主视觉层级。
- 竖屏先考虑上下纵深，再考虑左右分栏。
- UI 不是默认全屏。

信息越复杂，越应减少同屏对象，而不是缩小字号硬塞。

## 六、动效语义

动画必须对应一个语义动作：

- 出现 = 被注意/生成/进入视野
- 消失 = 使用/离开/被消耗
- 复制 = 奖励/新增/再得一张
- 位移 = 转赠/传递/关系改变
- 聚拢 = 注意力集中/结果形成
- 扩散 = 传播/裂变
- 锐化 = 认知明确/关键句落地
- 变暗 = 失去/退出/过渡

禁止无语义的“为了好看而动”。

## 七、Attention Curve

每个关键镜头只设置一个 peak frame。

推荐节奏：

`建立状态 → 累积 → peak → 停留/确认 → 退出`

peak 前避免堆叠新的高权重元素；peak 后主动减法，为下一镜留注意力空间。

## 八、动效性格

动效不统一为一个速度。

- **Snappy**：问题、结论、关键数字。
- **Heavy**：产品实体、手机、券、重要结果。
- **Soft**：背景、烟雾、光晕、氛围。
- **Elastic**：奖励、生成、轻惊喜。
- **Linear/Drift**：只有需要持续匀速移动的环境元素才使用。

具体参数回 R3；本层只决定语义与选型。

## 九、排版决策

优先顺序：

`关键词 > 数字 > 解释文字 > 装饰`

普通口播不自动变成字幕海报。

一个镜头只有在文案本身构成视觉事件时，才使用大字主视觉。

## 十、产品 UI 决策

UI 的任务是提供“产品证据”，不是负责制造氛围。

适合 UI：设置、核销、状态、领取、转赠、奖励。

不适合 UI：老板痛点、行业规模、情绪、抽象洞察。

当一个 UI 镜头无法通过状态变化完成叙事，应优先重构镜头，而不是继续添加 UI 元素。

## 十一、纯 Remotion 场景转换

默认无外部场景素材。遇到“排队、空店、顾客、老板、夜市”等现实场景要求时，先抽取信息关系，再转换成：

`数字 / 大字 / 产品状态 / 连线 / 密度 / 光影 / 粒子 / 空间`

禁止使用低质占位图假装真实场景。

## 十二、质量诊断词典

用户说“廉价”时，优先检查：
- 同层级对象是否过多
- 卡片是否成为主视觉
- 动效是否机械同频
- 阴影/渐变是否过度
- 是否缺少空间层级
- 是否缺少停顿

用户说“乱”时，优先检查：
- 是否有多个视觉主语
- 是否所有元素都在动
- 是否文字过多
- 是否没有主次

用户说“空”时，优先检查：
- 主体尺寸是否不足
- 是否缺少纵深
- 是否缺少环境层
- 是否应该增加视觉隐喻，而不是增加装饰

## 十三、审片顺序

先看：
1. 第一眼主语
2. 注意力峰值
3. 信息层级
4. 空间层级
5. 动效语义
6. 转场逻辑
7. 细节质感

不得反过来先修阴影、圆角、字号等细节，再发现整镜构图错误。

## 十四、与其他文档的边界

- `R3`：Remotion 原理、API、动画参数与工程实现。

- `R9`：视觉决策、审美判断、镜头语言与文案→视觉的转换。
