> 这是给你看的项目总览。技术细节、执行手册都在 `docs/internal/`（AI 内部文档），你不用打开。

## 一、我们在做啥
「券到卡包」是一个**免费的电子券工具（小程序）**，帮实体店做电子券：制券 → 发券 → 领券 → 扫码核销 → 统计，还支持企业微信自动发券。
当前我们只做一件事：**宣传推广、吸引实体店老板来了解使用**。

## 二、在哪发
- **抖音**：发短视频
- **小红书**：发图文笔记
- **搜狐**：发文章（不带视频）
就这个分法，简单。

## 三、你给我啥（素材）
- 小程序前端代码（同级 `../applet/`）：让我知道这个工具**真实能做到什么**，我只宣传真实有的功能，不瞎编。
- **背景素材 / 商用字体 / 图标素材**：你慢慢收集、慢慢丰富；AI 也会帮你找优秀设计参考来补全。

## 四、我（AI）负责啥
- 创意规划 + 视频 / 文章制作。Remotion 怎么用、视频能做到什么程度、术语是啥——都是我的事，你不用管。
- 你只看成品三点：**卖点讲清没、画面美不美、语音跟画面齐不齐**。

## 五、底线（不可破）
- 不虚构代码里没有的功能；用行业泛称（咖啡店/火锅店…），不编具体商户、不编数据。
- 三平台都**不能出现小程序码**；软种草为主、不硬广。
- 保完播：单条 ≤180s，前 3 秒要抓人。
