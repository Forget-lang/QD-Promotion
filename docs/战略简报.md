# 券到卡包 · 战略简报（你唯一需要读的这一页）
> 最后校验：2026-09-16（变更史见 docs/changes/，本文不复述）。

> 这是给你看的项目总览。技术细节、执行手册都在 `spec/`、`docs/internal/`（AI 内部文档），你不用打开。

## 一、我们在做啥
「券到卡包」是一个**免费的电子券工具（小程序）**，帮实体店做电子券：制券 → 发券 → 领券 → 扫码核销 → 统计，还支持加好友自动发券。
当前我们只做一件事：**宣传推广、吸引实体店老板来了解使用**。

## 二、在哪发
- **抖音**：发短视频
- **小红书**：发图文笔记
- **搜狐**：发文章（不带视频）
就这个分法，简单。

## 三、你给我啥（素材）
- 小程序前端代码（`../applet/`，即 promotion/ 上级目录中的 applet/）：让我知道这个工具**真实能做到什么**，我只宣传真实有的功能，不瞎编。
- **背景素材 / 商用字体 / 图标素材**：你慢慢收集、慢慢丰富；AI 也会帮你找优秀设计参考来补全。
- **新片开工，你先核一眼母题一页的「〇 视觉定位卡」四栏（核心痛点 / 情绪关键词 / 视觉关键词 / 禁止出现）+「背景素材张数」**（2026-09-14 定，SKILL 第 2 步强制）：这是本片的情绪契约 + 素材纪律，AI 必须先定出来才谈画面。你只要扫一眼——那四栏像不像本行业、张数是不是很小（1 张底多重构图，不逐屏讨素材）——不合就退给 AI，别让它带着空缺做片子。

## 四、我（AI）负责啥
- 创意规划 + 视频 / 文章制作。Remotion 怎么用、视频能做到什么程度、术语是啥——都是我的事，你不用管。
- 你只看成品三点：**卖点讲清没、画面美不美、语音跟画面齐不齐**。
- **发布后只需你加一个动作（2026-09-14 定）**：片子发布约 24 小时/一周后，把抖音后台这几个数发我给 AI——**播放量 / 封面CTR / 2秒跳出 / 完播**。判向（该修入口还是开口还是结构）由 AI 按漏斗做，你只出数。**这就让下一条片有真数据可依、不靠猜**——之前播放上不去，缺的正是这一步"数据没回流"。

## 五、内容怎么做
- **核心思路**：按业态讲玩法——不是罗列我有什么功能，而是站在老板角度讲"开咖啡店/理发店/健身房，具体怎么用电子券拉客、锁客、做裂变"。
- **观众是 0 接触（2026-08-30 用户拍板）**：实体店商家没打开过这个产品，所以"讲场景"和"教会怎么用"不许分成两段——一条片子把这套攻略讲透：要用到的每一项该选什么、填什么值、为什么要这么设，场景与教程同格（画面里填进去的值就是场景）。细则见 SKILL 第 3、4 步。
- **一个行业拍成一个系列，一条视频讲一套攻略（同日三次敲定）**：判定单位是**用一条闭环故事讲透的一套攻略**（从某个最痛的时刻引出）——五拍走到底：先抛痛点做悬念 → 讲懂背后道理 → 用示例证明 → 落到可照抄的做法 → 一句金句收口。**功能点不求多**：一条攻略用到哪几个就讲哪几个（兑换券怎么设、满减券怎么只给指定手机号的人、转赠奖励怎么走到账），**每个都讲透讲明白**；用不上的不提。想讲的多了就会变成每个都提一句，不吸引人也不细致，那就拆成下一个痛点的视频（下次讲券包、或者换一套玩法）。画面重心放在"怎么做这张券"：逐项陈列要设的内容，着重讲哪一项必须这么设、为什么。**难理解的讲透，简单的不细说**——发券、领券这种一次就会的动作不占屏；要设数据的私密发放、以及核销页上"这张券是不是别人转赠的、奖励发没发成功"才值得说。每片独立成立，不许说"看上一条"。
- **尺子分两层（同日拍板）**：事实与合规全部机检（红线词、上屏字段名回 `../applet/` 源码取证、假 UI、观众反应数字）；"懂不懂/直不直白/风格是否雷同"用人判——自检问句 + 看真图，**不许写成数量配额或检查清单**（配额会做出雷同的片子）。
- **玩法库**：我们曾针对门店经营场景（锁客、裂变、拉新、复购、唤醒沉睡老客、会员日、闲时填充、提客单价等）整理过一套通用玩法。原件已随 2026-08-29 清零重启物理删除（git 历史可查），做法已并入 SKILL 第 1 步——现在选攻略直接按 SKILL 走，不存在独立的"玩法库"可挑（AI 内部文档，你不用读）。
- **视频标准**：至少 6 个信息单元、前 3 秒必须抓住人是硬性；时长不设固定区间，按行业复杂度自然落位（落位区间与硬上限以 `SKILL.md` §二 第 3 步为准）——时长和字数是内容深度的结果，不硬凑（拍板与修订史见 docs/changes/）。**按系列分片之后，落位档位按"每片自己那套攻略"计，不再拿一个行业的总时长去套一档。**

## 六、底线（不可破）
- 不虚构代码里没有的功能；用行业泛称（咖啡店/火锅店…），不编具体商户、不编数据。
- 三平台都**不能出现小程序码**；软种草为主、不硬广。
- 暂不加「AI 技术制作」角标，待浏览效果评估
- 完整红线规则以 `spec/redlines.json`（红线唯一真源）为准。
