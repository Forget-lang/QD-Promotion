# 券到卡包 · 战略简报（你唯一需要读的这一页）

> 这是给你看的项目总览。技术细节、执行手册都在 `spec/`、`workflow/`、`docs/internal/`（AI 内部文档），你不用打开。

## 一、我们在做啥
「券到卡包」是一个**免费的电子券工具（小程序）**，帮实体店做电子券：制券 → 发券 → 领券 → 扫码核销 → 统计，还支持加好友自动发券。
当前我们只做一件事：**宣传推广、吸引实体店老板来了解使用**。

## 二、在哪发
- **抖音**：发短视频
- **小红书**：发图文笔记
- **搜狐**：发文章（不带视频）
就这个分法，简单。

## 三、你给我啥（素材）
- 小程序前端代码（`../applet/`，即 promotion/ 上级目录中的 applet/）：让我知道这个工具**真实能做到什么**，我只宣传真实有的功能，不瞎编。
- **背景素材 / 商用字体 / 图标素材**：你慢慢收集、慢慢丰富；AI 也会帮你找优秀设计参考来补全。

## 四、我（AI）负责啥
- 创意规划 + 视频 / 文章制作。Remotion 怎么用、视频能做到什么程度、术语是啥——都是我的事，你不用管。
- 你只看成品三点：**卖点讲清没、画面美不美、语音跟画面齐不齐**。

## 五、内容怎么做
- **核心思路**：按业态讲玩法——不是罗列我有什么功能，而是站在老板角度讲"开咖啡店/理发店/健身房，具体怎么用电子券拉客、锁客、做裂变"。
- **玩法库**：我们整理了 7 套通用玩法（P-01~P-07），覆盖锁客、裂变、拉新、复购、闲时填充、储值替代、提客单价等门店经营场景。每个行业从玩法库里挑最合适的来组合做内容。详细玩法库见 `workflow/策划弹药库.md` §1（AI 内部文档，你不用读）。
- **视频标准**：一条 8-10 屏、60-150 秒（按玩法复杂度自然落位，上限 200 秒）、至少 6 个信息单元，前 3 秒必须抓住人；时长和字数是内容深度的结果，不硬凑。

## 六、底线（不可破）
- 不虚构代码里没有的功能；用行业泛称（咖啡店/火锅店…），不编具体商户、不编数据。
- 三平台都**不能出现小程序码**；软种草为主、不硬广。
- 暂不加「AI 技术制作」角标，待浏览效果评估
- 完整红线规则以 `spec/redlines.json`（红线唯一真源）为准。

## 七、我们怎么协作
- 你提想法 = 抛线索，**规划交给我**；有分歧我先跟你对好口径再动，不擅自把你的话钉成死规定。
- 文档要改动、或要删文件，我先把清单给你确认。
- 上下文被压缩、怕记偏时，我会把关键决定回读给你确认，不乱写。
