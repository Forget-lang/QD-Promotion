## G02 视频 Remotion 专业级评估与优化
对 `video/src/` 全量源码做了专业级 Remotion 评审，发现并修复 10 项技术问题：
1. **motion 风格维度失效**（T1，最严重）：`style.motion:'buttery'` 声明了但所有动画组件硬编码默认 `'bouncy'`，场景调用未透传 motion 参数 → 全部 7 个场景透传 `style.motion`。
2. **转场名不副实**（T2）：用 `<Sequence>` 硬切，与 `transition:'wipe'` 声明不符 → 安装 `@remotion/transitions@4.0.507`，接入 `TransitionSeries` + `wipe({direction:'from-bottom'})`，0.4s spring 转场；`getPresentation()` 按 style.transition 分发，未来视频换值即换型。
3. **S2 右卡嵌套动画时序 Bug**（T3）：`<SlideInRight delay=14><ScaleIn delay=40>` 导致 slide 期间 opacity=0 白做，40 帧才弹出 → 合并为单 spring 同步驱动 translateX+scale+opacity。
4. **S4 节点点亮瞬切**（T4）：boolean `f > threshold` 导致颜色/透明度硬切 → `interpolate`+`interpolateColors` 15 帧平滑过渡。
5. **S1 钩子缺数字视觉**（T5）：hookStyle:'number' 但无数字动画，标题用 ScaleIn 而非设计稿写的 wipe → 新增 `WipeIn`（clip-path）组件；「十次」拆为绿色「10次」spring 弹入 + Pulse 强调；浮动周期 2.1s→3.1s 更克制。
6. **S6 箭头静态**（T6）：↑/↓ 无动画 → 入场后 translateY 脉冲。
7. **S7 装饰线方向错误**（T7）：width% 从左展开 → scaleX 从中心 draw-on + 标题微脉冲。
8. **缓动不统一**（T8）：多处插值无 easing 或线性 → 统一 `Easing.bezier(0.16,1,0.3,1)`（expo-out），导出 `EASE_OUT`。
9. **下划线宽度 bug**（T9）：`text.length*30` 对中文严重偏宽 → `text.length*size*0.55`，cap 380px。
10. **SlideTag 瞬现**（T10）：加入场淡入。

新增组件：`WipeIn`（clip-path 擦入）、`Pulse`（单次脉冲强调）。
验证：`tsc --noEmit` 零错误；6 个关键帧 still 渲染通过（S1/S2/S3/S4/S6/S7）；`check-redlines` code 层零命中。
