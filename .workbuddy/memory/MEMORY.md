## 红线速记（完整真源见 14 号文档）

- 不虚构功能、不编案例数据、禁极限词
- 三平台不提微信/小程序/搜索，禁小程序码，导流仅限账号资料位
- 企微泛称：不说「企业微信/企微」，说「加好友/进群自动发券」
- 核销活码不在宣传中提，只讲「扫码核销、手动输码兜底」
- 次卡/券包仅私密发放，无公开领取
- CTA = 品牌名 + 价值主张（具体文案由设计稿定制），不硬推关注收藏

## 内容模式速记（完整标准见 08 号文档）

- **业态讲玩法**：选细分业态（不选大行业），从玩法库 P-01~P-07 选 1 主 + 1 辅
- **深度硬指标**：≥6 个信息单元 + ≥2 层递进 + 三重绑定（场景/操作/目的）
- **屏数**：推荐 8-10 屏，深度达标可浮动。屏数是结果，不是原因
- **差异化**：风格五维与上一条 ≥3 维不同 + 场景序列至少 3 个位置不同
