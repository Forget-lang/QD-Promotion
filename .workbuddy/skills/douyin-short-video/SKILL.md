# 抖音短视频 Playbook

> 本技能只讲**抖音平台特有手艺**。红线（不虚构功能/不编数据/禁小程序码/绝口不提微信/软种草）与生产 SOP 一律以 14 号文档为准，冲突以 14 号文档为准。本技能不重复红线，只补平台细节。

## 一、平台特性（为什么这么写）

- 抖音是**算法推荐**平台：完播率、互动率、转粉率决定流量池。**完播率 <15% 十分钟停推**（14 号文档 §2.2#10）。
- **站外导流零容忍**：微信/小程序/搜XX/VX 等暗语，AI 语义识别，一次降权多次封号 → **视频与文案绝口不提微信**（14 号文档 §2.2#6）。
- **同质化严打**：相似度 >25% 压流量池；同行业不同选题也要换风格（14 号文档 §六）。
- 单条 **目标 120-150s，上限 200s**，以把当前设计点一次讲透为准，不硬切「下个视频」钩子。

## 二、前 3 秒强钩子（完播率生死线）

前 3 秒决定划走率，必须**静音可懂**（很多用户静音刷）。钩子五型（每型给本行业换词即可）：

| 类型 | 公式 | 示例（餐饮） |
|---|---|---|
| 反差型 | 「你以为 X，其实 Y」 | 「你店里的老客，正被隔壁一张券悄悄撬走」 |
| 数字型 | 「N% 的 X，第一件事就做错了」 | 「90% 的奶茶店，第一张券就做错了」 |
| 提问型 | 「为什么 X，却 Y？」 | 「为什么隔壁火锅店，周一也满台？」 |
| 故事型 | 「上周有个老板跟我说……」 | 「上周有个开面馆的老板跟我说……」 |
| 挑战型 | 「不花一分钱，让 X，你做得到吗？」 | 「不花一分钱让老客带新客，你做得到吗？」 |

**纪律**：钩子句必须与后文强相关，不许「标题党开场、内容无关」——平台会判低质。

## 三、软种草结构（防硬广限流）

带明显导流外链的视频自然推荐低约 62%。结构：

1. **Hook（0–3s）**：钩子句 + 视觉冲击（代码 UI 组件大字标题）
2. **痛点（3–10s）**：把商家痛点讲具体（同行密集/价格战/不锁客）
3. **解法软种草（10–20s）**：讲「券到卡包」怎么帮（随机金额券/次卡/兑换券），只讲真实功能
4. **价值点（stagger）**：逐条亮卖点，节奏错落
5. **CTA（末 3–5s，屏幕停留 ≥5s）**：自然收尾，不硬推关注/收藏；必须出现品牌名「券到卡包」，具体收尾文案由设计稿定制

## 四、封面（抖音特有）

- 9:16 竖版；封面 = **未播放态缩略图（≠ 第一帧）**，决定 feed 里是否点击，可独立构图、更海报化。
- 首帧复用封面 hero 视觉（同背景/主视觉/标题，可加动效延续），避免「封面一张图、开场又一张图」。
- **发布时必须手动设置封面并关闭「自动同步首帧」**——否则平台默认取首帧，独立封面不生效。
- 封面来源（2026-08-17 统一，14 号文档 §5.0）：AI 先从 `背景素材/` 索取；无合适模板则 AI 输出「详细引导」——给检索词/尺寸 9:16 1080×1920/风格/版权要求，指引用户去创客贴等优秀设计网站查找制作，回传后核对收口；AI 不生成封面。

## 五、发布与自查清单

- □ 前 3s 静音可懂、有钩子
- □ 全程无微信/小程序/搜索字样、无小程序码
- □ 「免费」可说但不着重强调；无极限词、无虚构数据
- □ 单条目标 120-150s，上限 200s，一次讲透，无「下个视频」钩子
- □ 封面已手动设置、关闭自动同步
- □ 同行业不同选题风格有差异（防同质化）
- □ 结尾不硬推关注/收藏/去领券
