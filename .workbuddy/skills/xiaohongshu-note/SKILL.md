# 小红书 Playbook

> 本技能只讲**小红书平台特有手艺**。红线（不虚构功能/不编数据/禁小程序码/绝口不提微信/软种草）与生产 SOP 一律以 `quandao-content` skill 为准，冲突以 quandao-content 为准。

## 一、平台特性

- 小红书是**种草社区**：搜索 + 推荐双入口，**关键词布局**决定被搜到（商家老板会主动搜「奶茶店 会员 券」这类词）。
- 内容形态：**图文笔记 + 视频**。视频与抖音同一条（9:16），封面可微调；图文笔记是小红书独有优势形态。
- **软种草 >> 硬广**：带明显导流外链自然推荐低约 62%；做「痛点+玩法干货+价值」。
- **同质化严打**：相似度 >25% 压流量池；同行业不同选题换风格。
- 站外导流零容忍：**绝口不提微信/小程序/搜索**（quandao-content §2.2#6）。

## 二、图文笔记结构（小红书独有）

1. **标题（≤20 字，含搜索关键词）**：把商家会搜的词放进去，如「奶茶店怎么锁住回头客」「火锅店淡季怎么办」。
2. **封面图**：3:4 竖版，标题大字居中留白；小红书在 feed 里按 3:4 裁切**中间区**——关键信息放中间，别被裁掉。
3. **正文**：痛点开头 → 玩法干货（分点讲）→ 价值收尾；行业泛称、不编数据。
4. **标签**：行业词 + 场景词（#茶饮 #咖啡店 #门店经营 #电子券）。

## 三、视频笔记要点

- 与抖音同一条 9:16 视频，**封面可微调**（小红书更吃「干净高级」的封面审美）。
- 封面 3:4 裁切中间区：构图时把主标题/主视觉放画面中间 3:4 安全区。
- 正文配 2–3 句种草文案 + 标签，别只丢视频链接。

## 四、封面（小红书特有）

- 封面 = **未播放态缩略图（≠ 第一帧）**，可独立构图、更海报化；首帧复用封面 hero 视觉。
- 小红书封面按 **3:4 裁切中间区**——标题/主视觉务必落在中间安全区。
- 封面来源（2026-08-17 统一，quandao-content §5.0）：AI 先从 `背景素材/` 索取；无合适模板则 AI 输出「详细引导」——给检索词/尺寸/风格/版权要求，指引用户去创客贴等优秀设计网站查找制作，回传后核对收口；AI 不生成封面。

## 五、发布与自查清单

- □ 标题含搜索关键词、≤20 字
- □ 封面 3:4 裁切后关键信息仍在中间区
- □ 全程无微信/小程序/搜索字样、无小程序码
- □ 「免费」可说但不着重强调；无极限词、无虚构数据
- □ 图文笔记有分点干货 + 标签；视频笔记配种草文案
- □ 结尾不硬推关注/收藏/去领券
