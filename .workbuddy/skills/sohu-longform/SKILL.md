# 搜狐长文攻略 Playbook

> 本技能只讲**搜狐平台特有手艺**。红线（不虚构功能/不编数据/禁小程序码/绝口不提微信/软种草）与生产 SOP 一律以 `quandao-content` skill 为准，冲突以 quandao-content 为准。

## 一、平台特性

- 搜狐是**门户 + 搜索收录**平台：文章会被搜索引擎收录、长期沉淀流量，是「搜索端内容沉淀、利于收录」的阵地。
- 定位 = **品牌曝光 + 引流**；与抖音/小红书一致，**文章绝口不提微信/小程序/搜索**（导流仅限账号资料位，quandao-content §2.1#5）。
- 形式：**图文长文攻略**（不带视频），16:9 头图。
- 相对抖音/小红书，搜狐对导流更宽容，但**本项目口径已统一**：三平台文章/视频均不提微信搜索/小程序，不设例外。

## 二、长文攻略结构（G 类深度攻略）

1. **标题**：含行业关键词 + 价值承诺，利于搜索收录（如「奶茶店锁客攻略：电子券怎么发才有效」）。
2. **16:9 头图**：与视频共用同一 hero 视觉语言（背景/主视觉/标题一致），不同载体不割裂。
3. **痛点开头**：把商家痛点讲具体（同行密集/价格战/不锁客/时段不均）。
4. **玩法干货分点讲**：随机金额券/次卡/兑换券/活动海报怎么组合，只讲真实功能（quandao-content §2.1#1）。
5. **价值收尾**：自然引导了解产品，不硬推、不出现微信搜索/小程序字样。

## 三、SEO 关键词布局

- 标题 + 首段 + 小标题里自然埋入商家会搜的词（行业词 + 场景词）。
- 正文用小标题分节（利于收录与阅读）。
- 行业泛称、不编具体商户名、不编数据（quandao-content §2.1#2）。

## 四、头图（搜狐特有）

- **16:9 横版**头图，与抖音/小红书 9:16 封面共用同一 hero 视觉语言。
- 头图来源（2026-08-17 统一，quandao-content §5.0）：AI 先从 `背景素材/` 索取；无合适模板则 AI 输出「详细引导」——给检索词/尺寸 16:9 1920×1080/风格/版权要求，指引用户去创客贴等优秀设计网站查找制作，回传后核对收口；AI 不生成封面。

## 五、发布与自查清单

- □ 标题含行业关键词、利于搜索收录
- □ 16:9 头图已配，与视频 hero 视觉一致
- □ 全文无微信/小程序/搜索字样、无小程序码
- □ 「免费」可说但不着重强调；无极限词、无虚构数据
- □ 小标题分节、关键词自然埋入
- □ 结尾不硬推关注/收藏/去领券
