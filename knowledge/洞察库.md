# 洞察库 · 道理弹药库（闭环故事「理解」层的燃料）

> 定位：**表达引擎的燃料，不是选题主轴，也不是台词库。** 主轴始终是「这个行业怎么用电子券把活动做好」；本库的机制只在闭环故事的「理解」段登场——给功能点一个「为什么这么做」的人性依据，让观众从「会照抄」升级到「懂了为什么」。
> **用途边界（2026-09-17 CHANGE-020 落定）**：本库的「定律」句是**理解机制的索引语言**，**不是可直接复制的口播语言**。层级链条钉死：
>
> ```text
> 定律 → 机制理解 → 当前行业 / 人物 / 情境 → 选择表达形态 → 原创表达
> ```
>
> **切断「定律 → 台词」直连**：任何把定律句（或其近义改写）直接搬进口播、画面文字的做法一律拒收。每条机制下方的「讲法形态空间」列出**已被明确区分的可用实现**，供选择，不是配额。
> 每条定律 = 定律 + 心理机制 + 适用行业痛点 + 承载的真实功能 + 讲法形态空间 + 语料出处。语料出处指 `knowledge/爆款整片解剖.md` 的 JP 编号（借思路不搬话术）。
> ⚠️ 语料原话部分含平台违禁表达（诱导互动、储值预付、编造案例），本库只抽「道理」，一切产出照过 `check-redlines` 与铁律一（不编案例数字）。经营效果类的数字一律改机制化描述，见 `SKILL.md` 第 3 步「数字锚点翻译」。

## 定律一 · 不珍惜律（白给的东西不被珍惜）

- **定律**：免费、随手可得的东西，人不会珍惜；要让人珍惜，得让他「付出一点」才拿到。
- **心理机制**：努力正当化 + 损失厌恶——人高估自己付出过努力得来的东西的价值。
- **适用行业痛点**：老板群发券，顾客领了一堆不用；上门发传单被当废纸。
- **承载的真实功能**：私密发放（一对一给到对的人）、指定手机号可领取（不是公开谁都能领）、转赠奖励（要转出去才有奖励）。
- **讲法形态空间**（≥2 个已区分的可用实现；选一个用，不是每片都用）：
  - 观察型：镜头只盯顾客拿到券的那一下——随手领的进了卡包就再没打开；排队抢到的那张，当晚就用掉了。
  - 算账型：把「门口见人就发」与「到点才开抢」两种发法摆一起算——同样发出去了券，回店核销的那部分差在哪里。
  - 反例型：先说老板此刻正在做的事（发了一大把没人用），再给改法，让观众自己看见差别。
- **语料出处**：JP-02「对人好，他反而不珍惜」、JP-09「凡未经努力获得的东西都不珍惜」。

## 定律二 · 门槛换珍惜（有条件的券才被当回事）

- **定律**：给「拿到」设一个门槛（限人数/限时间/限对象），券才从「垃圾」变成「机会」。
- **心理机制**：稀缺性 + 投入感——越难得到越想要，拿到后越想用掉。
- **适用行业痛点**：券发出去一大把，核销率极低；顾客囤着不来。
- **承载的真实功能**：每人限领总量、领取开始时间（到点才能领）、私密发放数量控制。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 现场型：把两行设置摆到观众眼前——不限领 vs 每人限领一张，就这一行，客人的重视程度不一样。
  - 故事型：老板把「到点开抢」做成了每周固定的节目，群里那两分钟是大家最活跃的时候。
  - 对话型：用一问一答把门槛演出来——「现在能领吗？」「还没到点，晚上八点。」
- **语料出处**：JP-09「直接给 vs 争取来」的对照实验讲法。

## 定律三 · 占便宜感（让顾客觉得占了便宜，又不用真掉价）

- **定律**：顾客买不买账，不在实际便宜多少，在他「感受到」自己占了便宜——用门槛数字把优惠包装成「划算」，而不是「降价」。
- **心理机制**：面子 + 身份认同——顾客要的是「我赚到了」的体面，不是承认自己在贪便宜。
- **适用行业痛点**：直接打折伤利润、拉低品牌；不打折又没客流。
- **承载的真实功能**：满减券（「满 X 减 Y」，用门槛让优惠显得有来头）、代金券（「X 代 Y」）。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 算账型：把「直接打七折」与「满一百减三十」并排算给老板看——让出去的差不多，客人记住的却是「我够格了」「我赚到了」。
  - 对照型：同一个优惠写成两句话，摆出两种顾客反应，让观众自己挑哪句更像话。
  - 观察型：盯着结账那一刻——用门槛的客人会主动往上凑单，氛围完全不同。
- **语料出处**：JP-02 金句「顾客占了便宜，但他不认为自己是来占便宜的」、JP-06「觉得亏？其实相当于打八折」拆穿式。

## 定律四 · 到期焦虑（损失厌恶把顾客推回来）

- **定律**：券有个期限，快到期的损失感会推着顾客回头用掉——「不用就亏」比「用了划算」更催人。
- **心理机制**：损失厌恶——人对「即将失去」的痛苦感受强于「可能得到」的快乐。
- **适用行业痛点**：发出去的券石沉大海，客人不来核销。
- **承载的真实功能**：有效期（给一个「到哪天不用就作废」的边界）、到期提醒（到点推送提醒）。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 观察型：券在卡包里躺了很久没人动，临到期突然被用掉——推着他来的不是想念，是不想亏。
  - 对话型：用两句话把紧迫感演出来——「这张还有两天到期。」「那我明天过来。」
  - 算账型：把「有效期三十天」与「三天」摆一起算——长有效期看着宽容，短有效期才有回店的节奏。
- **语料出处**：JP-09「三天不作废，你不来也得来，因为不来你自己感觉有损失」。

## 定律五 · 先埋后揭（约束条件先给，机制后面再拆）

- **定律**：讲故事时先把「限制条件」埋在开头，后面拆机制那一拍观众才恍然大悟「原来老板稳赚的原因早埋在这」。
- **心理机制**：认知闭合 + 顿悟——先留一个反直觉的钩，揭底时补齐认知，获得感翻倍。
- **适用行业痛点**：讲解干巴巴，观众一带而过，记不住也转不出去。
- **承载的真实功能**：任意功能讲解的叙事结构——选中功能点后，先亮「这对老板意味着什么限制/反复」，再逐项拆怎么设。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 故事型：先讲一个反常识的做法（比如只给某个冷门时段优惠），把疑问留给观众，讲完机制再揭底。
  - 现场型：把限制条件先打在画面上，观众带着「为什么」往下看，后半段逐项拆开。
  - 对照型：先让观众猜一个错误原因，再用机制把猜测推翻。
- **语料出处**：JP-08 法国餐厅「只在淡季时段免单」先埋约束、概率拆解后揭底。

## 定律六 · 具体到不可疑（参数颗粒度 = 可信度）

- **定律**：把数字给到「具体到不可疑」的颗粒度，可信度自然立起来——「三斤二两」比「食材很好」可信一百倍。
- **心理机制**：可信度启发式——越具体越像真的，越像真的越被当行家。
- **适用行业痛点**：教程像空话，老板觉得「你在讲抽象道理，不是教我做」。
- **承载的真实功能**：券面额、有效期天数、限领张数、核销次数等「示例值」（标「示例」，数值取自 `spec/facts.json` / `spec/coupon-fields.json` 上限内自由设）。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 对照型：把「服务很用心」与「每天早上六点去市场挑一趟」并排摆，让颗粒度自己说话。
  - 算账型：把参数摆出来算一遍——这个次数是怎么来的、这个间隔是怎么定的、这个天数管多久。
  - 现场型：镜头跟着老板的手，一边设一边把具体值念出来。
- **语料出处**：JP-05「每只剁 36 块、油温 220 度、精确到三斤二两」。

## 定律七 · 过程即内容（演示「普通人怎么做」比晒结果更留人）

- **定律**：观众要看的不是「做好的结果」，是「一个普通老板在一步步怎么设、哪里会卡、卡了怎么改」的实录——过程自身就是内容。
- **心理机制**：代入感 + 学习动机——看别人磕磕绊绊做成，比看完美成品更能让我觉得「我也行」。
- **适用行业痛点**：老板不会设券，怕自己学不会；看成品截图无感。
- **承载的真实功能**：功能点逐个走「怎么设 → 为什么这么设 → 设完哪一方看到什么」的演示链路。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 现场型：老板一边操作一边说这一步为什么这么填，观众跟着学；卡壳的地方也留着。
  - 对照型：第一版设置错了、客人反应不对，改第二版——把纠偏过程本身当内容。
  - 对话型：教练逐句带老板拍口播的过程实录（JP-12 原样本形态）。
- **语料出处**：JP-12 全片是教练逐句带老板娘拍口播的过程；其「人群场景钩 → 视觉证据 → 数字背书 → 主张收束」四句模板可迁移。

## 定律八 · 认知缺口（把痛点定义成认知缺口，不是能力缺口）

- **定律**：老板不是「没能力」把生意做好，是「缺一个知道怎么做的认知」——把痛点讲成认知缺口，观众才信「补上这块我就能成」，而不是被教做人。
- **心理机制**：归因重构——把「我做得差」这种自我否定，翻成「我少懂一招」这种可补的缺口，保护自尊、激发动机。
- **适用行业痛点**：老板觉得「我生意不好是因为没客人/没命」，陷入无力感。
- **承载的真实功能**：开场钩子 + 功能点选择的取舍逻辑（选能补上那条认知缺口的功能线）。
- **讲法形态空间**（≥2 个已区分的可用实现）：
  - 观察型：从观众看得见的现象切入（某个时段就是没人来），再把原因指向一个可补的缺口。
  - 反例型：把「生意不行是因为命/位置/运气」与「我少懂这么一手」摆一起，让观众自己选信哪个。
  - 算账型：把「缺什么」量化成一道能算的题——差的那部分到底差在哪个动作上。
- **语料出处**：JP-05「你缺的不是好味道，是让别人知道你味道好的方法」、JP-14「把玄学讲成机制」。

## 使用方式（挂进五拍的「理解」段）

五拍是认知功能骨架（吸引 → 保持 → 理解与相信 → 落地 → 收口），本库服务其中的「理解」段。**本库是引擎之一，不是每片必用的固定素材源**：

- **进入方式二选一（设计入口，不是两套可套用的模板）**：
  - **机制入口**：先定要讲清哪条机制（从本库选），再把它落到本行业的具体情境与人物上；
  - **场景入口**：先从行业里一个具体情境/现象出发，再回指它对应了哪条机制。
- **落地链条**：机制理解 → 当前行业 / 人物 / 情境 → **从该条的「讲法形态空间」里挑一个适合本片的形态** → 原创表达。**禁止把定律句（或其近义改写）直接搬进口播或画面文字。**
- **收口**：把整片收束成一句可转发的认知（可选；收口方式不限）。
- **选择留痕**：本片用了哪条机制、走哪个入口、选了哪种形态、上一条片用过什么形态——写进内容输入包《表达形态选择及理由》（选择证据，非数量配额）。

本库**不设「每片必须用几条定律」的配额**；一条讲透 > 八条点到。形态空间是**知识资产完整度要求**（每条 ≥2 个已被明确区分的可用实现），不是「每片必须选两个」。
