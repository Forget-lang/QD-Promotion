# 洞察库 · 道理弹药库（闭环故事「讲道理」层的燃料）

> 定位：**表达引擎的燃料，不是选题主轴。** 主轴始终是「这个行业怎么用电子券把活动做好」；本库的定律只在闭环故事的「讲道理」那一拍登场——给功能点一个「为什么这么做」的人性依据，让观众从「会照抄」升级到「懂了为什么」。
> 每条定律 = 定律 + 心理机制 + 适用行业痛点 + 承载的真实功能 + 语料出处。语料出处指 `knowledge/爆款整片解剖.md` 的 JP 编号（借思路不搬话术）。
> ⚠️ 语料原话部分含平台违禁表达（诱导互动、储值预付、编造案例），本库只抽「道理」，一切产出照过 `check-redlines` 与铁律一（不编案例数字）。经营效果类的数字一律改机制化描述，见 `SKILL.md` 第 3 步「数字锚点翻译」。

## 定律一 · 不珍惜律（白给的东西不被珍惜）

- **定律**：免费、随手可得的东西，人不会珍惜；要让人珍惜，得让他「付出一点」才拿到。
- **心理机制**：努力正当化 + 损失厌恶——人高估自己付出过努力得来的东西的价值。
- **适用行业痛点**：老板群发券，顾客领了一堆不用；上门发传单被当废纸。
- **承载的真实功能**：私密发放（一对一给到对的人）、指定手机号可领取（不是公开谁都能领）、转赠奖励（要转出去才有奖励）。
- **语料出处**：JP-02「对人好，他反而不珍惜」、JP-09「凡未经努力获得的东西都不珍惜」。

## 定律二 · 门槛换珍惜（有条件的券才被当回事）

- **定律**：给「拿到」设一个门槛（限人数/限时间/限对象），券才从「垃圾」变成「机会」。
- **心理机制**：稀缺性 + 投入感——越难得到越想要，拿到后越想用掉。
- **适用行业痛点**：券发出去一大把，核销率极低；顾客囤着不来。
- **承载的真实功能**：每人限领总量、领取开始时间（到点才能领）、私密发放数量控制。
- **语料出处**：JP-09「直接给 vs 争取来」的对照实验讲法。

## 定律三 · 占便宜感（让顾客觉得占了便宜，又不用真掉价）

- **定律**：顾客买不买账，不在实际便宜多少，在他「感受到」自己占了便宜——用门槛数字把优惠包装成「划算」，而不是「降价」。
- **心理机制**：面子 + 身份认同——顾客要的是「我赚到了」的体面，不是承认自己在贪便宜。
- **适用行业痛点**：直接打折伤利润、拉低品牌；不打折又没客流。
- **承载的真实功能**：满减券（「满 X 减 Y」，用门槛让优惠显得有来头）、代金券（「X 代 Y」）。
- **语料出处**：JP-02 金句「顾客占了便宜，但他不认为自己是来占便宜的」、JP-06「觉得亏？其实相当于打八折」拆穿式。

## 定律四 · 到期焦虑（损失厌恶把顾客推回来）

- **定律**：券有个期限，快到期的损失感会推着顾客回头用掉——「不用就亏」比「用了划算」更催人。
- **心理机制**：损失厌恶——人对「即将失去」的痛苦感受强于「可能得到」的快乐。
- **适用行业痛点**：发出去的券石沉大海，客人不来核销。
- **承载的真实功能**：有效期（给一个「到哪天不用就作废」的边界）、到期提醒（到点推送提醒）。
- **语料出处**：JP-09「三天不作废，你不来也得来，因为不来你自己感觉有损失」。

## 定律五 · 先埋后揭（约束条件先给，机制后面再拆）

- **定律**：讲故事时先把「限制条件」埋在开头，后面拆机制那一拍观众才恍然大悟「原来老板稳赚的原因早埋在这」。
- **心理机制**：认知闭合 + 顿悟——先留一个反直觉的钩，揭底时补齐认知，获得感翻倍。
- **适用行业痛点**：讲解干巴巴，观众一带而过，记不住也转不出去。
- **承载的真实功能**：任意功能讲解的叙事结构——选中功能点后，先亮「这对老板意味着什么限制/反复」，再逐项拆怎么设。
- **语料出处**：JP-08 法国餐厅「只在淡季时段免单」先埋约束、概率拆解后揭底。

## 定律六 · 具体到不可疑（参数颗粒度 = 可信度）

- **定律**：把数字给到「具体到不可疑」的颗粒度，可信度自然立起来——「三斤二两」比「食材很好」可信一百倍。
- **心理机制**：可信度启发式——越具体越像真的，越像真的越被当行家。
- **适用行业痛点**：教程像空话，老板觉得「你在讲抽象道理，不是教我做」。
- **承载的真实功能**：券面额、有效期天数、限领张数、核销次数等「示例值」（标「示例」，数值取自 `spec/facts.json` / `spec/coupon-fields.json` 上限内自由设）。
- **语料出处**：JP-05「每只剁 36 块、油温 220 度、精确到三斤二两」。

## 定律七 · 过程即内容（演示「普通人怎么做」比晒结果更留人）

- **定律**：观众要看的不是「做好的结果」，是「一个普通老板在一步步怎么设、哪里会卡、卡了怎么改」的实录——过程自身就是内容。
- **心理机制**：代入感 + 学习动机——看别人磕磕绊绊做成，比看完美成品更能让我觉得「我也行」。
- **适用行业痛点**：老板不会设券，怕自己学不会；看成品截图无感。
- **承载的真实功能**：功能点逐个走「怎么设 → 为什么这么设 → 设完哪一方看到什么」的演示链路。
- **语料出处**：JP-12 全片是教练逐句带老板娘拍口播的过程；其「人群场景钩 → 视觉证据 → 数字背书 → 主张收束」四句模板可迁移。

## 定律八 · 认知缺口（把痛点定义成认知缺口，不是能力缺口）

- **定律**：老板不是「没能力」把生意做好，是「缺一个知道怎么做的认知」——把痛点讲成认知缺口，观众才信「补上这块我就能成」，而不是被教做人。
- **心理机制**：归因重构——把「我做得差」这种自我否定，翻成「我少懂一招」这种可补的缺口，保护自尊、激发动机。
- **适用行业痛点**：老板觉得「我生意不好是因为没客人/没命」，陷入无力感。
- **承载的真实功能**：开场钩子 + 功能点选择的取舍逻辑（选能补上那条认知缺口的功能线）。
- **语料出处**：JP-05「你缺的不是好味道，是让别人知道你味道好的方法」、JP-14「把玄学讲成机制」。

## 使用方式（挂进闭环故事五拍）

闭环故事五拍 = **抛悬念 → 讲道理 → 证明 → 落地 → 金句**。本库定律只在「讲道理」这一拍出场，配一首来自真实功能与行业的例子：

- **抛悬念**：先亮这个行业老板最痛的那个时刻（行业主轴，非定律）。
- **讲道理**：用上面某条定律解释「为什么你现在这么干不管用」——这是本库的落点。
- **证明**：用选中功能的「示例值」演示怎么解决（定律六的具体颗粒度）。
- **落地**：可照抄的操作（功能点逐个「怎么设/为什么/设完看到什么」，定律七的过程视角）。
- **金句**：把整片收束成一句可转发的认知（定律八的认知缺口式收口）。

每条片从本库挑 1 条主定律讲透即可（配 1~2 条辅助定律），不堆砌——**一条讲透 > 八条点到**。
