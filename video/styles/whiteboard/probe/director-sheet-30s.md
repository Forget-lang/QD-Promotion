## 一、导演六项（R9 §十五，逐项作答）

| # | 项 | 本片作答 | 判据自查 |
|---|---|---|---|
| 1 | **叙事结构** | 对比开场（周五热／周一冷）→ 诊断（缺的不是味道，是"来的理由"）→ 机制（到点开抢＋只有工作日可用）→ 兑现（回暖）→ 收口 | 相邻段都有"因为…所以…"：周一冷 → 所以要给理由 → 所以设机制 → 所以回暖；顺序调换会散架 ✓ |
| 2 | **观看动力** | 每个节点留下一个问题：为什么同一个店两种晚上 → 怎么让周一有人 → 它靠什么把人叫回来 | 三处均可答 ✓ |
| 3 | **悬念** | 缺口＝"同样是晚上，周一为什么没人"；兑现＝"缺的不是味道，是理由"（以机制呈现，不以台词解释） | 提出问题→延后回答，完整对答 ✓ |
| 4 | **转折** | 观众预期"要打折" → 实际**不打折**：设一个"到点才开抢、只有工作日能用"的券 | 可指出"原本以为 X → 改为 Y" ✓ |
| 5 | **情绪曲线** | 低（冷清）→ 疑问 → 亮（诊断与灯泡）→ 热（满座）→ 稳（收口） | 有"低—高"变化点 ✓ |
| 6 | **信息释放顺序** | 现象 → 原因 → 机制 → 结果 → 动作句 | 先讲机制后讲现象会失掉"诊断"环节 ⇒ 顺序有理由 ✓ |
