# 风格包 · whiteboard（白板手绘）

> **本文件是风格包（styleId=whiteboard），不是行业线作业流程；作业流程唯一 Owner 是仓库根 `SKILL.md`。**
> 本包只定义"**用什么视觉语言表达**"。**不含**：故事结构、信息释放顺序、悬念/转折设计、观看路径、情绪曲线、镜头决策意图——这些属导演层（`docs/internal/R9-视觉导演与审美决策.md` ＋ 逐片《导演稿》）。
> 验收判据：**换包不换导演稿**——同一份《导演稿》换用本包或其它风格包都应能落地；若本包要求改写叙事顺序／信息释放／观看路径，即本包越界。

## ① 身份

- **styleId**：`whiteboard`｜**名称**：白板手绘（手绘解释型表达）
- **适合**：经营概念的拆解与对比、机制说明、关系与因果的视觉化、过程感表达（"一件事正在被画出来"）。
- **不适合**：写实场景重现（本包不产出写实画面）；精细产品操作演示（产品界面按 ⑤ 走真实素材）。
- **状态**：`experimental`——首个验证风格。验证目标＝"导演稿 → 风格包 → 实现"链路成立 ＋ 换包不换导演稿可验。
- **选择理由（入档）**：六维初评 28 分居首，领先原因＝自带引擎（最快出真片）＋异介质（证"实现层并列"）＋annotation 契约天然即风格包接口。**非视觉偏好，非预设**。

## ② 表达能力（**不是叙事法**）

- **能表达**：概念之间的顺序与关系；对比与因果；量的变化；物的出现与消失；"逐笔落墨"的过程感。
- **用什么表达**：手绘线稿 ＋ 连续笔迹（起笔 ink → 添彩 color）＋ 少量概念色点缀 ＋ 纸面留白。
- **明确不承担**（属导演层，写进本包即越界）：故事结构、悬念与转折的设计、信息释放顺序、观看路径、情绪曲线；也不决定"这里必须出现什么内容"（内容选择属导演层）。

## ③ 视觉语言

- **纸底**：暖米黄 `#F5EBD7`（源图与成片一致；本风格**不使用**背景素材库的图当底）
- **线条**：深灰素描线；红／橙／蓝**仅作少量概念性点缀**；不用其它强调色、不用高饱和、不用复杂纹理
- **构图**：极简、干净、大量留白；对象以轮廓与少量线条表达，不追求写实比例与材质
- **一致性**：同一片内线条粗细、人物、配色统一；同风格跨片沿用同一套语言
- **源图禁文字（硬）**：线稿中不得出现任何文字／字母／数字／标签——所有文字一律由排版层叠加（见 ⑥）
- **禁止**：写实感、摄影细节、3D、绘画质感、密集背景、繁复装饰

## ④ 素材生成法（画面从哪来）

- **画面来源**：**矢量／程序化绘制**（当前无图像／视频生成渠道）——线稿由**绘制代码**产出（SVG 或等价的程序化绘制脚本），光栅化后进入引擎。
- **手部素材**：随引擎内置（不作对外素材登记）
- **统一视觉锚**：动笔前先落"视觉锚"（线条风格／人物比例／留白密度），同片全部线稿照同一锚产出；锚不落不得开画。
- **禁止生成清单（L1＋L3 落地）**：产品界面、功能字段、事实数字、经营结果数字、品牌名与 logo、可辨读的信息文字；不得产出"看起来像真实产品页面"的任何界面。
- **插槽声明**：本包当前**不产出写实人物／场景**。将来接入图像／视频生成能力时，只改本包（本栏即插槽）＋注册表一行，不动核心。

## ⑤ 产品证据位（L1 落地）

- 产品界面／字段／事实数字**只认三来源**：真实产品截图（D-1 登记且 `current-verified`）／按 R6 像素真值复刻／真实录屏。
- **在本风格里的出现方式**：**以"真实素材帧"接入**——干净贴入纸面，或作为独立证据段落；**不得画进线稿、不得生成**。
- 证据帧须与《导演稿》对应节点对齐（证据出现在它被需要的位置，而不是被装饰）。

## ⑧ 实现说明

- **引擎**：位于本目录 `engine/`（Python；自带独立 `.venv`；依赖 opencv-python／numpy／av／Pillow）；输入＝线稿 PNG ＋ 同名 `*.annotation.json`（区域／时序／字幕关联），输出＝**无声 MP4**。
- **出处与许可（合规硬要求）**：引擎适配自 `geeklee/srt-whiteboard-animation`（**MIT**）——**必须保留其 LICENSE 与版权／出处声明**，不得删除。
- **工程边界**：本目录不属 npm 工程（不修改 `video/src` 与 Remotion 工程）；引擎自带环境，不污染共享层。
- **合成链路**：本包只产出无声整片；**字幕／口播／产品证据帧的叠加与合成按《导演稿》在实现层完成**（Remotion 或后期），不属本包职责。
- **参数**：ink→color 权重、笔迹路径、上色风格、长边上限等，以引擎 README 为准（不在本包复述命令细节）。

## ⑨ 交付物清单（每片）

- **沿用现有编号产物**：内容输入包（须含本片 `styleId` 声明）、口播文案（如为有声）、分镜稿、R9 视觉决策卡（含「导演稿」节）、发布稿（如发布）。
- **本风格专属产物**：该片目录下的 `whiteboard/` 子目录——各场景线稿 PNG ＋ 同名 annotation.json ＋ 无声成片 ＋ 区域预览图。
- **不做**：「母题一页」（本风格已声明 N/A）、行业线的屏级数据文件（`video/src/data/*.ts`）。

## ⑩ 隔离与轮换

- **同风格不得连续复用**：下一片应换风格；若当前只有本包、必须连用，须在片首显式声明"连续复用例外＋理由"，交人判。
- **视觉隔离基准＝同风格内**：比较对象是上一条同为 whiteboard 的片；跨风格不比较。
- **扩展判据（本包自证）**：本包不引用其它包的实现；不要求 R9／`SKILL.md`／`AGENTS.md`／核心 Gate 为本包增改规则——新增本包＝一个目录 ＋ 注册表一行。
